# L3 层总目录: 大师票

> **L3 = 判断层**: 五位大师各发一票 — **通读 L1/L2 全部分卡** (阅读范围=全体, 见 §3), 按各自的 checklist 给独立 judgement。**收口卡是路标不是代读** (大师自己搬货)。
>
> **L4 = 裁决层 (链末)**: 总结定性、定量、五票结论, 给出建/等/弃 — L3 交出的两件东西 = 五票 + 各自定价区间, L4 的第一个实质消费动作 = **五票价格区间整合** (见 §4)。
>
> 基座: L3_01_fisher / L3_02_graham / L3_03_munger / L3_04_buffett / L3_05_duan (规则原文在各自 doc)。
>
> **执行节奏 (00 §0.1.5)**: 逐大师生成 — 每票 ①先提问→②逐问搜索→③④⑤写票→锁定→下一位; 五票浇筑 = 节奏+独立性双重违规 ("可并行"只指逻辑互不读)。

## §2 字面骨架 (五票共用的产出 contract; owner 本节, 执行规则见 §3)

> 每票产出的节标题照抄本模板字面; 五票 doc 不复述本模板, 各自头部引一行 `字面模板 = L3_00 §字面骨架`。排版可发挥, 节名/挂法是常量。

```
# {STOCK} — L3_0N 票名          ← A 式标题 (含 STOCK; 票名 = "费雪票/格雷厄姆票/芒格票/巴菲特票/段永平票", 不带括注)
## 这位大师会怎么说 (1 分钟, 无背景版)
## ① 我的问题 (先提问)
## ② 专属搜索 (逐问, 散文式)
## ③ 独白 (500 字)
## ④ checklist 逐条判定
## ⑤ 判决块 (机器层, 供 L4 grep)
## 尾注: 最想问管理层的一件事      ← 独立节 (禁表格内挂法; L4 财报夜清单 grep 锚)
## 锁定                         ← 时间戳 + 一句写后锁定声明
```

- **判决块字段顺序 (七行法定)**: 票 / 置信 / 质量档×麻烦档 (各票用各自档位语: 费雪 质量×麻烦 / 格 安全边际实测+r 异议位 / 芒 kill 计数+r 异议位 / 巴 生意定性+麻烦定性+资本配置 / 段 生意模式+十年路径+敢拿十年) / 折扣系数+r / 一票否决 / 定价区间 / 翻案条件 — 字段名跨票统一, 档位语义各票私器
- **票向双型 (conditional 必须声明挂哪一夜)**: conditional 的括号条件标 "等事件" (挂财报夜 — 财报/C-level 验证) 或 "等价格" (挂价格夜 — EOD 穿带/穿击球价); go/no-go 不分型。慢快解耦: 公司好不好 = 票向+档位 (慢, 锁定), 价格好不好 = 区间对 EOD (快, L4 价格夜重算) — 票向不被价格波动改写
- **定价区间行自带算式** (下沿/上沿 = L2_07 保守格 × 私器, 两锚全引 L2_07 已有格子, 禁自算新数; 第三列只装纯算式, 长语义注移入 hint 引段或翻案条件): 下沿 = 费雪 折扣×①基 / 格 熊档×2/3 / 段 回本线反推价 / 巴 ③扣信贷 / 芒 赔率够的入场格; 上沿 = 费雪 ③名基准 DCF / 格 ①基 / 段 回本 ≤12 年价 / 巴 ③名 r10 / 芒 fair 带 ②基
- **计算 hint 引段** (人话计算提示 — 算式管机器 grep, hint 管人 readable; 价格夜重算的 L4 输入也直接读这段):
  - **位置** = 判决块表格完全闭合之后 (空行→hint→空行); 禁插表格中间 — 分离的表格行渲染成两个无表头表
  - **四段式结构**: `> **计算 hint**:` 标签行 → 空 `>` → 上沿段 (≤~120 字, 算式+语义注) → 空 `>` → 下沿段 (同构) → 空 `>` → 速查段 (原料/格子出处)
  - 禁 300+ 字压一行 (hint 自己守 readable 总规); 长语义注 (如 "GARP 勉强格/仍超我 15 线") 写进对应锚的段里, 不挤表格列
- **上沿倒挂规则**: ③名 r(质量档) < 下沿时 → 上沿用 ②基 (禁区间负宽度)
- **r 异议位** (格/芒票法定字段): r 单源不另定, 异议只是重检/交叉验证

## §3 执行规则 (五件套逐件; 节序与节名以 §2 模板为准)

```
  ① (先提问)
     — 通读 L1/L2 分卡后, 这位大师会先冒出哪 3-5 个"必须搞清楚才能投票"的问题?
     — 问题写在前, 搜索是为它服务的 (不是先有结论后找补证据)
     — 问题合格标准: 只有这位大师会问 / L1/L2 公共池没碰 / 有 stakeholder
  ② (后搜索)
     — 逐问执行, 散文式记录, 禁表格
     — 每问三段结构 (段间空行, 禁拼成一块): query 行 (query 原词照抄) → 空行 →
       readable 发现段 (人话描述搜到了什么) → 空行 → 影响判定段 (影响哪条)
     — 零发现也要记录: 换词 ≥2 次后的"搜过, 无结果" (query 原词留档 = 防糊弄, 读者可验可复现)
     — ≥3 问中至少 1 个"受益判定" (发现实际改变某条的置信/理由)
  ③ (独白)
     — 此时写: 搜索已把问题变成证据, 独白消化它们
     — 每个论断必须能溯源到 ④ 的某条判定; 声音锚定 (格的数字纪律腔/段的口语反问/芒的毒舌比喻)
  ④ (checklist)
     — 各自清单跑全 (费雪 15/巴 10/段 8/芒格清单/格纪律)
     — 每条: 判定 + 一句证据引用 (指向 L1/L2 分卡页 或 ② 的某问)
     — 权重标注 (core/major/minor)
  ⑤ (判决块)
     — go / no-go / conditional + 置信 + 翻案条件 top 2-3
     — 字段顺序与定价区间规则见 §2
  尾注
     — 必须是 ② 搜索打开的那个洞 (显式标注"来自 #N 没搜到"), 不是收尾装饰
     — 五票的五个"最想问" = 裁决日 (财报夜) 的关注清单原料
```

**专属搜索的独立性**: 独立性第二支柱 (第一: 证据入口隔离)。与 L1/L2 搜索池的关系 — 池子是公共菜, 专属搜索是私房菜, **没搜过的独特点 = 这张票没真正独立过**。问题设计的大师视角例: 费雪 → 客户/卖家侧闲聊; 格雷厄姆 → 净流动资产历史带; 巴菲特 → 同生意十年前谁做过 (历史同型); 芒格 → "这生意死过的同行" (尸检史); 段 → "这生意十年后还需要人吗" (终局问)。

**阅读范围 ≠ 引用权重**: **阅读范围 = L1/L2 全部分卡通读** (大师进店先逛完整个铺子); **分发页只定引用权重** (侧重哪些卡、引用锚在哪), 不是阅读边界 — 票头"必读页清单"是侧重声明, 不是阅读窄门。独立性近似: 同一 LLM 同数据 → 模拟独立 (gut_check 是唯一真独立); 缓解 = 五票按分发权重看同一数据房间的五个不同角落 (格看 BS 皱眉, 费看留存心安 — 同一房子不同本能)。

**写后锁定**: 每票写完立即锁定 (时间戳), 互不回改 (防 L4 互评污染)。发现错漏 → 记"翻案条件"不改票; 字面格式修正例外 (对齐 §2 模板, 不碰判定/数字/文字内容)。

**版式**: 遵守 L2_00 十五条 (先结论/计算透明/标签附录) + #14 矩阵格一数一 cell; 散文层额外: 短句、大师口吻、黑话当场翻译、导读块分段 (四段之间插空 `>` 行 — 连续 > 行 = md 同段, 空 > 行才是分段)。

## §4 收口与整合 (五票写完之后)

**L3_00 产出 = 收口卡** (五票全部锁定后写): 一票一行的结论表 (票向/置信/核心理由一句/定价区间/翻案关键词) + 五票区间并排的分歧标注 — 给 L4 与用户的 3 分钟入口; 详细证据仍在各票。

**L4 价格区间整合协议** (五票各圈 [下沿, 上沿] 后, L4 整合三步):

> ① **共识带** = 五票区间 max(下沿) ~ min(上沿) 的重叠带 (无重叠时取重叠最多三票的带并注记)
> ② **离群票** = 与共识带零重叠的票 — 引其理由 + 00 §0.3 裁决优先级 (能力圈否决 > kill 共振 > 弃牌线 > BF6 仲裁) 定"离群赢还是共识赢"
> ③ 产出 = 共识价带 ± 离群注记 → L4 裁决 (L4 把区间变成建/等/弃与触发器)

> 价值: 五票分歧从五个数字变成可见几何 (重叠/离群一眼见), L4 从算术层升级整合层。
