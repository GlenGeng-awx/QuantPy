## 判定规则

- 三态: pass / borderline / fail (同 Fisher 协议; G7 是核心条目 = 票的门)
- **G2/G7 组合双 fail → no-go 直接出** (Graham 票的否决形态: 又贵又脆弱)
- borderline ≥5 → 置信降档
- G3 历史不足 10 年 (次新股/中概) → 用 5 年版本 + 置信降一档, 标注
