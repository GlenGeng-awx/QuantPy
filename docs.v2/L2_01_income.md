## §2 利润表 3yr 趋势 (income_annual)

**骨架行 (法定, 漏行=未完成, 行序锁定)**: Revenue ($B) → Rev YoY → GM% → OpM% → NI ($B) → NM% → EPS (dil) → 股数 (dil) — 8 行任何标的必含。NI/NM 紧跟 OpM 后 = 漏斗收口。NM 趋势列自带判读 ("含糖/虚高"类发现写在自己的行, 不等表尾)。
