## 费雪 15 条 (本体定义)

```
#1  产品/服务是否有足够大的市场空间支撑数年增长？    [否决项]
    补充: 市场增长是否健康 (公司能从中获利)？技术是否在改变价值分配 (市场增长但定价权下降)？
#2  管理层是否有决心开发新产品/工艺来扩大销售潜力？
#3  R&D 效率如何（相对公司规模）？
#4  是否有优秀的销售组织？
#5  是否有值得的利润率？
    补充: 利润率趋势是否结构性下降？技术商品化是否在侵蚀定价权？
#6  在做什么来维持/改善利润率？
    补充: margin 下降是否来自结构性因素 (技术商品化/竞争加剧) 而非一次性投资？
#7  劳工关系是否出色？
#8  高管关系是否出色？
#9  管理层是否有深度？
#10 成本分析和会计控制有多好？
#11 是否有其他方面给投资者优于竞争对手的洞察？      [护城河]
    补充: 护城河的性质是否在变？技术是否在让公司从"必需品"变为"商品"？
#12 短期还是长期视角？
    补充: 商业模式转换 (高价低量→低价高量；许可→订阅→freemium)？转换是否可持续盈利？
#13 股权融资是否会稀释现有股东？
#14 顺境时坦白，逆境时是否"闭嘴"？
#15 管理层诚信是否毋庸置疑？                        [否决项]
```

> 补充问题 (#1/#5/#6/#11/#12) 判定时加权: 补充问题为"是" (风险存在) → 该条至少 borderline; 严重影响 → borderline→fail。

**两维分拆** (折扣系数的行与列):

| 维度 | Fisher 条目 | 评什么 |
|------|-----------|--------|
| **质量** (10 条) | #2,#3,#4,#5,#7,#9,#10,#11,#12,#13 | 公司行不行 |
| **麻烦** (5 条) | #1,#6,#8,#14,#15 | 公司现在有没有麻烦 |

**权重列**: core 5 条 (#1/#3/#5/#9/#11+#14/#15 中取) / major 6 / minor 4 — 权重不进计分, 供 L4 判断"哪个 borderline 最疼"的参考。

## 三态与判定规则

```
PK 三态: pass / fail / borderline
  borderline = neutral: 有顾虑但没到 fail (不写 "borderline PASS" 式含糊)
  计分 (两维对称, 都数 PASS): borderline 不计入 PASS → 隐性降档
```

- 经搜索判定的条目: PASS 必须附负面搜索结果 (证明搜过负面); 纯水平 default 条目标 "default (未升级)"
- **否决项 (#1/#15) 的 FAIL 需 ≥2 个独立 source**
- 负面搜索是触发器不是终点 — 找到问题追问一层 (#8 离职 → "谁接任? 空窗多久? 主动还是被迫?")
- 搜索未执行 (captcha/失败) ≠ 无结果; 未搜索不 default PASS, 标"未搜索"
- **判定 = 分析日状态**: 离职旧闻 ≠ 当前 (TTD 判例: 已补位有序过渡 → borderline; 空缺/churn → fail)
- FAIL 去重: ≥3 条 FAIL 同根因 → 总结合并 1 条 (仅展示; 否决项不参与合并)

## 专属搜索协议 (为什么是 #7/#8/#14/#15 必搜)

**设计哲学 = 费雪闲聊法, web search 就是我们的"闲聊"** — 搜索优先级表:

| 类别 | 条目 | 能否从 data 推断 | 理由 |
|------|------|-----------------|------|
| **必搜** | #7 劳工 / #8 高管 / #14 坦白 / #15 诚信 | ❌ 财报无此信息 | 裁员/离职/隐瞒/SEC 案底都不在三表 — **只有 web 能验** (v3: 口碑三层协议见 L1_07) |
| **建议搜** | #11 护城河 / #2 新品 / #1 市场 | 部分 (GM/g 隐含) | 性质 (在不在变/TAM/侵蚀) 要搜 |
| **default 可升级** | #3/#4/#5/#6/#9/#10/#12/#13 | ✓ 水平可判 | **升级触发 (任一)**: ① L2_04 损伤表 flag 该维度 ② 判定悬在 borderline 候选 ③ 补充问题问"性质"非"水平" |

**闲聊视角交叉 (scuttlebutt lens — 与搜索层级正交)**: 杠杆是**视角交叉**不是递进深度 — 意外来自"换个人问"。管理层口径 = 单源不算交叉。规则: 必搜/升级条目 ≥2 个闲聊视角 (管理层/员工/客户/竞对/监管); 悬在补充问题的 ≥3 个。

**搜索弹药 (全文见源声明的 git 指针; 常用)**:
```
#1  pos "{company} market size TAM growth outlook" / neg "{company} market share loss declining"
#8  neg "{company} executive departure CFO CTO resign" + follow-up "who replaced, gap, forced?"
#15 neg "{company} SEC investigation scandal fraud lawsuit accounting"
#11 补充 "{company} moat type changing technology disruption commoditization"
```

## 计分 → 档位 → 折扣 (2D 表本体)

```
质量 (10 条数 PASS, borderline 不计):
  ≥9/10 → 伟大 / 6-8 → 好公司 / ≤5 → 平庸

麻烦 (5 条数 PASS):
  4-5/5 → 无麻烦 / 2-3 → 存疑 / 0-1 → 重麻烦
```

**折扣系数 2D 表 (质量 × 麻烦 → ×系数)**:

| | 无麻烦 (4-5) | 存疑 (2-3) | 重麻烦 (0-1) |
|---|---|---|---|
| **伟大** | ×1.0 | ×0.85 | ×0.67 |
| **好公司** | ×0.85 | ×0.70 | ×0.50 |
| **平庸** | ×0.67 | ×0.50 | ×0.40 |

**r 定档 (质量维度, L2_07 r 杠杆 -35% 的 owner 在此)**:
```
伟大 → r9 / 好公司 → r10 / 平庸 → r11
```

**Override 优先级 (高盖低)**:
```
1. 硬规则: FCF-SBC < 0 → ×0.40 (不否决, 总是估值; 不与其他折扣叠加)
2. 价值陷阱过滤器: #1+#6+#14 ≥2 FAIL →
     档 A: FCF-SBC ≤0 OR Rev YoY <0 → ×0.40 (强制)
     档 B: 均为正 → g=0 估值 + ×0.70 (上限 — 2D 更低时取 2D)
3. 否决项: #1 或 #15 FAIL → 麻烦档至少存疑 (无论 PASS 数)
4. 2D 表
```

## 票产出格式 (L4 消费)

```
| 项 | 值 |
|----|-----|
| 票 | go / no-go / conditional (附条件) |
| 置信 | 高/中/低 |
| 质量档 × 麻烦档 | (伟大/好/平庸) × (无/存疑/重) + PASS 计数 |
| 折扣系数 + r | 2D 表格值 + override 说明 |
| 一票否决 | #1 或 #15 FAIL? (是 → L4 裁决优先级 2) |
| 定价区间 | [下沿, 上沿] — 下沿 = ①基×折扣; 上沿 = ③ 名义 r(质量档) (锚全引 L2_07 格子); 倒挂时上沿用 ②基 |
| 翻案条件 | top 2-3 |
```

> 区间行下必附**计算 hint 引段** (模板见 L3_00 §2): "上沿 = EPS×(8.5+2g 或 ③DCF) = 算式 = 数字; 下沿 = ①基×折扣系数 = 算式 = 数字。速查: 原料在 L2_05/06, 格子在 L2_07"。
> 价值陷阱过滤器输出 (档 A/B) 交 L4 归类; 折扣只乘入场价层 (L4)。
