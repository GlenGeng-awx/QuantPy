## 双维裁决矩阵 (核心裁决逻辑 — 两件共用)

> L3 五票的票向 → 两个维度: **公司好不好** (生意有没有人否 — 慢变量, 财报级) × **价格好不好** (现价落在共识带什么位置 — 快变量, EOD 级)。

```
                 好价格 (≤ 共识带内)       坏价格 (> 共识带上沿)

好公司            建 (击球: 升级建仓评估)    等 (挂触发器: 价格或事件)
(生意无人否)

坏公司            弃 (便宜是症状)           弃
(kill/圈外否决)
```

- **两道数量门 (fair price for a great company 的机器判据)**:
  - **公司门** = ≥4/5 票 (数据源: **L3_00 收口表 "公司侧" 列直读** — 好=1 / 好·带注=0.5 / 否=0; L4 只需数数) + 否决权 (公司侧"否" = kill 共振 fail/能力圈 → 一票毙, 落"弃"); 输出三态:
    **好** (票数够且无注) / **好带验证** (票数够, 但有 好·带注 票 — 价格到位也不裸建, 挂事件夜验证解锁, 见合成矩阵"等-贴线") / **弃**
  - **价格门** = **≥3 票区间覆盖现价** = 击球候选 (数据源: 收口表 "价格侧" 列; 三票同意 = 多数决; 比共识带上沿宽一档 — 共识带 = 最严少数决, 三票覆盖 = 多数决); 现价入共识带下沿区 = 强击球
  - **格票防线 (旁路否决, 独立于两门)**: E-peak 检查 (L2_08 §1) — 三票覆盖但 E 在周期山顶 → 击球降级"观察" (防 DCF 口径同源的三票假击球)
- **合成矩阵**:
  - 公司门好 × 价格门 ≥3 票覆盖 → **建** (击球: 升级建仓评估)
  - 公司门好带验证 × 价格门 ≥3 票覆盖 → **等-贴线** (事件夜三验解锁后才建)
  - 公司门好 (任何态) × 价格门 <3 票覆盖 → **等** (挂双夜触发器)
  - 公司门弃 × 任何价格 → **弃** (便宜是症状)
- **共识带** = 五票定价区间的 max(下沿)~min(上沿) 重叠带 (L3_00 收口已算) — 强击球刻度 (下沿区), 不再是价格门的唯一判据。
- **共识强度 → 仓位语义** (建评估解锁后用): 5:0 满仓资格 / 4:1 小仓 / 3:2 观察 / 分裂 → 等裁决日。
- 归类映射 (旧五词的简化): 建=最佳买点 / 等=公允价好公司 / 弃(坏公司)=价值陷阱+结构性恶化 / 能力圈外=段 D2 独立否决。

## 触发器纪律

> 触发器表 (详版 §5) = 五票翻案条件归并, 每条带阈值与动作 — 链的**产出物** (阈值来自锁定票的翻案条件)
>
> **"等"不是不动, 是挂单在事件或价格上**; 距击球区 <10% 的等 = 挂 等价 CSP (协议见本节下方)
>
> 持仓衔接段必须处理用户现有仓位 (含期权的时序错配检查)
>
> **等价 CSP (击球候选 → 挂单不等价)**: 现价距击球区 <10% 时, 等待不空转 — 挂 CSP 行权价 = 击球区边界 (链纪律 ≤共识带上沿):
> - **到期日必须跨下一个验证事件**: 接货发生在验证之后, 接的是"验过的货"不是刀
> - **事件夜平仓防线**: 验证败 (如三验 miss) → 当晚买回平仓, 认 1-2 倍权利金的错 — 弃纪律优先于收租 (不等刀穿行权价)
> - 权利金语义: 收租的等 = 价格没到击球区的补偿; 接货 = 市场先生替你在击球区成交
