## 双维裁决矩阵 (核心裁决逻辑 — 两件共用)

> L3 五票的票向 → 两个维度: **公司好不好** (生意有没有人否 — 慢变量, 财报级) × **价格好不好** (现价落在共识带什么位置 — 快变量, EOD 级, 价格夜重算见下)。

```
                 好价格 (≤ 共识带内)       坏价格 (> 共识带上沿)

好公司            建 (击球: 升级建仓评估)    等 (挂触发器: 价格或事件)
(生意无人否)

坏公司            弃 (便宜是症状)           弃
(kill/圈外否决)
```

- **两道数量门 (fair price for a great company 的机器判据)**:
  - **公司门** = ≥4/5 票 "公司好不好"判好 (数据源: L4_01 §3 双维表第三列, L4 只需数数) + 否决权 (kill 共振/能力圈 → 一票毙, 落"弃"); 输出三态: **好 / 好带验证 (kill 共振或周期注) / 弃**
  - **价格门** = **≥3 票区间覆盖现价** = 击球候选 (三票同意 = 多数决; 比共识带上沿宽一档 — 共识带 = 最严少数决, 三票覆盖 = 多数决); 现价入共识带下沿区 = 强击球
  - **格票防线 (旁路否决, 独立于两门)**: E-peak 检查 (L2_08 §1) — 三票覆盖但 E 在周期山顶 → 击球降级"观察" (防 DCF 口径同源的三票假击球)
- **合成矩阵**:
  - 公司门好 × 价格门 ≥3 票覆盖 → **建** (击球: 升级建仓评估)
  - 公司门好带验证 × 价格门 ≥3 票覆盖 → **等-贴线** (事件夜三验解锁后才建)
  - 公司门好 (任何态) × 价格门 <3 票覆盖 → **等** (挂双夜触发器)
  - 公司门弃 × 任何价格 → **弃** (便宜是症状)
- **旧的多数决/no-go 性质拆解并入两门**: conditional 算 0.5 票只进公司门计分; 价格型 no-go → 公司门过+价格门未过 = "等"; 生意型 no-go (kill 共振/能力圈/D4) → 公司门毙 = "弃"。
- **共识带** = 五票定价区间的 max(下沿)~min(上沿) 重叠带 (L3_00 收口已算) — 强击球刻度 (下沿区), 不再是价格门的唯一判据。
- 归类映射 (旧五词的简化): 建=最佳买点 / 等=公允价好公司 / 弃(坏公司)=价值陷阱+结构性恶化 / 能力圈外=段 D2 独立否决。

## 触发器纪律

> 触发器表 (详版 §5) = 五票翻案条件归并, **双夜分列**:
>
> **财报夜** (事件验证, 按时间排序优先) + **价格夜** (EOD 穿带/穿击球价) — 每条带阈值与动作
>
> **"等"不是不动, 是挂单在事件或价格上**; 距击球区 <10% 的等 = 挂 等价 CSP (协议见 §价格夜重算)
>
> 持仓衔接段必须处理用户现有仓位 (含期权的时序错配检查 (芒格 B4 域))

## 价格夜重算 (EOD 驱动的快通道)

> 慢快解耦: 公司好不好 (L3 票向+档位, 财报级, 锁定) × 价格好不好 (区间对 EOD, 日频)。事件夜 (财报/C-level/SEC) → 全链重跑 (现有时效协议); 价格夜 → 本协议, 快通道。

- **触发**: EOD 收盘后 — 现价穿共识带任一边界 / 穿任一票的"等价格"型击球价 / 单日 |>5%
- **动作**: 只重跑 L2_08 §1 锚定 (隐含 g 反推 + 市场先生状态) + L4_00 一屏 (裁决行/击球判定/持仓衔接); **L3 票不动** (锁定语义为此服务 — 公司判断不被价格波动改写)
- **输出**: 两道门击球判定 (规则见§双维矩阵) — 公司门三态 × 价格门 (≥3 票区间覆盖现价 = 击球候选; 入共识带下沿区 = 强击球) + 格票防线刀检
- **格票防线 (强制)**: 价格夜必带 E-peak 检查 (L2_08 §1 三口径隐含 g + 分位 + 周期位置刻度) — 跌进带 ≠ 便宜, 刀股带内也带刀; 输出是"重算+刀检", 不是"买"
- **等价 CSP (击球候选 → 挂单不等价)**: 现价距击球区 <10% 时, 等待不空转 — 挂 CSP 行权价 = 击球区边界 (链纪律 ≤共识带上沿):
  - **到期日必须跨下一个验证事件** (B4 纪律: 接货发生在验证之后, 接的是"验过的货"不是刀)
  - **事件夜平仓防线**: 验证败 (如三验 miss) → 当晚买回平仓, 认 1-2 倍权利金的错 — 弃纪律优先于收租 (不等刀穿行权价)
  - 权利金语义: 收租的等 = 价格没到击球区的补偿; 接货 = 市场先生替你在击球区成交
- **不做**: 不改票向, 不改区间 (L3 锁定); 统计层不判断公司好坏 (倒因为果 = G10/NVO 教训); 快通道连续触发 ≥2 次仍无法裁决 → 升级全链重跑 (可能基本面已变)
