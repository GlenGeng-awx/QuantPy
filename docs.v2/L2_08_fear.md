## 先说结论

三句: 是错杀还是已定价 (核心判定) + 是刀吗 (下修正证中?) + 唯一的买点逻辑是什么; 30 秒导览 (§1 故事 → §2 足迹 → §3 even-if → §4 对面 → §5 判定 → 锚点)。

## §1 市场在讲什么故事? (隐含定价的锚定审计)

**三口径隐含 g 倒推** (现价 ÷ 各口径 EPS → 市场接受的 g):

| 口径 | EPS | 隐含 g | 语义 |
|------|-----|--------|------|
| GAAP trailing | | | 含糖口径 (市场信的表面数) |
| FINAL (L2_05) | | | 洗糖口径 (真实要求) |
| forward (街) | | | 远端口径 |

- 现价在 L2_07 矩阵带的位置 (上沿/中枢/下沿/r 几档) — 一句话命名 (如 "r9 伟大默认价" 式标签)
- 52w 区间位置 (距高点/低点 %) + 当日事件标记
- **E-peak 证据链挂点** (分位双低 ≠ 便宜的反证, 三重证据: ① 分位低 + derating ② 中周期位置刻度 (L2_05 §4) ③ 直折 vs 匀速差 (L2_07 §4)) — 全在 = "低分位主因 E 在周期高位" 判定成立
- **LLM 判断 (给理由)**: 市场信的故事 = 框架哪一档? 过度惩罚 (< 熊档) = 错杀候选 / 恰当 (贴基准) = 已定价 / 乐观 (> 基准) = 风险
恐惧体积 (定义保留, 判定降级为 §1 输入): 体积 = 趋势 g (过去 8 季盈利增速年化) ÷ 隐含 g (现价/EPS_trailing − 8.5, Graham 式反推); 体积 ≥ 1.5× → 错杀候选 / ~1.0× → 恰当 / < 1.0× → "负体积" (无错杀甚至透支)。
  实例: TTD 8/7 股价 -76% 但体积 0.67× (趋势 -5% vs 隐含 +7) → 跌很多 ≠ 便宜, 拒接 ✓; SE 10/22 体积 3.1× → 真恐慌错杀深 ✓。
  已知盲区: ① E-peak 盲 — NVDA 体积 0.35× 判 "无错杀" 碰巧对但理由错 (负体积本质 = E-peak 判定的最早形态, 当时没意识到分母在山顶) ② 阀值拍脑袋 + 看不见 "病/死" 分层 — 所以判定权归 三问审计, 体积只作 §1 输入 (需配 E-peak 三重证据链才能下 "非错杀" 结论)。

## §2 故事踩表了吗? (足迹审计 — 主菜)

| 子叙事 | 应现足迹 | 实际 (5Q) | 踩表? | 病/死 | LLM 判断与理由 |
|--------|---------|-----------|-------|-------|---------------|

- 恐惧叙事**拆子叙事**逐条踩; **加权分层: 病 (可逆: 费用/预算/周期) vs 死 (不可逆: 替代/封杀/前提)** — 机械 ≥半数规则废除, 权重结构归 LLM
- 表后**加权结论句** (如 "踩表 4.5/8, 踩的几乎全是病级, 唯一死级已被共识打印 → 基本面事件" 式)
- 诚实边界: 公司口径数据 (留存/份额) 标注口径

## §3 even-if 与赔率 (诚实条款)

- even-if: 最狠故事兑现价 (EPS 降档 × 封底 PE, 直引 L2_07 情景行); 对照框架基准带; 赔率 = 上行 ÷ 下行 (对熊档 / 对 even-if 双口径)
- **诚实条款 (Nokia 反例)**: even-if 不证明恐惧会来; 赔率浅 ≠ 该卖, 深 ≠ 该买 — 它只回答 "这个价格在赌什么"
- **给 L4 的语义**: 现价买入理由是 "转折赌注" (事件驱动) 还是 "安全边际" (错杀驱动) — 两者别混

## §5 判定 (叙事审计结论)

四问逐项判 + 理由:
1. **是错杀吗?** (对照 E-peak 证据链 — 分位双低在周期高位标的上的默认答案是"不是")
2. **是刀吗?** (下修**落地程度** — 指引上修中 = 非刀; 但标记"刀化候选窗": 下一次财报 miss 即反转)
3. **脚下有底吗?** (框架底/even-if 底/回购托底位, 各标 -x%)
4. **唯一的买点逻辑是什么?**

**错杀形态学枚举** (五形态谱, 判定第一句从这里选型): 无火型 (SE) / 自下而上型 (ADBE) / 自上而下型 (TTD) / 带下方型 / **信仰定价型 (第五形态: 既非错杀也非转折, 现价 = 市场把质量档当默认前提 — NVDA 首例)**。
**收尾 = 给 L4 的原话** (一句话可执行的区分)。
