# 05 利润率卡: 行业赚多少, 它赚多少, 资本饥渴吗

> 核心问题: 利润率的行业对标 (贵不贵在哪儿) + 资本强度 (赚的钱要不要全吐回去建产能)。
> 
> 大师锚: 巴菲特 1977 信 (通胀如何欺诈投资者 — 重资产之痛) / 1986 信附录 (所有者收益); 芒格 A3 (资本饥饿 kill); Fisher #5/#6。

## 卡要回答的六个问题

```
1. 行业利润率量级: 同行普遍什么水平 (毛利率/经营利润率量级区间, 毛估估)
2. 公司利润率 + 对标差: 它是多少? 比行业头部高/低多少 pp? 高出来的部分,
   护城河 (03 卡) 能解释吗 — 超额利润的来源必须指认 (品牌溢价/成本优势/垄断租金)
3. 利润率方向 (5 季 + 年度): 在爬/在滑/走平? 滑的原因是竞争价格 (NVO) 还是
   投资期成本 (ADBE freemium) 还是周期 (MU) — 定性归因, 这是 L3 麻烦定性的原料
4. 资本强度 (本卡灵魂之一): CapEx/收入 多少年? CapEx vs D&A 的比值 (>1 =
   在扩张, <1 = 在收割); **赚的钱要不要全部再投才能维持** (芒格 A3 判定:
   CapEx 长期 > 经营现金流的 60-70% = 资本饥饿型)
5. 资产负债表的镜子: 净债趋势 (扩张谁买单 — 自己的现金还是发债); 净债/EBITDA 量级
6. 利润质量: OCF/NI 比值 (现金>账面 = 优质, <1 = 应收/存货积压警告); SBC 占收入
   比重 (利润被期权稀释的程度)
```

## 写作纪律

- 散文 ~1000 字; **本卡是 L1 卡组里定量最重的一张** (但仍是毛估估 — 量级和方向, 不做三口径校验)
- 对标必须有参照系: 至少 2-3 家同行的量级 (拿不到写"未获取", 不编)
- 归因三选一框架 (竞争/投资期/周期) 是 L2e 足迹检查和 L3 BF6 的直接接口
- **FCF 负 + 净债上升的组合必须显式标出** (ORCL/NVO 型 — 资本周期豪赌画像, 芒格 A3+A6 双 kill 候选)
- 禁现价/估值倍率; 利润率/现金流/净债全是生意事实, 允许

## 附录锚点 (机器层)

```
A1 行业 vs 公司: GM {行业 X% vs 公司 Y%}, OpM {同}
A2 超额利润来源: {指认}
A3 方向+归因: {爬/滑/平; 竞争/投资期/周期}
A4 资本强度: CapEx/Rev {X%}; CapEx/D&A {Nx}; A3 判定 {饥饿/平衡/收割}
A5 净债: {金额 + 趋势 + 谁买单}
A6 利润质量: OCF/NI {X.X}; SBC/Rev {X%}
A7 红旗 + 证伪信号 (利润率/GM/FCF 的阈值挂 08 卡裁决日)
```

## 搜索弹药库 (实战沉淀, 持续迭代)

> 纪律: 数字最多的卡 — 每个数字都要口径; 对标找不着就降级为"量级印象", 不编数

```
主取数 (web 标准路径, 本卡核心):
  stockanalysis 财务页: TTM/年度的 GM/OpM/NI/FCF/净现金 一页全给 (TTD/COIN 实例)
  季度序列: 同页 Quarterly 视图 (COIN 实例: 收入四连降+OpInc 转负的 5Q 序列)
方向判定轮:
  5 季+年度的 GM/OpM 分岔必读 (TTD 实例: GM 滑 5pp + OpM 爬 12pp = 收缩型管理)
  分岔时追问费用端动作 (裁员/重组新闻交叉) — 利润率的爬是生意还是剪刀
对标轮:
  "{peers} gross margin operating margin comparison"
  卖方 preview 的行业 margin 表; 同层上市对手的 stockanalysis 页直接开 (最省轮次)
  拿不到精确对标 → 降级量级印象并标注 (AWX 做法: Wise/Adyen/Payoneer 三档量级带)
私有公司特例轮:
  融资 PR + "record revenue but losses widen" 式年报转述 (AWX 实例); ASIC 备案媒体口径
  无三表 → 本卡退化为方向性事实卡 (AWX 模板)
GAAP 亏损解剖轮 (出现亏损时):
  亏损构成必须拆到条目 (COIN 实例: 重估损失 ~$1.7B 非现金 — 三层报表三个故事)
```

## 追问规则 (本卡)

- OpM 的每次显著爬升必须交叉费用新闻 (裁了几人/砍了什么) — 一次性动作要标注
- 净债/净现金的趋势变化必须归因 (回购? 发债? 经营?) (TTD 实例: FY24→25 净现金 -$742M 是回购)
- SBC 与 CapEx 并列摆 (费用形态的资本开支, 供 L3 芒格 A3 用)
