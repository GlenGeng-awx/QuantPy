## 条目 (~10)

| # | 条目 | 标准与出处 | 接口 |
|---|------|-----------|------|
| BF1 | 能力圈: 生意我能懂吗 | "告诉十岁孩子它怎么赚钱" (1996 信: 能力圈); 懂 = 能大致说出它十年后的利润量级 | L1 §6 |
| BF2 | 消费者特许经营 (franchise) | 有定价权、被需要、无替代、不受监管摆布 (1991 信); vs 商品生意 | L1 §3 + 提价史 |
| BF3 | ROE 质量 | 长期 ROE ≥ 15% 且**非杠杆虚增** (1977/1988 信 ROE 讨论; 剔除 D/E 抬升) | L2_01/02/03 |
| BF4 | 所有者收益 > 会计利润 | OCF − CapEx − 维持性 CapEx ≥ NI 的 ~90%+ (1986 信附录所有者收益定义); CapEx 长期 > D&A 的"利润幻觉"标 fail | L2_02 §4 (D&A vs CapEx) |
| BF5 | 资本配置评级 | 四去向检验 (留存/回购/分红/M&A): 留存 1 美元创造 ≥1 美元市值 (1984 信); 回购须低于内在价值 (2007 信); 分红稳定 (1988/2012 信); M&A 不高价买平庸 (1982 信 "以黄金价格买白银") | L2_02 §5 资本配置轨迹 + web |
| BF6 | **一次性麻烦 vs 永久损伤** | 暂时性问题 (经营周期/一次性事件/品牌受损可修复) vs 夕阳结构 (1977 信纺织 vs 保险; 1989 信); **L4 裁决 Graham/Fisher 冲突的仲裁人** | L1 + L2_04 § 损伤评估 + web |
| BF7 | 十年测试 | "不打算持有十年就不要持有十分钟" (1988 信); 十年后利润大概更多吗? 答不出 = no-go | L2_06 + L1 C2 交叉 |
| BF8 | 管理层三件套 | 理性 / 坦诚 (全面如实报告, 不藏坏消息) / 抵制制度惯性 (1987 信《Rational 资本配置》) | web (指引兑现史) |
| BF9 | 资本结构与通胀敏感 | 不需要持续新增资本就能增长 (2007 信 "轻资本复利"); 通胀下重资产生意价值毁灭 (1977 信《通货膨胀如何欺诈股票投资者》) | L2_02 §4 CapEx 趋势 |
| BF10 | 价格纪律 | "以合理价格买伟大公司, 远胜以便宜价格买平庸公司" (1989 信) — 但**价格刻度仍从 L2 取** (本票只表态"这个生意配得上什么价格态度", 不自算价格) | L2_07 + 本票定性 |

## 判定规则

- 三态 per 条; **BF1 不懂 → no-go (圈外, 与段/芒格 E1 同为 L4 否决线)**; BF7 答不出十年 → no-go
- BF6 是本票最重一格 (麻烦定性 → 直接进 L4 常驻冲突议题 1 的裁决输入)
- BF5 资本配置评级四格表 (留存/回购/分红/M&A 各一档) 是独有产出

## 票产出格式

```
| 项 | 值 |
|----|-----|
| 票 | go / no-go / conditional |
| 置信 | 高/中/低 |
| 生意定性 | franchise / weak franchise / commodity (BF2) |
| 麻烦定性 | 一次性 / 结构性 / 修复中 (BF6 — L4 仲裁输入) |
| 资本配置评级 | A/B/C/D (BF5 四格) |
| 十年答案 | 一句话 (BF7) |
| 定价区间 | [下沿, 上沿] — 下沿 = ③名 r10 − 信贷调整; 上沿 = ③名 r10 (锚全引 L2_07) |
| 翻案条件 | top 2-3 |
```

> 区间行下必附**计算 hint 引段** (模板见 L3_00 §2): "上沿 = ③ DCF (F×g1, r10) = 算式 = 数字; 下沿 = 同格 − 信贷调整额 (净债/循环敞口的最坏计) = 算式 = 数字。速查: 原料在 L2_02/03, 格子在 L2_07"。

> 校准锚: NVO 9/30 — BF2 weak franchise (定价权流失中), BF4 fail 型 (CapEx 3.1x D&A, 利润幻觉), BF5 B+ (分红 121% FCF 债务供养扣分, BD 纪律弱), BF6 定价战 = 结构性 (修复需 2027-28) → conditional 票, BF6 输出直接预告 L4 议题 1 裁决方向。
