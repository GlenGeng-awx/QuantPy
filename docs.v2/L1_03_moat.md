# 03 护城河卡: 客户想走时有多疼

> 核心问题: 护城河的来源与实测; 差异化存不存在; **敢不敢提价** (定价权 = 护城河的体温计)。
> 
> 大师锚: 巴菲特 BF2 (特许经营四问 — 1991 信); 段 D5 ("没有差异化, 最终都是价格战"); Fisher #11。

## 卡要回答的六个问题

```
1. 护城河来源盘点 (白话 + 强度): 品牌 / 网络 / 转换成本 / 成本优势 / IP与牌照 /
   无形资产 — 每项一个"疼感画面": 客户换走时要付出什么具体代价 (重学/重建/丢数据/丢兼容)
2. 定价权实测 (本卡灵魂): 提价史 — 过去 5-10 年提过几次价? 提价后客户流失了吗?
   反向问: 为什么不敢提 (NVO 价格战)? 为什么推迟提 (ADBE 2026)?
3. 差异化判定 (段式): 客户视角"非它不可"的点是什么? 竞品模仿这个点要多久/多少钱?
   双层分化时分开写 (ADBE: 专业层厚/prosumer 层被磨)
4. 护城河是否在变: 性质在变吗 (价值从旧防线流向新防线)? 有硬到期日吗
   (专利 LOE/协议续约/牌照窗口)? 软性侵蚀时间表 (教育渗透/习惯迁移)?
5. 反证收集: 客户成功离开的案例 (Publicis 决裂 = TTD 护城河的反向实测);
   提价失败史; 份额被抢的环节
6. 护城河与 02 卡战况的交叉: 每条战线 (价格战/换轴) 正在攻护城河的哪一层,
   守住了吗 (给证据)
```

## 写作纪律

- 散文 ~1000 字; **提价史必须给实证** (年份/幅度/后续留存), 这是最硬的定性证据, 拿不到写"未获取"
- 疼感画面优先于术语 (说"技能和文件长在里面", 不说"高转换成本")
- "是否在变"是本卡最重要的判定输入 (→ L3 五票吵架的主战场), 本卡只摆事实不裁决
- 禁"护城河很深/在崩"式结论词; 禁现价/估值

## 附录锚点 (机器层)

```
A1 来源×强度: {品牌:强 / 转换成本:强 / 网络:中 ...}
A2 定价权实测: {提价频率/幅度/留存 — 或"不敢提"+原因}
A3 是否在变: {是/否; 旧防线→新防线一句话}
A4 干涸时间表: {硬日期/软性年数}
A5 反证: {客户离开案例/提价失败史}
A6 红旗 + 证伪信号
```

## 搜索弹药库 (实战沉淀, 持续迭代)

> 纪律: 每轮至少追问一层; 提价史是最硬证据, 值得多换几组词

```
定价权实测轮 (本卡灵魂, 允许 3+ 轮):
  "{company} price increase / fee increase history"
  "{company} pricing backlash" (提价被骂的客户反应)
  不敢提价的证据也搜: "{company} fee pressure / audit / dispute" (TTD 实例: Publicis 战争起因)
  让利换量的模式: "{company} take rate decline" (COIN/AWX 同款形态)
反证轮 (客户离开案例):
  "{company} customer defection / drops / switches to"
  大客户公开决裂的全周期 (开战→审计→和解) 都要追 (TTD 实例: Publicis 决裂-和解完整弧)
性质在变轮:
  "{company} moat erosion / disruption"
  平台依赖方的政策动作 = 地基信号 (TTD 实例: 苹果黑名单; AWX 实例: GENIUS 后银行进场)
效果证据轮:
  公司自研口径的研究 (ROAS 提升类) 必须标注"公司口径", 独立验证另搜一轮, 搜不到写零
已验证无效:
  空泛的 "moat analysis" 文章 (SA 长文多为观点复述, 无新事实)
```

## 追问规则 (本卡)

- 提价史拿不到 → 换词至少 3 组再判"未获取" (这是全套最硬的定性证据, 值得烧轮次)
- 每条"公司在变"的证据必须配"对手/客户/平台"的动作做交叉, 单边叙事降级
- scuttlebutt 追加问 (见下) 是最后兜底

## scuttlebutt 追加问 (定价权实测, 只能靠一级信息)

```
问采购员: 你上一次认真比价是什么时候? 换供应商的报价差距要到多少才值得换?
(媒体永远不会报道"差 3% 所以没换" — 但那就是护城河的真实宽度)
[榨干注规则同 L1_07: 公开代理已到哪 (提价史/流失案例) / 剩"差多少才不换"这格结构性不公开]
```
