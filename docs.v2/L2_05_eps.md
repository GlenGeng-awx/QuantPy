## §3 显形规则 + 峰值口径检查

- **单季异常峰**: OpM 偏离 5Q 均值 >15pp (L2_01 §3 已应看到) — 正常化时该季必须拆解: 一次性收益成分 (剔) vs 旺季规模效应 (留+季节系数)。
- **恢复 EPS (EPS 负值时)**: 加回一次性费用 − 剥离一次性收益 × (1-正常税率) / 股数; 仍 ≤0 → 标"经营亏损不可恢复", EPS 模型 N/A。
- **峰值口径检查 (L1_06 周期型/周期阴影 强制)**: FINAL 建在 TTM 收入上 — 若远端减速兑现, EPS 峰值风险在哪年; 回落情景 EPS (周期回落假设, 如 DC -30% + OpM 反向) 只立刻度, 具体格子留 L2_07 情景行。

## §4 周期口径 (中周期 EPS — 镜头消费: L1_06 周期型/周期阴影)

**算法 hint (不是规则 — 算法是起点, LLM 判断收尾)**:
- 窗口 = 最近 10 财年 (不足用全部并标注; CSV 之外的年份 web 补, 来源入表)
- 统计量 = **中位数** (每年 NI ÷ 当年股数 = 当年 EPS, 再对 EPS 序列取统计量 — 禁先加总 NI 再除末年股数, 缩股会虚高); 均值同算一列, **均值/中位 >2x 本身是信号**
- 产出 = 中周期 EPS + **周期位置刻度** (TTM FINAL ÷ 中周期: >1.3 高位 / 1.0±0.2 中枢 / <0.8 低位)

**LLM 判断 (必须给: 结论 + 置信度 + 理由)** — 判断维度: ① 窗口内结构是否换轴 (两时代拼接 → 中位数失效) ② 均值/中位比值的分布形态 ③ 窗口完整周期数 (≥1 峰 1 谷?)。结论三选:
- **(a) 可靠** → 中周期 EPS 入 §2 FINAL 区做估值锚, L2_07 加中周期行
- **(b) 算术对但语义失效** (如: 换轴 + 均值/中位 >2x 极端分叉) → 降级为**位置刻度** (喂 L2_08 E-peak 证据), 估值锚退给情景法 — **拒绝采纳本身是合格产出**
- **(c) 数据不足** → 显式写, 不编

**留档要求 (全过程入卡)**: 输入表 (每年 EPS + 来源) / 三口径结果表 (中位/均值/含 TTM 版) / 判断结论+置信度+理由 — 后来者可验可推翻。
