# 02 地位卡: 公司在行业里的位置

> 核心问题: 排第几? 它在追赶谁? 它被谁追赶、被谁绕过? 战争是什么性质的?
> 
> 大师锚: 段永平"看懂竞争格局再谈生意"; Fisher #4 (销售组织的外化)。

## 卡要回答的六个问题

```
1. 排位: 公司在行业利润池里排第几 (按利润不按收入 — 收入第几不重要, 利润第几才重要)
2. 竞对地图: 前 3-5 名各是谁, 各自"靠什么赢" (一句话/家, 不列营收表)
3. 追赶对象: 公司在往上打谁? 打得动吗 (份额/头对头数据)?
4. 被谁打: 谁在往下攻它? 攻它的哪一层 (价格/功能/渠道/范式)?
5. 被谁绕过: 有没有对手不打它、直接换战场让它 relevance 衰减 (TTD 被 AppLovin 绕;
   传统零售被电商绕)? 这是"换轴战"识别位
6. 战争性质 (白话): 份额战 (同轴抢地盘) / 价格战 (拼成本) / 换轴战 (战场本身在变) /
   靴子战 (等对手犯错) — 可组合, 写清主战场
```

## 写作纪律

- 散文 ~1000 字; 份额/头对头结果给数字 (行业报告口径, 毛估估), 拿不到写"未获取"
- **"靠什么赢"一列是本卡灵魂**: 只写对手名字 = 没做功课; 每家一句赢法才构成地图
- 头对头证据 (临床/评测/盲测/份额拐点) 优先于定性叙述
- 换轴判定要给"旧轴 vs 新轴"的具体对照, 并显式写"这威胁护城河的哪一层" (→ 03 卡接口)
- 禁立场词; 禁"护城河很强/弱" (那是 03 卡的活, 本卡只摆战况)

## 附录锚点 (机器层)

```
A1 利润池排位: #N (按利润)
A2 战争类型: {份额/价格/换轴/靴子} 主战场 = {X}
A3 换轴威胁: {有/无; 旧轴→新轴一句话; 威胁护城河哪层}
A4 头对头证据: {最近一次可比数据结果}
A5 红旗: {0-2 条}
A6 证伪信号: {份额/头对头指标+阈值+裁决日}
```

## 搜索弹药库 (实战沉淀, 持续迭代)

> 纪律: 每轮至少追问一层; 空结果 = 换词重试

```
排位轮:
  "{company} vs {peers} revenue ranking" — 按利润不按收入, 口径要交叉 (AWX 教训: TPV≠收入)
  上市同层的市值/收入即排位侧证; 私有同层看最新融资估值 (Caplight 口径)
竞对赢法轮:
  "{competitor} strategy win how" / 行业媒体 "X vs Y" 对比稿
  卖方降级/升级报告的标题即立场信号 (TTD 实例: HSBC "代理 fallout" 式标题)
换轴识别轮:
  "who is disrupting {company}"
  WSJ/FT "Fall From ..." / "worst performing" 专题稿 (TTD 实例: $69B 摔落一文 = 路线对赌全叙事)
  同层对手走势分岔 = 同池不同命的信号 (TTD/Magnite 分岔)
官司即信号轮:
  竞对起诉监管 = 蛋糕重排进行中 (COIN 实例: CME 诉 CFTC)
  竞对间的客户诉讼/审计 = 关系重排 (TTD 实例: Publicis 开战/审计)
二级侧证轮:
  供应链对手的财报电话会提不提它 (TTD 实例: PubMatic "某大 DSP 缩支")
已验证无效:
  精确份额数字常常搜不到 — 用排位+侧证链代替, 严禁编数
```

## 追问规则 (本卡)

- "靠什么赢"每家一句必须来自对手动作的报道, 不能来自我概括
- 分岔走势 (它跌同层涨) 必须追问分岔原因, 不解释就标"未获取"
