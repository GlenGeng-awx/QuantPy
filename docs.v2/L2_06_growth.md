## §3 三档构造 (LLM 直接给 — 每档 = 源 × L1 证据的合成, 可验算)

**三档硬约束 (防自由发揥 — 每一条都是确定性锚)**:

1. **基准档必须锚定显式数字源**: 基准 g 不是拍的, 是选锚算的 — 锚 = 最可信的显式换算 (FY+1 指引换 EPS 增速 / 留源中位数 / 共识近端 三选一, 给理由), 写进构造格。
2. **熊/牛 = 基准 ± 具体变量**: 熊 = 基准 − 镜头最大威胁兑现的量化 (如 "量斜率折断到 +12%" + "价让位 GM trough 持久"); 牛 = 基准 + 最强驱动全额传导的量化 — 每个档距必须能翻译成 "哪个变量兑现多少", 禁凭感觉拉档距。
3. **路径法强制**: 每档给一条 5 年路径 (如 "FY27 +30% → FY28 +15% → 2029 停 → 复合 ~10%"), 禁单点 g 无路径 — 路径可验算, 单点不可。
4. 每档 2-4 条构造证据; 顺序 熊≤基准≤牛; 构造证据必须引用 L1 生意卡 (战争类型/护城河/分层结构的定性输入)。
5. 口径纪律: g 本体 = NI 口径 (回购不进 g); **①② PE 公式消费 EPS 口径\* = NI + 可持续缩股 (~2pp)** — 全额缩股 (如靠债补) 不可持续, 2pp = SBC 对冲 + 净缩 2%/yr ≈ 无债可付的回购下限; 共识的 EPS 口径通常含全额缩股, 与框架的差 = 缩股可持续性判断 (可验算)。

| 档位 | g (5yr EPS CAGR) | 5 年路径 | 构造 (锚 + 变量兑现量化) |
|------|---|------|------|
| 熊 (min) / 基准 / 牛 (max) | | | 基准行必写锚是什么; 熊/牛行写变量兑现 |

**参考行** (机械对照, 无感情锚): 留源均值列在档位表下方一行——LLM 基准与它的差必须指认来源 (定性判断/口径换算/位置判定)。
> 当参考行与基准分歧 ≥主流汴平时 (如: 参考行 68% vs 基准 20% 的 48pp 级分歧), 追加一次 **双向自诀**: 有无就业拆解能证明基准太保守 (镜头依据完整性)? 不能 → 维持; 能 → 上调并记录。

## §5 交叉验 (→ 共识-框架分歧 = L4 裁决输入)

分歧**三路处理**:
- **一致** (<3pp): 直接用, 不需处理
- **小分歧** (3-10pp): 取低者 + 单句命名差异本质 (口径换算/保守/情绪温度)
- **大分歧** (>10pp): 叙事差命名 + 挂裁决日 + 入 L4 裁决输入 (典型形态: 位置判定型一 48pp / 叙事分裂型 满分剧本 vs 均值回归) — 周期股条款保留; 街沉默型分歧 (远端无源) 卒一格处理: 写入 "悬置远端", 挂裁决日
