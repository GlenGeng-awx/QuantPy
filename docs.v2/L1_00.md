## 卡的通用纪律 (所有 L1_01-08 文件共用)

### 问题一: 立场污染 (L1 的产品是无判断白描)

- **中立白描**: 事实与各方说法并陈, 无立场词 (便宜/贵/看好/回避); 大师式判定词留给 L3
- **数字边界**: 允许生意事实 (增速/用户/绝对金额/量价/利润率), 禁现价/估值倍率/框架价

### 问题二: 证据质量 (写厚≠写满, 数字要有骨头)

- **数字取数**: web 为标准路径 (stockanalysis TTM/季度列) — 无 CSV 标的同流程可跑; CSV 仅交叉对照以新者为准; 拿不到写"未获取", 不编造
- **机械拆解强制**: 灵魂问题的数字拆到机械层 (如 "收入 +13% = 提价 ~6pp + 广告 1-2pp + 会员中个位数") — 禁只给 "量价双轮" 方向词
- **原文直引强制**: 公司原文 (letter/高管原话/10-Q 语句) 有则直引一句 — 二手转述密度天然低一层
- **搜索纪律**: 每轮至少追问一层 (标题亮点必点原文); 空结果 = 换词 ≥2 次才准写 "未获取"; 有效词沉淀回各卡弹药库

### 问题三: 可读性 (用户看的是渲染效果)

- **每卡结构**: 三段即全部, 产出 contract 见 "分卡格式" 节
- **摘要纪律**: 2-4 语义块成段, 每段一整行 ≤300 字, 总 ≤450 字; 白描味 ("护城河在变薄"可, "不行了"不可); 段内不换行 (渲染合并) / 禁一行一碎片 / 禁单巨段; 无导览行 — 句内挂卡号指路; per-stock 现场提炼, 禁模板句; 瘦身判据 = 分支细节留正文
- **密度纪律**: 每卡正文 ≥900 字 且 ≥2 段连续叙述段 (要点只进附录); 判据 = **读者不翻 L2 能凭本卡做出生意判断**
- **段落禁 merge**: 一段长不是问题, 多段压一行是问题; blockquote 语义分段处插空 `>` 行

### 量规 (尺度, 非动作)

- 总字数预算: 8 卡 × ~1000 字 + 总览 ~500 字 ≈ 8500 字/标的
- **回读指令**: 全卡读完, 拿 06 类型判定回读 03 护城河干涸时间表 (周期/转型型改写护城河读法)
- 时效: 触发即全卡组重跑 (财报/C-level/竞争格局/大额资本动作/进 L2 前必刷/距上次 ≥6 周); 分卡局部重跑仅限错别字与格式
- 执行节奏: 见 00 §0.1.5 物理计划 (搜索全量先行, 写作逐卡回证据; 九卡写作归主 agent)
