## 卡的通用纪律 (所有 L1_01-08 文件共用)

- **中立白描**: 事实与各方说法并陈, 无立场词 (便宜/贵/看好/回避); 大师式判定词留给 L3
- **数字取数 (web 为标准路径)**: L1 默认从 web 现取 (stockanalysis 财务页 TTM/季度列) — 不依赖本地 CSV, 保证无 CSV
  标的 (泡泡玛特型) 同流程可跑; 本地有 CSV 时仅作交叉对照, 以 web 新者为准; 拿不到写"未获取", 不编造
- **数字边界**: 允许生意事实 (增速/用户/绝对金额/量价/利润率), 禁现价/估值倍率/框架价
- **产出命名 (硬规则)**: 产出文件号镜像 doc 文件号且补零 — L1_00→`L1_00.md`, 01→`L1_01_industry.md` …
  08→`L1_08_challenge.md`; L2/L3 同规则
- **每卡结构**: ~1000 字散文正文 + 文末机器附录 (锚点: 红旗/证伪信号挂卡片自有议题)
- **时效 (激进版, 不为省预算)**: 触发即**全卡组重跑** (9 文件全新搜索, 旧版直接覆盖) — 触发器: 财报 / C-level 或治理事件 / 竞争格局变化 / 大额资本动作 (融资/回购/收购) / **进入全链 (跑 L2) 之前必刷** / 距上次重跑 ≥6 周 (即使无事)
- 分卡局部重跑仅用于纯错别字/格式修补 (不动搜索)

- **回读指令**: 全卡读完后, 拿 06 类型判定回读 03 护城河的干涸时间表 (周期型/转型型会改写护城河读法 — COIN/AWX 实例)
- **总字数预算**: 8 卡 × ~1000 字 + 总览 ~500 字 ≈ **8500 字/标的**
- **执行节奏 (00 §0.1.5)**: 搜索全量先行 (卡间互相咬合), 写作逐卡 — 每张落笔前回到该卡搜索证据, 禁凭记忆浇筑九卡
- **段落禁 merge 单行**: 一段长不是问题, 多段压一行是问题 — blockquote 语义分段处插空 `>` 行 (md 分段要点)

- **搜索纪律 (全卡组通用)**: ① 每轮至少追问一层 (标题亮点必点原文) ② 空结果 = 换词重试 ≥2 次才准写"未获取" ③ 每卡专属弹药库见各卡"搜索弹药库"节, **每次实战后把新挖到的有效词沉淀回库** (持续迭代) ④ 追问规则绑定在各卡
