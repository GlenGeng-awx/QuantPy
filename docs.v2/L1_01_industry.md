# 01 行业卡: 这是个什么行业

> 核心问题: 蛋糕多大? 长多快? 钱在价值链的哪一环? 周期性/监管/技术变迁速度如何?
> 
> 大师锚: 芒格"先懂行业经济学, 再谈公司"; Fisher #1 (市场空间, 否决项的一半)。

## 卡要回答的七个问题

```
1. 一句话定义: 给外行讲清这行当靠什么收钱
2. 规模与增速: 市场 TAM 多大, 过去 5 年多快, 未来驱动是什么 (渗透率/新品/替换周期)
3. 价值链利润池: 行业的总利润堆在哪一环 (品牌/渠道/制造/平台/原料)? 正在向哪一环迁移?
4. 周期性与频率: 强周期 (半导体/航运)? 弱周期 (广告)? 无周期 (水电/医药)? 需求是
   一次性 (地产) 还是复购型 (订阅/耗材)?
5. 监管与政策: 谁管? 管多紧? 当前风向 (关税/反垄断/价格管制/牌照)?
6. 技术变迁速度: 技术多久重写一次竞争规则 (慢=消费品牌, 快=AI/半导体)?
   当前有没有正在发生的"换轴" (价值从旧环节流向新环节)?
7. 行业的钱好不好赚: 行业平均利润率量级 + 头部的利润率量级 (给 05 卡做对标底)
```

## 写作纪律

- 散文 ~1000 字; 增速/利润池要给数字 (毛估估量级即可), 拿不到写"未获取"
- **价值链利润池是本卡灵魂**: "市场增长 ≠ 公司赚钱"的全部秘密在这一格 (NVO 教训: 市场双位数, 利润流向支付方; TTD 教训: 需求涨, 中间层被挤)
- 技术变迁若出现"换轴"信号 → 必须写清旧环节 vs 新环节, 这是 12 地位卡和 13 护城河卡的前置输入
- 禁现价/估值; 禁"这个行业不行/很好"式立场词 — 只摆结构与数字

## 附录锚点 (机器层)

```
A1 行业增速: __% (过去5年) / __% (未来驱动)
A2 利润池位置: {环节} → 迁移方向 {环节}
A3 周期类型: {强/弱/无/一次性}
A4 换轴信号: {有/无, 一句话}
A5 红旗 (进 L3): {0-2 条}
A6 证伪信号: {指标+阈值+裁决日}
```

## 搜索弹药库 (实战沉淀, 持续迭代)

> 纪律: 每轮至少追问一层 — 标题里有亮点 (调查/诉讼/白皮书/联名动作) 必点原文; 空结果 = 换词重试, 不等于"无数据"

```
基础轮:
  "{industry} market size growth CAGR" (TAM)
  "{industry} profit pool value chain who makes money" (利润池)
  "{industry} regulation 2026" (监管)
换轴识别轮 (本卡最值钱):
  "{technology} disruption {industry} value shift"
  "{industry} era ends / is dead / pivot" (AWX 实例: "纯加密交易所时代结束" 一文给足全行业换轴)
  大厂联名动作 = 池子迁移信号 (COIN 实例: Open USD 四巨头联盟)
调查报告轮 (一级刻度, 值得专追):
  Mastercard×Bain / McKinsey 类调查 (AWX 实例: 91% SME 两年换商)
已验证无效:
  Google News 搜行业协会动态 (IAB 类, 直接去官网)
```

## 追问规则 (本卡)

- 调查/白皮书: 必须取到 样本量/国别/时间窗 三口径, 否则降级"媒体印象"
- "XX 时代结束"式判词: 追问说话人身份 (竞对 CEO = 竞争情报; 分析师 = 观点)
