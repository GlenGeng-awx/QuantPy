## 判定规则

- 三态 per 条; **D2 不懂 / D4 不敢拿 → no-go** (双否决, 与 BF1/芒格 E1 同为 L4 否决线)
- D5 差异化是票的核心格 (Fisher 成长真实性的裁决人 — L4 裁决优先级 5)
- D6"发现错了马上改"输出一条: **当前持仓若在, 错了没有?** (持仓裁决时的灵魂问题)
