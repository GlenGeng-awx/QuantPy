# 04 生意模式卡: 怎么赚钱, 苦不苦

> 核心问题: 钱从谁的口袋、经过哪几步流到公司? 量价怎么拆? 这是不是一门苦生意?
> 
> 大师锚: 段 D1/D3 (生意模式 6:3:1 — "买股票就是买公司, 就是买其未来现金流"); 芒格 C1 (伟大/好/烂三分类)。

## 卡要回答的七个问题

```
1. 谁付钱给谁: 付费方 / 使用方 / 决策方三方拆开 (分离度 = 风险源: NVO 患者用药
   保险付钱 = 议价权在砍价方; PYPL 商户付钱采购员用 = 被代理层夹住)
2. 收入结构: 产品线各占多少 (毛估估百分比), 哪条是引擎哪条是现金牛哪条在死
3. 单位经济 (毛估估): 每单/每客户/每份的收入-变动成本; 量 × 价的驱动拆分
   (量 = 席位/用户/TPV, 价 = 抽成/单价/ARPU) — 过去靠哪个涨, 现在哪个在压力下
4. 经常性程度: 收入是订阅/耗材/一次性项目? 续费率或复购证据?
5. 苦生意判定 (芒格式三连): ①赚的钱要不要全部再投进去才能维持 (CapEx/SBC 抽血)?
   ②是靠勤劳赚 (人力密集/服务型) 还是靠资产赚 (品牌/网络收租)? ③这门生意的客户
   疼恨它吗 (SaaS 涨价被骂但留 vs 航空年年亏)?
6. 现金牛成色: 经营现金流 vs 利润的关系 (OCF/NI 比值), 现金转化是否稳定
7. 十年现金流路径 (段式提问): 能不能画出来 — 一条线讲清"今天的 $1 收入,
   十年后大概变成什么"
```

## 写作纪律

- 散文 ~1000 字; 单位经济与量价给数字 (web 现取, 毛估估量级)
- **苦生意判定是本卡灵魂** — 芒格烂生意三问逐条答, 不含糊
- 客户集中度 (前几大客户占多少) 必须答 — 拿不到写"未获取"
- 十年路径若画不出 (被专利/技术变迁/客户萎缩折断), 显式写"画不出 + 断点在哪"
  — 这是段票 D3/D4 的直接输入
- 禁立场词; 禁资本配置评级 (BF5 领地, 只摆回购/分红事实)

## 附录锚点 (机器层)

```
A1 付费/使用/决策方: {结构一句话 + 分离风险}
A2 收入结构: {引擎/现金牛/衰退 三档}
A3 量价拆分: {量驱动=X, 价驱动=Y, 当前压力端=Z}
A4 苦生意判定: {芒格三问 各 ✓/✗}
A5 客户集中度: {前N大占比/未获取}
A6 十年路径: {能画/断点在哪}
A7 红旗 + 证伪信号
```

## 搜索弹药库 (实战沉淀, 持续迭代)

> 纪律: 每轮至少追问一层; 空结果 = 换词重试

```
模式结构轮:
  "{company} business model how does it make money"
  "{company} revenue breakdown / segment mix" (10-K/财报的分部表)
  私有公司: 官方 PR 的收入里程碑句式 (AWX 实例: "年化收入 $1.3B, 90% 多产品使用" 全在 Series H PR 里)
量价拆分轮 (数字双轨 web 优先):
  stockanalysis 财务页 Revenue by Segment (COIN 实例: 消费交易/稳定币/质押分部全给)
  量与价分离: 增速差 = take rate 变化信号 (AWX 实例: TPV +120% vs 收入 +74% → 抽成在降)
  公司口径的量指标 (TPV/GMV/spend/客户数) 与收入增速的背离必算
集中度轮:
  "{company} customer concentration top customers"
  10-K 风险因子段; 拿不到写"未获取" (AWX: 无披露即标注)
订阅化进度轮:
  "{company} recurring revenue subscription mix" (转型型标的必加)
已验证无效:
  Business Model Analyst 类内容站的 SWOT 长文 (模板复述, 无独立事实)
```

## 追问规则 (本卡)

- 收入结构每条分部线必须带口径 (net/gross, 公司/审计)
- 量价背离出现时, 必须追问"价为什么变" (补贴? 结构迁移? 竞争?) — 追不到原因就挂证伪信号进 08 卡
