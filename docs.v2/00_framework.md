## §0.1.5 执行节奏 (物理计划)

> Owner: 本节; L1_00 / L2_00 / L3_00 各引一行。
> **物理计划 = 在 §0.1 (逻辑计划) 约束下的执行优化 — 隔离、效率、ctx 成本。**

### 问题一: ctx 蒸发 (主 agent 上下文 = 稀缺内存, 证据不留盘就没了)

- **dossier 落盘**: subagent 采集产物写 tmp/ 文件, 写作取材从文件读 (禁只存对话); dossier 发现必须**原文直引**, 禁主 agent 写作时凭印象补细节 (判例: NFLX Dan Lin)
- **逐文件串行, 禁浇筑**: 一张写完再写下一张 (L1_01→…/L2_01→02→…/L3_01→02→…); 浇筑 = 输出跑在证据前面, 在用已蒸发的 ctx 填槽
- **浇筑警报 (自检)**: 连续 >2 文件无新计算/新搜索 = 停, 回证据现场
- **L1 特例 (搜索全量先行, 写作逐卡回证据)**: 搜索间互相咬合须全量先行; 动笔时每卡回到该卡搜索证据 (材料已备 ≠ 卡已写)

### 问题二: 判断污染 (谁的观点混进了谁的产出)

- **L3 五票 = 架构级 subagent 隔离**: 每票全新上下文, 输入白名单 (私器+契约+18 卡), 禁读同链他票/他链 (防仿本); **主 agent 不写票** — 写过 L1/L2 的判断不得带进票; 可分批 2-3 (浏览器单实例)。详见 L3_00 §3
- **票内先提问后搜索**: 问题先于证据 = 防自污染 (先有结论后找补)
- **L1/L2 采集 subagent ≠ 隔离用途**: 纯劳动外包无污染场景 — 与 L3 的架构级是两档, 勿混

### 问题三: 时间 (无依赖的劳动在排队)

- **L1 搜索 ‖ L2 数据采集可并行**: 采集互不依赖 (L2 拿的是原始数据); 并行度按标的形态选 (全并行 / 段间串行 / 无财报标的 L2 路为空 — AWX 判例)

### 非优化项 (逻辑/交互约束, 原样保留)

- **L2 写作等 L1**: L2 第一张卡动笔前 L1_06 已落笔 (L1_06 镜头 → L2_00 镜头路由表, 是 L2_05/07/08 的输入); 采集并行 ≠ 写作并行
- **L2 生成序 = 拓扑序** (01→…→00, 依赖序见 L2_00); 每张 = checkpoint
- **用户在环 (软, 仅限分析跑链)**: 不设硬停, 逐张留插入点, 用户随时打断; 分析产物软在环 vs 用户文件硬在环 (notes.md)

## §0.2 框架不变量 (跨层/跨票仲裁 — 删掉任何一条, 两层以上或两票以上会各说各话)

> 本节只收跨层跨票条目; 单层细则与 L4 门/仓位语义归各 owner 文件。

**层间不变量**:

- **FCF − SBC < 0 → 先归因再处理** (数据在 L2_02, 处理在 L2_07, 消费在 L3_01): 投资期型 (CapEx 高但 D&A 同步) → 不打折, 强制附 CapEx 回落情景; 资本周期豪赌型 (FCF−SBC 负 + 净债升 + 回购不停) → ③ 输出 ×0.40, 不否决、总是估值; 超发型 (回购 > 核心 FCF, 净债升) → ③ + 缩股 2pp 上限注 (L2_07 §1 资本配置诊断)
- **L1/L2/L3 严格无决策**: L1 无价格无估值; L2 产数字不产判断; L3 产票只圈区间 (引 L2 格子)。安全边际/归类/建议只在 L4。
- **错杀判别 (链级部分)**: M&A 悬置 = 全链路暂停; 刀/基本面事件判据 → L2_08。

**票间不变量** (L4 仲裁时用; 否决线/两道门/仓位语义 → L4_00):

- **能力圈一票否决**: 段 D2 / 芒格 E1 / 巴菲特 BF1 任一判"不懂" → 其他仲裁不再进行。
- **生意冲突 → BF6 仲裁** (格雷厄姆票 vs 巴菲特票): 麻烦一次性 → 偏格雷厄姆票; 结构性 → 偏巴菲特票 (便宜不够, 等价格)。
- **成长冲突 → D5 仲裁** (费雪票 vs 段永平票): 差异化在 = 费雪成长可信; 差异化弱 = 费雪降档。
- **价格刻度的原料永远从 L2 取**: 五票定价区间 = 私器 × L2_07 已有格子, 禁自算新数; L4 整合五区间 → 共识带 + 离群注记。
