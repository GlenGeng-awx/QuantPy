## §0.1.5 执行节奏 (串行生成宪法)

> Owner: 本节; L1_00 / L2_00 / L3_00 各引一行。实证: 整层浇筑版 "表格对但密度薄" (SE/NFLX 重跑实感); 逐卡串行版三轮纠偏产出版式五条, 密度最高 (SE L2)。

- **逐文件串行, 禁止整层浇筑**: 产出文件一张写完再写下一张 — L1_01 → L1_02 → …; L2_01 → 02 → …; L3_01 → 02 → …。写作 = 逐张的思考单元, 不是整层倒出的填槽。
- **L1 特例 (搜索全量先行, 写作仍逐卡)**: L1 的搜索之间互相咬合 (01 行业的换轴喂 02 地位喂 03 护城河), 必须全部搜完才能动笔; 但搜索完成后**禁止凭记忆浇筑九卡** — 每张卡写作时回到该卡的搜索证据再落笔 (材料已备 ≠ 卡已写)。
- **L2 串行 = 拓扑序即生成序**: 01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 00; 每张写完是一个 checkpoint — 不强制停下等用户, 但下一张开始前 = 新一轮计算/交叉, 不是连排输出。
- **L3 逐大师 + 票内时序 (先提问后搜索)**: 每位大师 = ①我的问题 (3-5 个) → ②逐问搜索 (原始 query 照抄 + readable 发现, **散文式禁表格**) → ③独白 → ④checklist → ⑤判决块 + 尾注最想问 (须是 ② 打开的洞) → 锁定 → 下一位。五票浇筑 = 双重违规 (节奏 + 独立性: 专属搜索是票的第二支柱, 攒批执行等于抄自己)。注: §0.1 "五份可并行" 指**逻辑依赖**上互不读, 不豁免本节的生成节奏。
- **浇筑警报 (自检)**: 连续写 >2 个文件中间没有新计算/新搜索发生 = 浇筑 — 停, 回到逐张。
- **用户在环 (软)**: 不设硬停; 逐张生成天然留出插入点 (SE L2_01 三轮纠偏即此模式产物), 用户随时可打断纠偏, 生成方不等也不催。

## §0.2 硬规则 (不读 doc 也不能违反)

- **FCF − SBC < 0 → ×0.40**，不否决、总是估值（`20 §估值输入`）
- **折扣只乘在入场价（满仓）层**，不进合理价（`50 Step 3`）
- **base 四态**（回购/SBC 资本配置判定，L2_07 §1）（态 ABCD）: 态 A 标准/态 D 积累→③ 主、态 B 真缩股→⑤ 主、态 C 超发→③ 主+⑤ 乐观格；CapEx/OCF>30% → 附 CapEx 回落情景
- **DCF**：g≤3% 一阶段 Gordon；g>3% 两阶段 (N=5, g_terminal=3%；软着陆三段对照)；r 四档 = 伟大 9/好 10/平庸 11/EM 12（`L2_07 §2b`）
- **分位门 P/E + P/S 都 ≤30%** 才算便宜；derating 输入用 TTM 实绩, True → 分位标"不可信", 单口径触发 = 半触发 → "条件过"；查不到则暂停，严禁估算（`22`）
- **正常化 EPS = min(GAAP, 工具, v3.1)**，只剔收益不加回亏损；EPS 负值时用恢复 EPS（`20 §正常化`）
- **g 必须跑完全部 8 源（含 web #7+#8）**，未搜 = 未完成（`21`）
- **回购不进 g**；g 用 Revenue/NI 增长；EPS CAGR 只作背离信号（`21`）；①② PE 消费 EPS 口径\* = NI + 可持续缩股 ~2pp（净债约束下限，L2_06 §3）
- **L1/L2/L3 严格无决策**: L1 无价格无估值; L2 产数字不产判断; L3 产票只圈区间 (引 L2 格子)。安全边际/归类/建议只在 L4。
- **错杀判别**：修正动量下修中 = 刀，禁止当情绪错杀接（等 ≥4 周企稳）；M&A 悬置 = 全链路暂停；足迹 ≥半数或共识已打印伤害 = 基本面事件（`24`）
- **盲评可选前置**: gut_check 在 L1 之前锁定（新数据 + 不读 docs.v2/ai_report.v2，防锚定）；对账附录落报告尾部（`prompts/gut_check.md` 仍是 owner）
- **汇总/校验: L4 读所有五票 (L3_01-05)**

## §0.3 裁决优先级 (L4 用, 防五票扯皮 — no-go 性质拆解/否决线)

```
1. 段永平 #2 / Munger E1 (不懂/能力圈外) → 一票否决, 归类 "能力圈外", 不出手
2. Munger D1 kill 共振 (≥3 kill 同向) 或 A 域 ≥3 fail → 不出手 (归类按 50 映射)
3. Munger E2 赔率 < 0.5:1 → 弃牌 (除非 L4 触发器表显式推翻 even-if 假设)
4. Graham 票 vs Buffett 票冲突 → 看 Buffett #6 (麻烦一次性?): 一次性 → 偏 Graham 票 (折价是机会);
   结构性 → 偏 Buffett 票 (便宜不够, 等 L2 入场价)
5. Fisher 票 vs 段永平票冲突 → 段永平差异化 (§34 #7) 裁决成长真实性 (差异化在 = Fisher 成长可信)
6. 价格刻度的原料永远从 L2 取: 五票**可以圈自己的出手区间** (定价区间 = 私器 × L2_07 矩阵已有格子, 禁自算新数), L4 整合五区间 → 共识价带 + 离群注记 → L4 裁决
7. 共识强度 → 仓位语义: 5:0 满仓资格 / 4:1 小仓 / 3:2 观察 / 分裂 → 等裁决日
```

**output_3x 大师票导读模板 (4 块):**

```
## 这位大师会怎么说 (1 分钟, 无背景版)
> **{大师}是谁**: 一句话 (成就/代表作)
>
> **他最在乎什么**: 一句话 (他的筛选哲学)
> **他看完 {STOCK} 会说**: 2-4 句, 用大师的口吻说白话 — 结论 + 最核心的一两个理由
>
> **他投了**: {票向} + 一句话为什么
```

> 语气规则: 大师导读允许用大师的第一人称口吻 (叙事层); 判定行/表格保持机械。导读不引入新事实 (只能复述正文已有的证据, 换语言不换数字)。
> **导读数字边界** (与 L1 无价格纪律一致): 导读/小作文可用**生意事实**（用户数/增速/绝对现金规模）、**事件数字**（收购报价/裁员数）、定性方向；**禁**现价、估值倍率（P/E/yield/回本年限）、框架价（合理价/满仓价）——那些属于 2c/2d/5 层。output_3x 的大师口吻允许引用其票内已算的数字，但不引价格刻度。
