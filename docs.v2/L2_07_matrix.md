## §1 资本配置诊断 (③ 的 base 恒为 FCF-SBC; 本节只诊健康度, 不路由公式)

| 形态 | 信号 | 语义 |
|------|------|------|
| 对冲型 | 回购 ≈ SBC (±20%), 股数平 | SBC 维持成本由利润自担 — 基准健康 |
| 真缩股型 | 回购 > SBC 且 回购 ≤ FCF (净债不升) | ①② 消费口径的 +2pp 缩股可全额兑现 |
| 超发型 | 回购 > SBC 且净债升 (回购缺口靠债填补) | 缩股 2pp 上限 (债补不可永续); 00 §0.2 三岔口输入 |
| 积累型 | 回购 ≈ 0 | SBC 对冲没人接; FCF 去向是投资 — 检查 ①② 的 +2pp 假设 |

> 停火变体: 回购曾 > SBC 但已停 → 稀释转正预警。
> 折扣归属: 折扣系数全链归 L3 费雪票 (本卡只出公共原料与公式)。

## §3 方法矩阵 (全部公式的定义与原理)

**骨架: 3 个基础函数 → ③ 内部分段路由 → 输入变体层 → 后处理。**

### 基础公式 (4 个, 编号即族)

**① Graham PE**: `V = EPS × (8.5 + g)`
- 原理: 零增长公司的合理 PE ≈ 8.5 (格雷厄姆经验锚); 增长每 +1pp, 市场愿多付 1x。保守计价 g 一次。
- 分段: g<0 → PE 封底 8.5 (负增长不再惩罚); EPS≤0 → 弃格。

**② Fisher PE**: `V = EPS × (8.5 + 2g)`
- 原理: 优质成长的溢价翻倍计——增长可信度高时市场给双倍乘数。g>15 外推警告, g>30 乱来区 (仅作**出场参考**, 不作入场锚)。

**③ DCF-FCF-SBC** (两阶段为默认形态): `V = Σ₅ F(1+g1)ᵗ/(1+r)ᵗ + TV/(1+r)⁵ + net_cash`, F = FCF-SBC/sh
- 原理: SBC 是股东的维持成本 (不发新股就得付现金留人) → FCF-SBC 才是股东真实可支配现金流。三态四态里"标准/积累"的世界。

### ③ 的分段路由 (按 g 量级自适应 — 复杂度只花在必要处)

| g 量级 | 支 | 形态 |
|--------|-----|------|
| 全期 g ≤ 3% | Gordon 一阶段 | V = F/(r−g) + net_cash |
| 3% < g ≤ ~30%, 驼峰明确 | 三段软化 (解析式 = 模板化路径) | 5年g → 5年g/2 → 永续3% |
| g > ~30% (高成长档) | 逐年路径直折 (唯一强制展开) | L2_06 §4 逐年 5g 逐笔折现; g1 匀速版仅作对照格 |

> 低 g 路径化是浪费 (拆 5 个 3% 还是 3%); 高 g 不路径化是失真 (牛档 g1 外推 -29%)。
>
> g1 匀速表保留为矩阵主表 (全档一数可竖读); 直折列只在 >30% 档强制, 其余档双格差异 <10% 可省略。
>
> 阈值 ~30% 为软边界 — 判据是路径形状不只量级 (g 40% 但路径平直 → 仍可解析式; 25% 但驼峰陡 → 仍可直折)。

- **FCF-SBC < 0 → 先归因 (00 §0.2 三岔口, 判定数据来自 L2_02)**: 投资期型 (CapEx 高但 D&A 同步) → 不打折, 强制附 CapEx 回落情景 (变体行);
  资本周期豪赌型 (FCF−SBC 负 + 净债升 + 回购不停) → ③ 输出 × 0.40 (打六折仍列, 不否决)。

## §4 gap 诊断 (三法分歧的模式表)

| gap 模式 | 原因 | 诊断 | 更可信 |
|----------|------|------|--------|
| 全接近 | 三法互证 | 置信高 | — |
| ①② > ③ | CapEx/WC 吃现金流 | 利润≠现金 | ③ |
| ② > ③ | 稀释 | 回购对冲失败 | ③ |
| ①② < ③ | 过度剥离 | 一次性判定过头 | ①② |
| 分位大 (derating) | E-peak 失真 | 分位不可信 | ③ |
| 周期峰值 | 峰值 EPS | 中周期/情景行 | 变体行 |
| FCF 负 | 资本周期 | 先归因三岔口 (§3 后处理; 00 §0.2) | ③ |

> 防双扣条款 (SBC 非现金机制) 保留: ③ 已扣 SBC 的格子不再叠加 SBC 折扣。

**直折校验表 (必跑 — 两法都算, 形态结论在本卡出)**: 直折 = L2_06 §4 逐年路径 × 本卡 F/r (逐年现金流逐笔折现 + 终值挂第 5 年实际值 — 零失真主算法); g1 匀速 = 矩阵便利近似。

每档一行 (g1 值 / 直折值 / 差值 / 形态判读): 差 <10% 同意; ≥10% 形状极端信直折 — 矩阵保 g1 版但出场区/诊断列带校验警告 (高 g 外推失真可达 -29% 量级)。
