# 08 挑战卡: 未来 2-3 个季度最要命的事

> 核心问题: 短期最大挑战是什么 + 什么事件/数据会裁决它 (L1 唯一带时间维的卡)。
> 
> 大师锚: 无大师条目直接对应 — 本卡是 L1 证伪体系的收口 (Fisher "暂时性 vs 永久性" 的时钟)。

## 卡要回答的五个问题

```
1. 最大挑战排序 (1-3 件): 未来 2-3 季度最要命的事, 按杀伤力排序 —
   每件写清: 挑战是什么 / 如果恶化会怎样 / 如果解决会怎样
2. 裁决日历: 每个挑战的裁决事件 + 日期 (财报/监管决定/产品发布/合同到期/
   竞对数据) — 汇总成总表, 最近的排最前
3. 证伪信号总表 (卡组的收口): 从 11-17 各卡收集所有证伪信号, 统一登记
   (判断 → 信号+阈值 → 裁决日 → 结果回填列) — L1 的全部可跟踪假设在这张表
4. 基本情形叙事: 不悲不喜的那条路 — 接下来两季"正常发挥"长什么样
   (给 L4 情景表 (§5 触发器) 的基准档预填)
5. **这生意怎么死** (芒格逆向, 曝露清单的升级形态): 三条最短死法路径, 每条写
   "起点事件 → 传导链 → 死于什么" (ORCL: OpenAI 融资断裂 → RPO 悬空 → 债市拒收
   → 死于资产负债表而非生意)。宏观/行业单点并入路径, 不单列
```

## 写作纪律

- 散文 ~800 字 + 裁决日历表 + 证伪总表 (表是本卡主体, 散文是导语)
- **证伪信号必须带阈值** ("Q3 GM < 76%" 而不是 "毛利率恶化") — 不可证伪的信号不收
- 裁决日历是全卡组唯一强制更新的时间维: 每个裁决日过后回填结果
  (✗ 未证伪 = 置信+1 / ✓ 证伪 = 标记重跑)
- 暴露清单不判断概率, 只画传导链

## 附录锚点 (机器层)

```
A1 挑战排序: {1/2/3 + 各自的恶化/解决情形}
A2 裁决日历: {日期 + 事件 + 裁哪条信号} — 按时间排序
A3 证伪信号总表: {各卡收集, 统一编号}
A4 基本情形: {两季基准叙事一句话}
A5 这生意怎么死: {路径1/2/3, 各含起点→传导链→死因} — 散文段落, 不用 code 块
```

## 搜索弹药库 (收口卡, 以日历核对为主)

```
日历轮:
  "{company} next earnings date" — stockanalysis 概览页直接读 (比新闻快)
  监管/诉讼的裁决日期: 追涉事方新闻的时间线 (AWX 实例: AUSTRAC 审计无日期 → 标"滚动悬置")
催化剂轮:
  "{company} upcoming catalyst risk"
  卖方目标价调整潮 = 预期位置的侧证 (TTD 实例: UBS $16→$15 = 预期已压低)
死法清单轮 (A5 升级后必做):
  每条死法路径的"起点事件"必须对应一个可观察信号 (有信号才有死法, 没有就是空想)
汇总轮:
  01-07 各卡的证伪信号在此收口 — 逐条带阈值, 不可证伪的信号退回原卡重写
```

## 追问规则 (本卡)

- 裁决日历每个日期必须有来源 (IR 官宣/监管文件/事件日期), 推测日期标"待确认"
- 挑战排序 (1/2/3) 的依据是"杀伤力×时间距离", 写一句话理由, 不只排序号
