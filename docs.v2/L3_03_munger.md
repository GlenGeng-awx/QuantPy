## 判定规则

- 三态 per 条; **A 域 ≥3 fail 或 D1 熊共振 → 票 = no-go** (L4 裁决优先级 2)
- B 域不进计分 (自审产出 = 偏差清单, 交给 L4b 做外部攻防的预备)
- C1 三分类 + C2 可预测性 = 票的核心叙事格

```

|----|-----|
| 票 | go / no-go / conditional |
```
