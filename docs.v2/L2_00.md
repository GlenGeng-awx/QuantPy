### 硬纪律: L3 禁止只读收口卡

> **阅读范围 = L1/L2 全部分卡通读**; **分发清单只定引用权重 (侧重哪些卡), 不是阅读边界** — 票头"必读页"是侧重声明不是窄门。具体证据/算式/处置理由都在分卡; 数字一屏供人扫但 L3 引用必须指向分卡页。

## 可读性版式 (所有 L2 卡适用; 十五条)

1. **先说结论**: 每卡 2-3 句, 最重要的发现放第一屏
2. **全表给绝对数**: 趋势表 ~13 行含 $ 原值; 分析基于表后追问
3. **短句**: 论点。证据。含义。三口气; 禁 120 字嵌套四层
4. **机器标签进附录**: `→喂:` 统一文末 (grep 不受影响, 正文零机械码)
5. **推断标注来源**: 行业量级非公司披露 → "行业印象" 或去伪精度
6. **计算透明**: 拆解/比值给原始数与算式 (22.9/32.0=0.72×); 口径敏感给区间不给单点
7. **30 秒导航**: 结论后一行节导览 (主菜/流水)
8. **常规件不可缺**: EBITDA / FCF bridge / Goodwill 检查 — 查过无风险也显式写
9. **缺口显式**: L1 声明的量 CSV 无数据 → "未获取", 不沉默跳过
10. **格式法定 / insight 自由 (原则)**: 三表卡各有法定骨架, 锁死且锁序, 漏行=未完成 (具体行清单在各卡 doc — 01 八行/L2_01, 02 bridge/L2_02, 03 快照/L2_03); 自由行与全部判断 = LLM 发挥区 — 格式错是"错", insight 平庸是"可改进"
11. **三表卡 insights 配额 + 位置**: L2_01/02/03 每卡至少挖 **3 个 readable insights** — 一句人话点破数字背后的机制 (谁在付钱/什么在吃利润/哪条曲线在拐), 附算式或数字对照; 挖不足 3 个 = 该卡未完成。**位置 = 跟随发现地点**: 每条 insight 挂在其证据来源节的表格后, 无独立标题 — 用节内加粗首句引段 (`> **insight (n/3): …**`), 每条独立成段 (引段间空行), 编号 n/3 供配额 grep; 禁打包堆尾 (病机: 破案离了证据现场)。
12. **形状列禁裸箭头**: 必须带数字或一句话 (↑ +3.0pp)
13. **数据进表不进散文**: ≥2 个数值的序列/对照一律表格 (含判读列)
14. **一数一 cell (全表适用)**: 每档参数独立成列成行 (| g | r9 | r10 | … 式; NI 与 NM% 拆行同理), 禁复合 cell ("29.8 / 48.8%") — 复合 cell 不可竖读不可比, 退化为散文
15. **blockquote 语义段分行 (全库总规, 三次同病教学后抽象化)**: 任何 blockquote 内, 两个 `> **X**:` 语义段头之间必插空 `>` 行 (连续 > 行 = md 同段渲染, 空 > 行才是分段) — 适用于 doc 层与产出层全部文件; 分段粒度 = 语义大段不是句子 (引文内部连续 > 行 = 段内软换行, 不插空); 引号跨行首尾各一次

## 层间纪律

- **执行节奏 (00 §0.1.5)**: L2 串行 = 拓扑序即生成序 (01→02→…→08→00), 每张写完是 checkpoint, 禁一次性浇筑八卡

- **L2 与 L3 分界**: 度量衡+透明判断 vs 投票+私器; L2 的判断 (处置/构造/审计) 全部"给理由+可验算", 不产 go/no-go
- **现价污染隔离**: 现价只出现在 L2_08 (锚定审计); 01-07 grep 现价 = 0 (00 一屏为容忍态需声明)
- **判例回写机制**: 每张实跑卡完成后问一次 "doc 需要回写吗" (判例/版式/结构槽位三类候选)
- **工具哲学**: 工具只做取数 (download) 和报警 (health); 判断归 LLM
