## 可读性版式 (所有 L2 卡适用)

### 问题一: 报表读不动 (信息埋在数字堆里)

- **先说结论**: 3-5 段, 每段一整行 ≤~200 字 (L1 同款); 每段 = 一个发现 (结论句 → 数字证据 → 一句含义); §指针每段最多 1 个挂段尾, 数字进主句不进括号; 不设导览行; per-stock 特别发现融进结论段
- **短句**: 论点。证据。含义。三口气; 禁 120 字嵌套四层
- **数据进表不进散文**: ≥2 个数值的序列/对照一律表格 (含判读列)

### 问题二: 报表验不了 (数字没骨头, 读者只能信不能查)

- **全表给绝对数**: 趋势表 ~13 行含 $ 原值; 分析基于表后追问
- **计算透明**: 拆解/比值给原始数与算式 (22.9/32.0=0.72×); 口径敏感给区间不给单点
- **推断标注来源**: 行业量级非公司披露 → "行业印象" 或去伪精度
- **形状列禁裸箭头**: 必须带数字或一句话 (↑ +3.0pp)
- **一数一 cell**: 每档参数独立成列成行 (| g | r9 | r10 | … 式; NI 与 NM% 拆行同理), 禁复合 cell ("29.8 / 48.8%") — 复合 cell 不可竖读不可比, 退化为散文

### 问题三: 结构不完备 (缺了不知道缺 — 层门/下游都查不出)

- **常规件不可缺**: EBITDA / FCF bridge / Goodwill 检查 — 查过无风险也显式写
- **缺口显式**: L1 声明的量 CSV 无数据 → "未获取", 不沉默跳过
- **格式法定 / insight 自由**: 三表卡法定骨架锁死锁序, 漏行 = 未完成 (行清单在各卡 doc: L2_01 八行 / L2_02 bridge / L2_03 快照); 自由行与判断 = LLM 发挥区 — 格式错是"错", insight 平庸是"可改进"
- **三表卡 insights 配额 + 位置**: L2_01/02/03 每卡 ≥3 个 readable insights (一句人话点破机制, 附算式); 位置 = 跟随发现地点 (证据来源节表格后, `> **insight (n/3): …**` 引段, 段间空行, 编号供 grep); 禁打包堆尾 — 破案离了证据现场
- **引段通用律**: 引段内独立论断之间空 `>` 行 (连续 `>` 行渲染成一整段); 唯一合法连排 = 同语义标签组 (如 L2_07 范围协议 "下限/上限/中间" 三行同属一个语义)
- **机器标签进附录**: `→喂:` 统一文末 (正文零机械码, grep 不受影响)


## 层间纪律

- **执行节奏**: 见 00 §0.1.5 物理计划 (L2 写作等 L1; 拓扑序即生成序; 采集可 subagent, 九卡写作归主 agent)

- **L2 与 L3 分界**: 度量衡+透明判断 vs 投票+私器; L2 的判断 (处置/构造/审计) 全部"给理由+可验算", 不产 go/no-go
- **现价污染隔离**: 现价只出现在 L2_08 (锚定审计); 01-07 grep 现价 = 0 (00 一屏为容忍态需声明)
- **判例回写机制**: 每张实跑卡完成后问一次 "doc 需要回写吗" (判例/版式/结构槽位三类候选)
- **工具哲学**: 工具只做取数/报警/格式化, 判断归 LLM (工具清单见 CLAUDE.md)
