# 06 类型卡: 这是一门什么类型的生意

> 核心问题: 红利/成长/周期/现金牛/转型 — 业务类型归类, 决定 L2 用哪套估值镜头。
> 
> 大师锚: 格雷厄姆《聪明的投资者》第 14/15 章 (防御型 vs 进取型的不同选股标准 — 类型决定标准)。

## 卡要回答的五个问题

```
1. 类型判定 (可组合, 写主类型 + 次类型):
   - 现金牛型: 低增长 + 高 FCF + 回购/分红 (ADBE/PYPL)
   - 成长型: 双位数增长, 利润再投 (早期 TTD)
   - 周期型: 利润率随供需大幅摆动 (MU/存储; 周期股用中周期 EPS 而不是峰值 EPS 估值)
   - 红利型: 稳定分红 + 低增长 + 高收益 (电信/公用事业)
   - 转型型: 旧业务在死, 新业务在建, 报表混合 (ORCL: 数据库现金牛 + AI 算力扩张;
     NVO: 专利悬崖前重注)
   - 价值陷阱候选型: 低估值 + 生意在结构性恶化 (便宜是症状不是机会)
2. 判定证据: 哪三个数字支撑这个归类 (增速量级 / FCF 转化 / 利润率摆动幅度)?
3. 类型稳定性: 这个归类是稳态还是切换中 (转型型 = 正在切换)? 切到什么?
   什么信号确认切换完成?
4. 对 L2 的镜头指令 (本卡输出, 机器消费):
   - 周期型 → 提醒 L2 用中周期 EPS (§5.4 fallback), 分位法失效风险
   - 现金牛型 → FCF yield / 股东回报覆盖是第一镜头
   - 成长型 → 两阶段 DCF + PEG 的陷阱提示
   - 转型型 → 分部口径 (SOTP 思维提醒, 如 PYPL "三块生意")
   - 红利型 → 股息覆盖 + 净债纪律第一
5. 历史类型回放: 它过去 10 年是什么类型? 类型变过几次? (类型稳定的生意,
   定性结论可以外推; 类型频变的生意, 一切结论的保质期短)
```

## 写作纪律

- 散文可以短 (本卡 600-800 字 — 判定 + 证据 + 镜头指令, 不需要展开叙事)
- **类型判定本身是中性描述** (转型不是贬义, 周期不是缺陷), 立场词仍禁
- "价值陷阱候选"是唯一接近立场的一格 — 必须挂三重证据 (低倍数 + 结构恶化证据 + 修复路径存疑), 且最终判定权在 L3/L4, 本卡只贴警示标签
- 镜头指令写给 L2 grep (机器层是本卡主要产出)

## 附录锚点 (机器层)

```
A1 主类型+次类型: {X + Y}
A2 支撑数字: {三件套}

```
