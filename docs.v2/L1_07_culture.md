# 07 文化卡: 管理层本分吗

> 核心问题: 企业文化一瞥 + 管理层诚信实证 + 治理事件史。
> 
> 大师锚: 段 D6 ("本分 = 不骗人, 不占便宜, 发现错了马上改"); Fisher #15 (诚信, 否决项) / #14 (坦白) / #8 (高管); 巴菲特 BF8 (理性/坦诚/抵制惯性 — 1987 信)。

## 卡要回答的六个问题

```
1. 创始人与接班: 创始人还在吗? 几岁了? 接班安排了吗? 职业经理人 vs 创始人
   帝国的差别 (Ellison 型 vs ADBE 交棒型); 所有权结构 (基金会/家族/双层股权)
2. 诚信实证 (本卡灵魂, 否决级证据): SEC/DOJ/欺诈/财务重述/举报人事件史 —
   逐件列时间线, 无则明写"专门搜过, 无结果" (空白即证据)
3. 坦白史: 坏消息怎么披露的? 指引兑现率 (beat 为主还是 miss+削为主)?
   有没有把结构性恶化包装成"暂时性逆风"的前科 (Fisher #14 fail 形态)
4. 股东友好的证据链: 回购/分红/发股史 — 是创造型回购 (低价回购缩股) 还是
   护盘型/兑现型 (高价回购 + 内部人同步减持)? 内部人交易方向 (近 90 天)
5. 员工口碑侧写: Glassdoor/Blind 评分量级; 裁员史 (幅度/频度/方式 — 周一到
   周五邮件型 vs 体面型); 高管流失密度; 拿不到写"未获取" (侧写代替)
6. 关键人风险: 公司命运与某个人的判断力/年龄/政治关系深度绑定的程度
   (结构型三例: ORCL-Ellison = 创始人×政治/资本关系绑 (危险面: 质押+并购豪赌);
   NVDA-Jensen = 创始人×技术判断绑 (危险面: 年度 cadence 赌注+无接班, 叙事/客户/技术三合一);
   ADBE-Chakravarthy = 正常交接)
```

## 写作纪律

- 散文 ~1000 字; **诚信实证必须"搜过且写明结果"** — Fisher #15 是否决项, 本卡的空白比内容更重要
- 治理事件只白描时间线, 不判"好文化/坏文化" (判定归 L3)
- 内部人减持要区分: 离任窗口的程序性减持 (Narayen $31.5M) vs 业绩前的异常减持 — 写事实与语境, 判断留给票
- 员工口碑是弱证据层 (Glassdoor 自选择偏差), 标注"侧写"级

## 附录锚点 (机器层)

```
A1 治理结构: {创始人/接班/所有权}
A2 诚信事件表: {逐件 or "搜过无结果"}
A3 指引兑现: {beat为主/miss+削为主}
A4 股东友好: {回购型态 + 内部人方向}
A5 员工侧写: {评分/裁员史/流失密度 or 未获取}
A6 关键人风险: {无/轻度/结构性}
A7 红旗 + 证伪信号 (治理事件类, 挂滚动裁决)
```

## 搜索协议

```
"{company} SEC investigation lawsuit fraud" (诚信, 必搜)
"{company} CFO CEO departure turnover" (必搜, Fisher #8)
口碑三层 (⚠ 不用 Google News 搜评分 — 它不索引 Glassdoor/Blind, "无结果"是工具错位不是无数据):
  ① Glassdoor 直达: glassdoor.com 站内搜索 → Overview 页 (总评分/推荐率/CEO 支持率, 通常免登录)
  ② Indeed 兜底: indeed.com/cmp/{company}/reviews (分项评分 + 最新评语)
  ③ Blind/团队口碑: 登录墙内, 标"未获取"并留给 scuttlebutt 清单
"{company} insider selling buying" (内部人)
```

## 追问规则 (本卡)

- 诚信事件表的每件都要拿到: 时间 / 指控方 / 现状 (进行中/和解/驳回/定罪) — 三缺一降级
- 高管离职必追问: 谁接任 + 何时生效 + 前任去向 (离职旧闻 ≠ 当前状态)
- 留任补助/金手铐 = 官方承认的留人风险, 金额和股数分开记 (TTD 实例: 246K RSU 是 24.6 万股)
- 起诉书类 (SEC/集体诉讼): 找原文转述 (Law360/FXNewsGroup 级), 标题党降级

## scuttlebutt 清单 (费雪闲聊法, 留给能打电话的人)

> 媒体转述是二手闲聊; 本节显式列出"如果能打三个电话, 问谁、问什么" — 一级信息缺口留给用户。
> **榨干证明规则**: 每问必须配一行 [榨干注] — 公开代理已到哪 / 剩哪格是结构性不公开。清单的语义 = "公开信息的边界在哪" (搜索跑完的残差反推成人话问题), 不是"待办" — 无榨干注的问题 = 偷懒没搜, 退回重跑。

```
问谁 1 (客户侧): {该行业的一个真实买家/媒介采购员}
  Q: 你们今年实际预算挪去哪了? 换平台的最后一次评估是什么时候、为什么没换/换了?
  [榨干注: {公开代理已到哪} / {剩哪格结构性不公开}]
问谁 2 (前员工侧): {Glassdoor 差评里可触达的离职者/LinkedIn 前同事}
  Q: 走的人去哪了? 走之前看到的最真实的内部信号是什么?
  [榨干注: ...]
问谁 3 (供应链侧): {上游供应商/合作伙伴 (SSP/出版商/代理)}
  Q: 跟它打交道比跟别人打交道, 钱和体验上差在哪?
  [榨干注: ...]
```
