# Task F: 恐惧体积检验 (错杀判别)

> **产出**: 恐惧体积 (隐含 g vs 趋势 g) + 修正动量 + 足迹计数 + even-if 赔率 + 恐惧分类 (情绪错杀/基本面事件/刀/M&A 悬置) + 截止日历。
>
> **定位**: 测量引擎 (同 Task 4/5 — 产 flag 不产操作)。**执行序: 5 → F → E** (触发式; 文件号 09 ≠ 执行序, F = Fear)。
>
> **触发** (非全量, 命中才跑):
> ① **拟建仓**: EOD 现价 < 合理价 或 ≤ 入场价 × 1.1 (击球区候选)
> ② **持仓裁决**: 加仓/退出评估前 ("手里的是刀还是错杀", TTD 型)
> ③ 用户指定
>
> **依赖**: output_1 (正常化 EPS + 5 季趋势 + 回购) + output_2 (调整 g) + output_5 (熊档/基准 ①) + EOD 现价 + web (共识修正 + 新闻足迹, **必带**)
>
> **output_f.md 结构 = 本文档节序 (§9.0→§9.6); 各 § 节的表格式即 output 格式, 不另设模板。**

## §9.0 前置门 (不满足则 F 暂停)

| 门 | 检查 | 不满足 → |
|---|---|---|
| 事件门 | M&A 悬置: 要约在桌 / 出售谈判 / 激进股东推动分拆 (news 近 2 周) | **全链路暂停** — 估值对象已变质 (spread/破裂 = merger arb, 框架外) |
| 数据门 | output_1/2/5 齐全 + EOD + forecast 页可取 | 暂停 (严禁估算) |

> PYPL 教训 (2026-09): $60.50 要约后 "错杀" 命题不复存在 — F 的对象是市场情绪, 不是交易对手报价。

## §9.1 Step 1: 恐惧体积 (隐含 g vs 趋势 g) + 修正动量

```
隐含 g (trailing) = 现价 ÷ 正常化 EPS − 8.5      # Graham 反推
隐含 g (forward)  = 现价 ÷ 共识 FY+1 EPS − 8.5
恐惧体积 = 趋势 g (output_2 调整 g) ÷ 隐含 g
修正动量 = FY+1 共识估计方向: 上修 / 企稳 (≥4 周无净下修 或 上修>下修) / 下修中
```

| 项 | 值 | 来源 |
|---|---|---|
| 隐含 g (trailing) | ...% | EOD ÷ output_1 正常化 EPS |
| 隐含 g (forward) | ...% | EOD ÷ 共识 FY+1 EPS (forecast 页) |
| 趋势 g | ...% | output_2 调整 g |
| 恐惧体积 | ...× | 趋势 ÷ 隐含 (trailing 口径) |
| 修正动量 | 上修/企稳/下修中 | forecast 页 (评级趋势 6mo + 近 30d PT 动作 + FY+1 估计方向) |

- 隐含 g 是**度量衡, 不是机制假设** (市场并不真用 8.5+g 定价; 它只是把恐惧翻译成倍数的语言)
- 隐含 g ≤ 0 (P/E < 8.5) → 体积记 "∞ (极端恐惧)", 不中止
- forward/trailing 断层 > 2x → 标注 (ORCL 型: 断层本身是信息 — 承诺 vs 已到手)
- **刀判别 (硬规则): 修正动量 = 下修中 → 缺口在收敛 (恐惧无体积可赚) → 分类 "刀", 等 ≥4 周企稳再跑 F**
  (PYPL 1/30: $57 机械便宜 + 估计下修中 → 5 个月 -25%)

## §9.2 Step 2: 足迹检查 (恐惧有无实体)

```
恐惧叙事 → 应留下的数据足迹 (output_1 5 季趋势 + web):
  收入类: ARR/Rev 增速减速? 订阅/用户流失?
  利润类: GM/OpM 连降? 定价压力?
  份额类: 竞品份额/替代品渗透拐头?
  现金类: FCF/OCF 转弱? (TCOM 型口径分裂: NI 缩 + FCF 稳 = 足迹减半)
足迹数 = 有 / 应有
零足迹 + 叙事推迟到"下一季" → 不可证伪叙事 → 情绪错杀候选
≥ 半数足迹 或 共识已打印伤害 → 基本面事件 (非错杀; TTD: FY26e OpInc -57% 已在共识)
```

## §9.3 Step 3: even-if 下行 + 赔率

```
恐惧兑现价 = 正常化 EPS × (8.5 + 恐惧 g)    # 恐惧 g 从叙事翻译, 必须写明逻辑 (如 "ARR 归零" → g≈0-3%)
框架熊价 = output_5 熊档 ①                  # 机械参照 (可能不够极端, 双列)
下行 = min(恐惧兑现价, 框架熊价) vs 现价
上行 = 基准 ① (output_5) vs 现价
赔率 = 上行 ÷ 下行
深度分档: 深 (下行 ≤10% 或 赔率 ≥4:1) / 中 (下行 ≤20% 或 赔率 ≥2:1) / 浅 (其余)
```

| 情形 | 价格 | vs 现价 |
|---|---|---|
| 恐惧 100% 兑现 (恐惧 g ...%) | $... | -...% |
| 框架熊档 ① | $... | ...% |
| 基准 ① | $... | +...% |
| 赔率 | ...:1 | |

> 诚实条款: even-if 只测 "恐惧若对, 亏多少" — **不证明恐惧错** (Nokia 反例: 被颠覆前数字也好看)。F 输出的是赔率结构, 不是真相判定。

## §9.6 恐惧分类 + 总结 (→ Task E 快速消费)

| 恐惧分类 | 判定条件 | → Task E 输入 |
|---|---|---|
| **情绪错杀 (深/中/浅)** | 体积 ≥1.5× + 足迹 ≤1 + 修正企稳/上修 + 有截止日 | 入场信号强化: 深 → 满仓资格候选; 中/浅 → 小仓/CSP |
