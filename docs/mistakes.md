## 〇 最高频五大错误（先默念）

这五条覆盖了超过七成的真实错误，每次分析前先在脑子里过一遍。括号内为两轮复查的命中标的数。

1. **安全边际符号** — `安全边际 = 1 − 现价/合理价`。（命中 4+：PDD / 0700.HK / TME / NVDA）
   - 现价 **<** 合理价 → 必为**正**（便宜）
   - 现价 **>** 合理价 → 才为**负**（贵）
   - "买贵了"仅当 现价 > 合理价。**绝不允许现价低于合理价却写负号。**

2. **现价联动刷新** — 头部价格/日期一改，所有派生量必须同步重算：P/E、EV/EBITDA、MCap、FCF yield、净现金%、P/B、敏感性表、快照表。现价漂移 >3-5% 触发 A+D 全刷。（命中 6+：TTD / ADBE / MU / TME / 0700.HK / NVDA）

3. **伟大 + 无麻烦 → ×1.0（主表无麻烦列，不是 ×0.75）** — `discount_coefficient.md` 主表第一列：伟大+无麻烦 = ×1.0 → 满仓目标 = 合理价（巴菲特"合理价买伟大公司"，合理价三重保守即边际，无需额外折扣）。**连框架官方范例 NVDA 都被误套了 ×0.75**，AAPL/MSFT/GOOG/AMZN 全犯。D.1 出现"伟大 × 无麻烦 ×0.75"即报错。（命中 5：AAPL / MSFT / GOOG / NVDA / AMZN）

4. **3yr CAGR 不许用 YoY 或 2yr 顶替** — 必须用 `(Value[0]/Value[N])^(1/year_gap)−1`，PRINT header 验证 year_gap（col2 常仅 2 年前非 3 年前，详见 `forward_g.md`）。常见错：把当年 YoY 标成"3yr CAGR"，或把 2yr CAGR（^1/2）当 3yr。（命中 6：AAPL / MSFT / GOOG / META / TSLA / NVDA）

5. **迁移即重做，不许 stub** — 写 `output_*.md` = 实跑 ABCDE 流程，不是抄旧 base 结论 + 一句话 stub。章节必须按 `docs/output_format.md` 齐备。典型 stub：A 只有 A.1 无 A.2/A.3；D 缺 D.2/D.3/D.4/D.5 + 写"B/C 详见 base（未迁移）"——但 output_b/c 实际已存在，属假声明。（命中 6+：0700.HK / PDD / CPNG / SPCX / AAPL / MSFT / GOOG / AMZN / TSLA / NVDA）

## 一、数学算错（最常见，约 16 处）

### 通用规律

- **安全边际符号反复反**：把"现价 < 合理价"误当"贵/负"。PDD、0700.HK、TME 三只都犯。
- **百分比手算误差**：满仓/合理价的上下行百分比不与 D.2 公式 reconcile，导致正文与表格、快照互相矛盾。
- **TTM 口径比率用旧年度值**：SBC/Rev、NM 等比率抄旧 base 年度序列，未按 TTM 现算。
- **汇率混用**：CNY→USD 换算同一文件出现 6.8 / 7.1 / 6.69 多个 FX，USD 数字相互对不上。
- **评分不逐项数**：质量评分笼统写"6/6"，实际逐项数只有 5/6。

### 精选案例

**PDD `output_d.md:6`** — 现价 $88.60 < 合理价 $178.53，安全边际写"−50%"，实际 `1 − 88.60/178.53 = +50.4%`。符号反，且把"便宜"误归"买贵了"。

**TCOM `output_d.md:110-112`** — D.7 快照表三行安全边际全错：Jul26 标 +15% 实算 +7.8%、Aug1 标 +13% 实算 +20.7%（同价同合理价的 Aug1 与 Jul6 给出 13% vs 21% 两个值）。

**COIN `output_b.md:29`** — SBC/Rev 写 13.7%，实算 939/6282 = 15.0%。13.7% 抄自旧 base 年度序列（25.1→13.9→11.7），未按 TTM 重算。

**TCOM `output_b.md:56`** — FCF−SBC = ¥11.31B，换算写 $1.58B，实算 ÷6.8 = $1.66B（疑似混用 7.15 汇率）。同文件 B.6 又正确写 $1.66B，自相矛盾。

## 二、框架硬规则违反（约 9 处，最严重）

### 通用规律

- **合理价 EPS 必须 = min(GAAP, tool, v3.1)**：不许取 tool/GAAP 上界、不许加回收购摊销、不许用"业主盈利中枢"替代。加回非现金项只能作 D.5 软估算补充列示。
- **合理 PE = min(8.5+g, 30)**：禁止用废弃的 `8.5+2g` 旧公式。
- **折扣只在满仓目标层，不进合理价**。
- **FCF − SBC < 0 → 重麻烦 → ×0.40**：必查 `cf_ttm.csv`，不许"无法确认/数据不足"搪塞。**已算出 <0 但以"capex 主动投入/OCF 强"为由不打 ×0.40 = 仍违规**。
- **5 年估值分位 ≤30%**：查不到则暂停，严禁自算估算；>30% 不得标好价格 ✓。

### 精选案例

**CRM `output_d.md:76-83`** — 合理价取 $200（业主盈利中枢 EPS $10.94，加回收购摊销 $3.77B after-tax），非框架 `min($8.63, $7.77, $7.77) = $7.77`。框架合理价应为 $7.77×18.5 = **$144**（非 $200），满仓目标 $86（非 $120）。加回 recurring 摊销违反"三重保守"+ 折扣不进合理价。结论从"买贵了"滑向"小仓"。

**PDD `output_d.md:3`** — g=5% 的合理 PE 用 `8.5+2g = 18.5x`，违反硬规则 `min(8.5+5, 30) = 13.5x`。合理价 $9.65×18.5=$178 严重高估，应为 ~$130。base.md 自己承认"沿用旧敏感表 8.5+2g"——迁移到 output_d 时未更正。

**SPCX `output_d.md:14`** — FCF−SBC 写"无法确认（数据不足）"，实查 `cf_ttm.csv`：FCF=−$19.78B、SBC=$2.35B → **−$22.13B << 0**，应标重麻烦 ×0.40 却漏判。

**AMZN `output_d.md:9,13-15`（已查未判变体）** — FCF−SBC 实算 −$30.9B（报告写 −$22.28B 仍<0）→ 应标重麻烦 ×0.40，但报告未打折扣，仍跑 `min(8.5+g,30)=22.5x` 完整估值 + 归类"买贵了"。承认"成长估值资格存疑"却未落实 ×0.40。与 SPCX 同类不同变体（SPCX 是"没查"，AMZN 是"查了跳过"）。

**TME `output_d.md:14`** — 正常化 EPS 取 GAAP $0.84（上界），框架 `min = $0.645`（tool）。论据是 TTM CSV 的 Total Unusual Items ¥2.508B 被年报数据渗透（已验证），但 `normalize_eps.md` 仅许可"标假阳性 + v3.1 过度保守"补偿路径，未许可直接取 GAAP 上界。合理价 $13.86 vs 框架 $10.64（+30% 乐观偏差）。

## 三、跨文件一致性（约 18 处，最多）

### 通用规律

- **B 的 EPS 必须 = D 的 EPS**、**C 的 g 必须 = D 的 g**、**B 质量评分 = D 质量评分**。
- **A 的 P/E 用的 EPS 必须 = B 的 GAAP EPS**，差异 >3% 须注明 screen vs CSV 口径。
- **同文件内部不许矛盾**：D 内 D.1 三要素 = D.2 锚 = D.5 质量判定；E 内 E.3 安全边际 = 1 − A.1 现价 / D.合理价。
- **现价只在 A 里**：B/C/D 不含 price，不受现价漂移影响。价格漂移只刷 A。
- **汇总表排序时旧行系数不回退**：升档后旧日期行应保持旧系数 + 标注。

### 精选案例

**ADBE `output_d.md:79 vs 83`** — D.5 好价格行写 FCF yield 9.7%，同文件 D.5 质量判定行写 11.5%，output_b 亦写 11.5%。8-01 实算 10.28/99.54 = 10.3%，三个值都不同且自相矛盾。

**MU `output_d.md:80 vs 117`** — 同文件同日（8-01）同价（$823），D.4 body 写 P/E 18.6x，D.7 快照写 19.8x。body 用 CSV GAAP EPS $44.24，快照用 info.json trailingEps $41.65，EPS 口径混用。

**TTD `output_a.md:2 vs 11/29`** — 头部标"现价 $18.04（8-01）"，但 A.1 表与 D.3 敏感性表全用 $17.29（7-27）。P/E 应为 20.5x 非表中所写 19.6x；EV 交叉验用 MCap $8.13B 而非头部 $8.48B。价改表未改。

**CRM `output_b:127 vs output_d:39`** — B 写本地评分 6/6，D 写机械 6/7。若本地 6/6 + 护城河 1 = 7/7，非 6/7。两文件对同一评分数字矛盾（B 算错，D 隐式用了正确值 5/6）。

## 四、偷懒/占位符（约 15 处）

### 通用规律

- **迁移即重做，不许 stub**：A/B/C 每个文件按 `output_format.md` 章节齐备（A: A.1 八项表 + A.2 区间表 + 同业表 + de-rating；B: B.1-B.6；C: C.1-C.6）。仅列结论数字 + "详见 analysis.base.md（未迁移）"= 占位，不算迁移完成。**注意：output_b/c 已存在时再写"B/C 详见 base（未迁移）"= 假声明。**
- **B.2 与 B.3 必须同一 TTM 戳**：迁移时常只更新 `income_ttm`（利润表）却整段照抄旧 base 的 `cf_ttm`（现金流），导致同文件两表差 $6–22B。income 与 cf 同日戳必须同批重算。
- **FCF−SBC<0 的标也需完整文件**：CPNG/SPCX/AMZN 因 FCF−SBC<0 后省略 B.2/B.4/A.2，违反模板。不再有"框架外"——总是估值（×0.40），章节必须齐全。
- **来源必须带具体 URL**："web"/"旧分析"/"估算"不算来源。同业对比不许抄旧快照。
- **B.5 EPS Chain 四行齐备**：GAAP/工具/v3.1/FINAL，工具行尤其不可省——它与 GAAP 方向相反时正是 min() 要防的信号。
- **A.1 粗筛 8 项全列**：N/A 须标原因（"亏损致 P/E N/A" ≠ "EV/EBITDA N/A"）。

### 精选案例

**0700.HK / PDD** — A/B/C 均为 4-8 行 stub，无表无推导无 URL，末行"详见 analysis.base.md（未迁移）"。PDD A.1 "2/8（P/E ✓ + P/S ✓）...至少 3/8。`CLAUDE.md` 规定"完成 ABCDE 后写 output_*.md 即完成迁移"——这批 stub 名实不副。

**COIN `output_b.md:35-39`** — B.5 EPS Chain 缺"工具"行。实算工具 EPS = +$1.88（Normalized Income $526M / 280M 股），与 GAAP −$3.87 方向相反——正是 min() 要防的"加回亏损"信号，被隐藏。

**MSFT `output_b.md:46-48`（B.2/B.3 不同步）** — B.2 利润表已更新到 Q4 FY26（营收 $331.84B ✓），但 B.3 现金流整段抄旧 base 的 Q3 TTM：CapEx 写 $97.22B（CSV $115.95B，**少报 $19B**）、OCF $170.14B（CSV $182.94B）。AAPL/GOOG/AMZN 同型全犯（GOOG CapEx 少报 $22B 且回购多报 $13B）。income 与 cf 同日戳必须同批重算。

**SPCX `output_b.md` 全文** — 仅 B.1/B.5/B.6，缺 B.2 利润表逐季、B.3 现金流、B.4 资产负债表。B.3 尤其关键——FCF−SBC 是重麻烦 ×0.40 判定的核心硬规则证据（见二）。

## 五、编造数据（约 18 处）

### 通用规律

- **数字一律回查 CSV 实算**：GM 取 `income_ttm.csv` GrossProfit/Total Revenue；SBC/Rev 取 TTM SBC/TTM Revenue；1Y low 取 252 日 close 的 `min()`。不许靠记忆。
- **季度 CSV 最新季利润表字段空白（仅 EPS/股数更新）时**：Rev/OpInc/NI/OtherInc 从 TTM 反推（TTM − 前三季），不许抄上一季 + 标 ~ 猜测。CSV 有值则不许标 ~。
- **快照现价按日期取 price CSV close**：禁用区间内高点（ATH）顶替某日收盘。ATH 属于其真实发生日期，不许张冠李戴到快照行日期。
- **detector 列表必须 print(norm_eps) 验证**：区分"触发"vs"实际进 total_adj"，不可手抄/猜。low/负值 detector 也列全（不影响 v3.1 但违反完整列表要求）。
- **CAGR 必须用公式 `(Value[0]/Value[N])^(1/year_gap)−1`（PRINT header 验证 N）**：YoY ≠ 3yr CAGR，2yr CAGR（^1/2）≠ 3yr CAGR，标错口径就是编造。注意 `forward_g.md` 公式"列2=3年前"与 CSV 实际列号可能偏移，须 print 验证。
- **NM 用 NI/Revenue**：不可用 OpInc/Revenue（那是 OpM）顶替。
- **同业 P/E 用当日收盘价 ÷ TTM EPS 实算**：不许抄不明快照。
- **股数注明口径**：TTM 加权 vs 期末，不许取无来源的中间值。

### 精选案例

**SPCX `output_b.md:27`** — detector 列表写"2a OtherInc + 2b Restructuring + 2c TaxAnomaly"，实跑 `normalize_eps.py` 触发 6 个（2a/2b/2c/2d/2f/2x），其中 **2f RDSpike（+4.73B）才是 v3.1 主驱动**，报告漏列 2d/2f/2x 且把不剥离的 2a/2b/2c 当主因。未实跑脚本，手抄/猜列表。

**AAPL / MSFT / GOOG `output_c.md:10-12`（CAGR 实为 YoY，6 只复发）** — 三行"3yr CAGR"实为当年 YoY。AAPL 营收看 6.4%（实算 3yr CAGR 2.77%）、MSFT 营收看 17.8%（实算 10.58%）、GOOG 营收看 15.1%（实算 9.4%）。端点写 col0/col2、结果却填 col0/col1 YoY。META（22.2% 实为 2yr ^1/2）、TSLA（营收 ~3% 实为 −0.7% 且符号错）、NVDA（~100% 实为 52.5%，且 `forward_g.md` 自带 NVDA 范例即标 52.5% 直接打脸）同型。属五·line 134 在 megacap 上系统性复发。

**NVDA `output_d.md:29`（用 ATH 充当某日收盘）** — D.7 7-04 行写"现价 ~$235"，但 price CSV 实查 2026-07-02 收盘 $194.83；$235.47 的 1Y 高点实际发生在 2026-05-14。把 5-14 的 ATH 套到 7-04 日期上，导致 P/E ~36x、安全边际 −35% 全建在错误现价上（真实 7-04 应 P/E 29.8x、安全边际 −12%）。

**AMZN `output_b.md:33 + output_c.md:13`（季度 CSV 空白 → 抄猜）** — income_quarterly.csv 的 Q2'26 利润表字段空白（仅 EPS/股数有值），报告 B.2 把 Q2'26 整行抄成 Q1'26（Rev=$181.52B 与 Q1 完全相同 copy-paste）+ NI 标"~33B"猜测。但 NI 与自报 TTM EPS $12.43（→NI $135.28B）自相矛盾（若 Q2'26 NI=$33B 则 TTM NI 仅 $105.6B→EPS $9.71）。正确应从 TTM 反推 Q2'26 差额（NI≈$62.7B）。

**PDD `output_b.md:6`** — GM 写"65%"，CSV 实算 TTM GM = 247.654B/442.403B = **56.0%**。65% 高于 60% 阈值会误判质量评分。65 与 56 易位，未回查 CSV。

**TCOM `output_c.md:7`** — 3yr CAGR 写 17%，框架公式 `(62.409/44.510)^(1/3)−1 = 11.9%`。17% 实为 FY25 YoY（62.409/53.294−1 = 17.1%），被误标为 3yr CAGR。

**CRM `output_a.md:38`** — 同业对比表 ORCL P/E 标 32x。实际 ORCL @ Jul28 $119.96 / GAAP EPS $5.83 = 20.6x。32x 不匹配任何 ORCL P/E 口径。

## 六、拼写/格式（约 3 处）

### 通用规律

- **缩股趋势用 past→present 箭头**：`471M→414M（−12.1%）`，不许写反成 414→471（读作增长，与 −12.1% 矛盾）。
- **归类必须用框架四档词汇**：最佳买点 / 价值陷阱 / 买贵了 / 结构性恶化。旧 colloquial 写法（"质优深价值"）不进新文件。
- **管理层年龄按出生年月 × 分析日期实算**：不许靠印象。

### 精选案例

**ADBE `output_b.md:107`** — 真缩股写"414M→471M（3yr −12.1%）"，箭头方向反。应"471M→414M"。当前写法读作增长，与 −12.1% 自相矛盾。

**TME `output_d.md:100`** — 归类写"质优深价值，满仓线附近"——非框架四档之一。应按 `task_d.md` D.5 归"最佳买点"或"买贵了"。

**CRM `output_c.md:61`** — CEO Benioff 写 60 岁，实际 2026-07 时 61 岁（生于 1964-09-25）。

## 七、框架细微违规（约 18 处）

### 通用规律

- **GM 阈值 >60% 是硬线**：`discount_coefficient.md` 写"GM >60% 且 3yr 不下滑 +1"。GM 在涨但未到 60% 仍为 ✗，不可把"GM 在改善"当通过。
- **伟大 + 无麻烦 → ×1.0**（主表无麻烦列，不是 ×0.75）。连官方范例 NVDA 都被误套 ×0.75，迁移任何 megacap 前先查主表第一列。
- **周期股默认用 `min(8.5+g,30)`，仅 EPS 波动大/为负时 fall back**：`task_a.md`/`forward_g.md` 已改——`EPS × (8.5+g)` 是通用公式，batches.md 标"周期"不自动触发切换。仅当 EPS 跨周期摆动大（峰谷 >2x）或为负时才 fall back 到中周期正常化 P/E + P/B 分位。EPS 稳定正的周期股（如 TSM）用标准公式 + 敏感性表覆盖周期风险。不许"头部贴周期标签 + 正文照套 `min(8.5+g,30)`"并存——要么不标周期（用标准公式），要么标了且确实 fall back（用中周期口径）。
- **麻烦定性看结构非事件**：永久行为约束/监管约束（如 take rate 永久受压）属"存疑"非"一般"。"事件落地" ≠ "麻烦降级"，要看 GM/FCF 是否结构性恶化。
- **分位用框架公式 `(当前−低)/(高−低)`**：不许用自算分布百分位替代；若 COVID 扭曲需换方法，须注明 + 补 web 源 URL。
- **回撤口径统一**：`(1Y_high − current)/1Y_high`（peak-to-current），全标的一致，不许用 peak-to-trough 抬高。
- **亏损股 v3.1 ≠ min 展示**：算法在亏损时可能比 GAAP 更负（R&D spike 被当收益剥离 + 负税率放大），应标"v3.1 算法失效，取 GAAP 兜底"或"公式不适用"。
- **CAGR 列号**：`forward_g.md` 指定 PRINT header 验证 year_gap，不许盲目锁 col2 或 col3。注意公式"列2=3年前"与 CSV 实际列号可能偏移（col2 常仅 2 年前），须 print 验证。

## 八、通用教训

按 A-F 六组归类，每条带编号，便于逐条核对。

### A. 迁移纪律

1. 写 `output_*.md` = 实跑 ABCDE，**不许抄旧 base 结论 + stub**。章节按 `output_format.md` 齐备。
2. 迁移时必须重算而非照抄——废弃公式（8.5+2g）、旧价、旧汇率都在旧文件里，抄进来 = 继承错误。
3. 修正历史数值错误时，在 output 文件中显式标注"原 X → Y（重算）"，不静默修正。

### B. 计算纪律

4. **合理价/满仓/安全边际三件套一步算**：`合理价 = min_EPS × min(8.5+g,30)`，`满仓 = 合理价 × 系数`，`安全边际 = 1 − 现价/合理价`。不拆步、不用中间值。
5. **现价 < 合理价 → 安全边际为正**。现价 > 合理价 → 才为负。符号必须对。
6. **快照表每行安全边际 = 该行现价 ÷ 该行合理价**，不许跨行混用；现价按日期取 price CSV close，禁用区间高点顶替。
7. **TTM 口径比率用 TTM 现算**：SBC/Rev、NM、FCF yield 都用 TTM 分子/TTM 分母，不抄年度序列。
8. **全报告统一一个 FX**：CNY→USD 换算一处定义，全文引用。

### C. 数据纪律

9. **数字回查 CSV**：GM、SBC、EPS、股数、净现金（Total Debt 含租赁）一律取 CSV 字段实算，不靠记忆。
10. **detector 实跑 `normalize_eps.py`**：print(norm_eps) 验证触发列表，区分"触发" vs "实际剥离"，low/负值 detector 也列全。
11. **CAGR 用框架公式 `(Value[0]/Value[N])^(1/year_gap)−1`**（PRINT header 验证 N）；YoY、2yr CAGR（^1/2）与 3yr CAGR 不可混标。注意公式"列2=3年前"与 CSV 实际列号可能偏移，须 print 验证。
12. **NM = NI/Revenue**，OpM = OpInc/Revenue，不可互替。
13. **同业 P/E = 当日收盘价 ÷ TTM EPS 实算**，注明来源 URL。
14. **季度 CSV 最新季利润表字段空白时**：Rev/OpInc/NI/OtherInc 从 TTM 反推（TTM − 前三季），不许抄上一季 + 标 ~ 猜测；CSV 有值则不许标 ~。

### D. 一致性纪律

15. **B 的 EPS = D 的 EPS，C 的 g = D 的 g，B 评分 = D 评分**——汇总前交叉核对。
16. **同文件内部不许矛盾**：D.1 三要素 = D.5 质量判定 = D.2 锚，三处数字必须一致。
17. **现价漂移 >3-5% 触发 A 全刷**：P/E、EV/EBITDA、MCap、FCF yield、安全边际重算。D 不动（price 无关）。lazy update 规则见 `output_format.md`。
18. **A 的 P/E 的 EPS = B 的 GAAP EPS**，差异 >3% 须注明 screen vs CSV 口径。
19. **B.2 利润表与 B.3 现金流同一 TTM 戳**：迁移时常只更 `income_ttm` 抄旧 `cf_ttm`，两表差 $6–22B。income 与 cf 同日戳必须同批重算。

### E. 框架边界纪律

20. **FCF−SBC<0 的标也要完整文件**：不再有"框架外"——总是估值（×0.40），B/C/D 章节仍按模板齐全，可用简化但不省略。
21. **亏损股**：EPS 负值时用恢复 EPS（详见 normalize_eps.md EPS-4b），不用 v3.1 兜底。
22. **周期股默认用 `min(8.5+g,30)`**——`EPS×(8.5+g)` 是通用公式，batches.md 标"周期"不自动触发切换。仅当 EPS 波动大/为负时 fall back 到中周期正常化 P/E + P/B 分位。EPS 稳定正的周期股用标准公式 + 敏感性表。不许贴周期标签又照套公式——要么不标（用标准公式），要么标了且确实 fall back。
23. **麻烦定性看结构非事件**：永久约束/监管压 take rate 属"存疑"，"事件落地" ≠ "麻烦降级"。
24. **归类用框架四档词汇**：最佳买点 / 价值陷阱 / 买贵了 / 结构性恶化。旧 colloquial 词汇不进新文件。
25. **伟大 + 无麻烦 → ×1.0**（主表无麻烦列，不是 ×0.75）。迁移 megacap 前先查 `discount_coefficient.md` 主表第一列——连官方范例 NVDA 都被误套过。
26. **price 不漏进 B/C/D**：D 是 price 无关的锚（合理价/满仓/系数/质量判定）; 安全边际 = 1 − A.现价/D.合理价, 只在 E.3。D.2 不含现价/安全边际/操作建议。B/C 不含任何 price 数据。违反 = price 污染锚层, 日频刷新时 D 不该动却动了。

### F. 自检纪律

26. **写完后回头读一遍**：E.3 安全边际 + D 合理价/满仓 + B EPS + C g 必须自洽。现价、EPS、g、系数、合理价、满仓、安全边际七数链式可推。
27. **半年报公司（0700.HK/PDD）detector 2a 必须半年报复查**：季度 CSV 多数为零 → vol_ratio 虚高 = 假阳性，需显式说明并改用 tool EPS 或 SOTP 补偿，不可直接取 GAAP 上界。
