# 输出格式：per-stock task 文件

> 每个 stock 的分析结果按 ABCD 四任务拆分到独立文件。

## 目录结构

```
ai_report/{STOCK}/
├── output_a.md    价格粗筛 + 估值分位
├── output_b.md    财务健康 + 正常化 EPS
├── output_c.md    增长前瞻 + 护城河 + 管理层 + 消息面 + 熊牛
└── output_d.md    估值汇聚 + 安全边际 + 仓位定档
```

跨标的对比存 `ai_report/comparison.{YYYY-MM-DD}.md`。

## 设计原则

1. **最小化变更**：只改动的 task 文件更新，其余不动
2. **checklist 可追溯**：每个文件按对应 checklist 展开，每步打勾，数据来源标明
3. **可 reconcile**：下次分析时读 task 文件即可复盘上次怎么算的
4. **并行写无冲突**：不同 agent 写不同 task 文件

## lazy 更新规则

| 事件 | 改 | 不改 |
|------|-----|------|
| 价格漂移（trivial） | 全不动 | — |
| 价格稳稳跨档（>3-5%） | output_a（粗筛）+ output_d（安全边际/定档） | B、C |
| 财报发布 | output_b + output_c（g）+ output_d（合理价重算）+ output_a（P/E 可能变） | — |
| 消息面 non-trivial | output_c | A、B、D |
| 无变化 | 全不动 | — |

## 工作频率

| 频率 | 触发 | 改动范围 | 不动 |
|------|------|---------|------|
| 日 | 每交易日 / 价格检查 | **A**（price/P/E/EV/EBITDA/FCF yield/安全边际 from CSV + D 锚） | B, C, D |
| 周 | 消息面扫描 | C.4 消息面（+C.1 g 若变化 → D 合理价重算） | A, B |
| 月/财报后 | 财报 / 彻底分析 | B + C + D + A.2 分位 | — |

### 日级别铁律（防止偷懒）

1. 读 `stock_data/{STOCK}_1d.csv` 取最新收盘价（不用记忆/估算）
2. 从 output_d 读合理价和满仓（不重算，D 是低频锚）
3. 安全边际 = 1 − 现价/合理价，写在 A.3
4. 价格漂移 >3-5% → 额外刷 A.1 粗筛（P/E/EV/EBITDA/FCF yield）
5. **不动**: output_b, output_c, output_d

## 跨标的对比 / 汇总

存 `ai_report/comparison.{YYYY-MM-DD}.md`（全部标的汇总）或 `ai_report/comparison.indices.{date}.md`（指数/商品）。
现价取 price 文件时点，注明会变动。

> **汇总 = join A(price) + D(锚)**：现价/PE/FCF yield from A，合理价/满仓/系数 from D，安全边际/操作建议现算。

### ① 主表（全部标的，join A + D）

| 标的 | 现价(A) | GAAP P/E(A) | 正常化 P/E(A) | g(D) | 合理价(D) | 安全边际(join) | 系数(D) | 满仓(D) | 操作建议(join) |

- **join 逻辑**：A 提供现价/P/E/FCF yield（daily），D 提供合理价/满仓/系数/质量判定（low-freq）。安全边际 = 1 − A.现价 / D.合理价，操作建议 = f(安全边际, D.满仓)
- **排序**：先按操作建议（满仓 > 小仓/待催化 > 买贵了），档位内再按安全边际降序
- **GAAP P/E** = 现价 ÷ TTM EPS（A.1 粗筛）；**正常化 P/E = 现价 ÷ 正常化 EPS**（from B，现价现算）
- **亏损股**：GAAP P/E = N/A，正常化 P/E 用恢复 EPS 算（标注"恢复"），系数 ×0.40（FCF−SBC<0）
- 两列都必给，两者背离要显式呈现（见 ③）
- g = 前瞻可持续增速；合理 PE = min(8.5+g, 30)
- 安全边际数字硬度不齐时，给软估算标注（如"~+25%·恢复 EPS 口径"）
- 利润分叉/低谷（PDD、BABA 类）给区间，不强凑单值
- 多币种标明币种，勿与 USD 标的直接比绝对价

### ② 特殊档（公式不适用：银行/周期股）

| 标的 | 现价 | 口径 | 锚 / 买点 | 结论 |

- 银行（JPM/BAC/GS/MS/NU）→ P/B 不用 EPS
- 周期股 → 中周期正常化 P/E + P/B 分位
- > 亏损股不再进特殊档——用恢复 EPS 进主表（×0.40 系数）

### ③ 背离方向

屏幕 P/E 低估贵（一次性收益垫高利润 → 正常化后更贵）vs 高估贵（低谷/低基数利润 → 正常化后更便宜）。基本无背离者一并点明。

| 标的 | GAAP P/E | 正常化 P/E | 背离方向 |
|------|---------|-----------|---------|
| {STOCK} | {值} | {值} | {低估贵/高估贵/无} |

### 指数/商品（框架外）

存 `ai_report/comparison.indices.{date}.md`。

- **股指 ETF**（QQQ/VOO/SOXX/KWEB/沪深300 等）：公允 P/E 带 + 10 年分位 / CAPE + 盈利收益率 vs 国债 + 股息率。红利看股息率 vs 国债利差；成长/周期指数用 P/B 分位
- **黄金/白银/BTC**：无现金流 = 框架失效，不产出合理价。标宏观对冲仓 + 仓位纪律（金银 ≤5-10%、BTC ≤3-5% 且视作可归零）
