# 输出格式：per-stock task 文件

> 每个 stock 的分析结果按 ABCDE 五任务拆分到独立文件。

## 目录结构

```
ai_report/{STOCK}/
├── output_a.md    价格层（daily）— 粗筛 8 项 + 双分位
├── output_b.md    财务健康 + 正常化 EPS
├── output_c.md    增长前瞻 + 护城河 + 管理层 + 消息面 + 熊牛
├── output_d.md    估值锚（low-freq）— 合理价 + 满仓 + 折扣 + DCF
└── output_e.md    决策（daily）— join A(price) + D(anchor) → 安全边际 + 操作 + 归类
```

跨标的对比存 `ai_report/comparison.{YYYY-MM-DD}.md`。

## 设计原则

1. **最小化变更**：只改动的 task 文件更新，其余不动
2. **checklist 可追溯**：每个文件按对应 checklist 展开，每步打勾，数据来源标明
3. **可 reconcile**：下次分析时读 task 文件即可复盘上次怎么算的
4. **并行写无冲突**：不同 agent 写不同 task 文件

## lazy 更新规则

| 事件 | 改 | 不改 |
|------|-----|------|
| 价格漂移（trivial） | 全不动 | — |
| 价格稳稳跨档（>3-5%） | output_a（粗筛）+ output_e（安全边际/操作） | B、C、D |
| 财报发布 | output_b + output_c（g）+ output_d（合理价重算）+ output_a（P/E 可能变）+ output_e | — |
| 消息面 non-trivial | output_c → output_d（若 g/麻烦变）→ output_e | A、B |
| 无变化 | 全不动 | — |

## 工作频率

| 频率 | 触发 | 改动范围 | 不动 |
|------|------|---------|------|
| 日 | 每交易日 / 价格检查 | **A**（price/粗筛）+ **E**（安全边际/操作 from A price + D 锚） | B, C, D |
| 周 | 消息面扫描 | C.4 消息面（+C.1 g 若变化 → D 合理价重算 → E） | A, B |
| 月/财报后 | 财报 / 彻底分析 | B + C + D + A.2 分位 + E | — |

### 日级别铁律（防止偷懒）

1. 读 `stock_data/{STOCK}_1d.csv` 取最新收盘价（不用记忆/估算）
2. 从 output_d 读合理价和满仓（不重算，D 是低频锚）
3. 安全边际 = 1 − 现价/合理价，写在 **output_e**（不在 A/D）
4. 价格漂移 >3-5% → 额外刷 A.1 粗筛（P/E/EV/EBITDA/FCF yield）→ E
5. **不动**: output_b, output_c, output_d

## 跨标的对比 / 汇总

存 `ai_report/comparison.{YYYY-MM-DD}.md`（全部标的汇总）或 `ai_report/comparison.indices.{date}.md`（指数/商品）。
现价取 price 文件时点，注明会变动。

> **汇总 = read E**：E 聚合 A(信号/price) + D(锚/DCF) + 计算决策（安全边际/操作/归类）。gen_comparison 只读 E，不重算 join。

### ① 主表（全部标的，read E）

| 标的 | 现价(A) | GAAP P/E(A) | 正常化 P/E(A) | g(D) | 合理价(D) | 安全边际(join) | 系数(D) | 满仓(D) | 操作建议(join) |

- **gen_comparison 只读 E**：E 聚合 A(信号/price/分位) + D(锚/DCF) + 计算决策（安全边际/操作/归类），gen_comparison 纯格式化 + 排序，不重算 join
- **排序**：先按操作建议（满仓 > 小仓/待催化 > 买贵了），档位内再按安全边际降序
- **GAAP P/E** = 现价 ÷ TTM EPS（A.1 粗筛）；**正常化 P/E = 现价 ÷ 正常化 EPS**（from B，现价现算）
- **亏损股**：GAAP P/E = N/A，正常化 P/E 用恢复 EPS 算（标注"恢复"），系数 ×0.40（FCF−SBC<0）
- 两列都必给，两者背离要显式呈现（见 ③）
- g = 前瞻可持续增速；合理 PE = min(8.5+g, 30)
- 安全边际数字硬度不齐时，给软估算标注（如"~+25%·恢复 EPS 口径"）
- 利润分叉/低谷（PDD、BABA 类）给区间，不强凑单值
- 多币种标明币种，勿与 USD 标的直接比绝对价
