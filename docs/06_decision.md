## §6.1 BS 生存力 + 估值能力判断 + 选可信方法 + 入场价/出场价 + 安全边际

### Step 1: BS 生存力 + 估值能力判断

**BS 生存力:**

| 条件 | 值 | ✓/✗ |
|------|-----|-----|
| 利息覆盖 > 5x | (val) | ✓/✗ |
| FCF-SBC > 0 | (val) | ✓/✗ |
| 净现金 > 0 | (val) | ✓/✗ |

> 高净债但利息覆盖 > 10x + FCF-SBC 持续正 → 豁免通过
> BS 脆弱 → 需要折扣保护 + 仓位控制

**估值能力判断 (读 output_1 EPS/FCF-SBC + output_2 g + output_3 质量档):**

按顺序判定, 命中即停 (先看是否例外, 再分能力圈外 vs 价值陷阱):

| 顺序 | 条件 | 判定 | 操作 |
|------|------|------|------|
| 1 | EPS > 0 AND FCF-SBC > 0 | **能** | 正常估值 + 入场 |
| 2 | g > 20% AND FCF-SBC ≤ 0 | 能 (Path B P/S) | 用 P/S 估值 |
| 3 | EPS ≤ 0 AND FCF-SBC ≤ 0 AND 质量 ≤5/10 PASS (平庸) | **价值陷阱** | 不出手 (×0.40 仍估值, 但 flag) |
| 4 | EPS ≤ 0 AND FCF-SBC ≤ 0 (其余) | **能力圈外** | 不出手 (×0.40 仍估值, 但 flag) |

> 旧 "Fisher < 8" 语义 = 质量维度 ≤5/10 PASS (平庸档)。质量是分母 (公司差 + 不赚钱 = 陷阱); g 是例外门 (亏损 hypergrowth 用 P/S, 如 TTD 类)
> 能力圈外 vs 价值陷阱: 都是 EPS≤0 + FCF-SBC≤0; 区别在质量 — 差公司亏损 = 陷阱 (市场可能还在抄底), 好公司亏损 = 圈外 (等它盈利再看)

### Step 3: 定入场价/出场价 (用可信方法)

**为何分叉判据 = 回购 vs SBC**

SBC 是真实股东成本, 但买单方式有两种, 在财报里的可见度完全不同:

| | 回购 > SBC | 回购 ≤ SBC |
|---|-----------|-----------|
| 谁买单 | 现金 (回购买回增发股) | 稀释 (没人买回增发股) |
| 股数 4yr | 缩 (如 ADBE -14.7%) | 胀 (如 PLTR +25%) |
| 当前 per-share 口径 | 天然保守 → **EPS 可信** (①②) | 虚高 (成本藏在未来分母) → **必须用 ⑦** (显式扣 SBC) |

> 本质: 回购 vs SBC = **分母收缩/膨胀的 proxy**; 确认信号 = §1.4 股数趋势 (单年 TTM 回购有择时性, 3-4yr 股数趋势更稳)

**⚠ 护栏: 回购 > SBC 但回购 ≥ FCF 的 80%**

借钱/吃老本回购 (ADBE 89%, TTD 115%) → "SBC 已对冲"的前提不牢:
FCF 一停滞, 稀释立刻显形 → 标注"**回购可持续性风险**", 进 §6.5 关键风险 (不换路径)

```
if 回购 > SBC (EPS 路径):
    入场价 = ①Graham (可信的) × 折扣系数 (output_5)
    出场价 = ②Fisher (可信的)
elif 回购 ≤ SBC (DCF 路径):
    入场价 = ⑦DCF FCF-SBC (可信的) × 折扣系数 (output_5)
    出场价 = ⑧DCF FCF (可信的)

if CapEx/OCF > 30%: 回到 EPS 路径 (DCF 低估)
if ④⑤⑥ 不可信 (derating/gap): 不用作入场/出场, 仅作参考
若路径主方法 ⚠ 不可信 → fallback: 用并列参考方法 × 折扣定入场, 标注"降级口径" + 置信度低
```

### Step 4: 安全边际 + 操作

```

```

| 现价位置 | 操作 |

| ≤ 入场价 | 分批建仓 |

## §6.3 入场策略 (A/B/C/D)

LLM 根据标的特征推荐策略:

### 策略 A: 正股 + PP (价值型 / 确定性高)

```
结构: Long 正股 + 2m ATM PP (protected put)
适用: g < 12%, 或 预期反弹 <15%, 确定性高
优点: delta=1, 无 hurdle, 横盘可 roll put 继续等
缺点: 全额资本, 仓位受限 (2-3 个)
max loss: PP premium 3-5%
break-even: 现价 + premium
```

### 策略 B: OTM Call (成长型 / 杠杆型)

```
结构: Long 3m 5% OTM call
适用: g > 12%, 预期反弹 >15%, crash 后高弹性
优点: 仅 premium 本金 (3-5%), 可同时下 10+, 杠杆放大
缺点: 5% hurdle, theta 衰减, 到期失效
max loss: call premium 3-5%
break-even: 现价 + 5% + premium
```

### 策略 C: CSP (收入型 / 等待型)

```
C1 ATM CSP:
  适用: 高确信 + 想在现价买入 + IV 高
  premium: 3-5%/月
  被行权: 现价买入 (减 premium) → 持有正股 → 转 A

C2 OTM CSP:
  适用: 中等确信 + 想等更低入场 + IV 高
  premium: 1.5-3%/月
  被行权: 折扣价买入 (减 premium) → 更好入场
  strike 定位 = Task E 入场价 (满仓价, Step 3) → 被行权 = 满仓价接货 (意图对齐)

优点: 横盘赚钱, 跌了折扣买入, post-crash IV 高=premium 丰富
缺点: 涨了错过, 需现金担保
```

### 策略选择逻辑

```
预期反弹 >15% + 资本效率优先 → B
预期反弹 5-15% + 确定性优先 → A
横盘/微跌 + 想等更好入场 → C2
高确信 + 想持有正股 → C1 或 A
无近期催化剂 + IV 高 → C
多标的扫描 (10+) → B 或 C
基本面极强 (FCF yield >8% + net cash >20%) → C 被行权也不怕
```

| 预期反弹 | A (正股+PP) | B (OTM Call) | C (CSP) |
|---------|------------|------------|---------|
| <5% | -premium | -premium | **+premium** |
| 5-15% | **更优** | 刚过 hurdle | -premium |
| 15-30% | 好 | **更优** | -premium |
| >30% | 好 | **最优** | -premium |
| 横盘 | 可 roll | theta 吃光 | **+premium** |
| 继续跌 | -premium | -premium | **被行权=折扣买入** |
| 资本效率 | 低(全额) | 高(仅 premium) | 中(现金担保) |

output 格式:

LLM 推荐: 策略 **{A/B/C/D}**
理由: {预期反弹 + 资本效率 + 催化剂 + 场景叙事基准}

## §6.4 策略 D: 收租 CSP (系统化收入, 与击球区框架互补)

```
不是标的精选, 而是系统化收入引擎 — 大跌日卖远 OTM put 收租。

触发规则:
  QQQ 跌 >1.5%  → 卖 3-4 周 put, strike = price × (1 - N_sigma × vol × √(T/252))
  SOX 跌 >3%   → 同上
  MU 跌 >5%    → 同上

  旧规则 (固定 %): QQQ ×0.9, SOX ×0.8, MU ×0.7
  动态 sigma (推荐): N=2.5, vol=60日年化, T=15 交易日
  → 固定 % 在正常 vol ≈ 2.3 sigma (行权 ~1%), 但高 vol 时偏浅

设计原理:
  ① 大跌日 IV 暴涨 → premium 最贵
  ② OTM 距离随波动率缩放 → sigma 对齐 → 行权概率一致
  ③ 3-4 周短期限 → theta 在卖方侧
  ④ 被行权 = 在想买的折扣价买入 → 意图对齐
  ⑤ 不 roll — 过期作废, 等下次触发再卖
     → 只在高 IV 日卖, 不在低 IV 日机械 roll
     → 间隙期现金空闲, 可用于击球区标的

实证 (截至 2026-07, 63 交易日 — 运营数据, 需定期更新):
  QQQ 触发 12 次 (19%), 行权 0 次
  SOXX 触发 13 次 (21%), 行权 0 次
  MU 触发 14 次 (22%), 行权 0 次
  同日触发 7 次 → 相关性风险需控制

仓位管理:
  单标的 ≤ 15% 现金担保
  科技类 (QQQ+SOX+MU) 总 ≤ 40% 现金
  建议加非科技 (XLF/XLE/TLT) 做分散
  同日多触发时 → 按优先级选 1-2 个, 不全上
```

### sigma 校准

```
固定 % 的问题: 波动率变化时行权概率会变
  正常 vol (QQQ 18%): 10% OTM = 2.3 sigma → 行权 1%
  高 vol  (QQQ 26%):  10% OTM = 1.6 sigma → 行权 6%

动态 sigma:
  strike = price × (1 - N_sigma × vol_60d × √(T/252))
  N = 2.5 (推荐, 行权 ~0.6%)
  vol = 60 日年化波动率
  T = 到期交易天数

  → vol 涨 → strike 自动变远 → 行权概率不变 → 自适应
```

## §6.5 总结

归类判定 (三维映射, §0.1 哲学):

```
好价格 = 现价 ≤ 入场价 (Step 3) 或 安全边际显著正
好公司 = 质量档 ≥ 好公司 (§3.2, ≥6/10 PASS)
麻烦一次性 = 麻烦档 ≤ 存疑 且 output_3 Top risk 无"结构性"定性

最佳买点     = 好价格 ✓ + 好公司 ✓ + 麻烦一次性 ✓
公允价好公司 = 好价格 ✗ (贵了) + 好公司 ✓ (+ 麻烦任一)
买贵了       = 现价 > 合理价/出场价 + 好公司 ✓
价值陷阱     = Step 1 flag (EPS≤0 + FCF-SBC≤0 + 平庸) 或 便宜但烂 (好价格 + 质量平庸 + 麻烦重)
结构性恶化   = 好价格 + 好公司 但 麻烦非一次性 (output_3 麻烦 重麻烦 OR Top risk 定性结构性: #6 margin 结构降 / #11 护城河性质变)
```
