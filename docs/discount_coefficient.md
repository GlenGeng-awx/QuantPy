# 折扣系数 Checklist v1.0

> 被引用自 `docs/task_d.md`。折扣系数的计算方法独立封装于此。

## 原理

折扣系数 = 质量 × 麻烦确定性 → 决定满仓目标 = 合理价 × 系数

```
合理价   = 正常化 EPS × min(8.5+g, 30)
满仓目标 = 合理价 × 折扣系数
```

质量越硬、麻烦越确定一次性，越敢接近合理价买（巴菲特"合理价买伟大公司"）。
麻烦越大/越存疑，越要"四毛买一块"。

> 估值三要素关系见 `analysis_framework.md`。

## 数据源

### 质量指标（来自 Task B，本地 CSV，免费）

| 指标 | 文件 / key | 计算 | 判定 |
|------|-----------|------|------|
| GM 水平 + 稳定性 | income_annual `Gross Profit` / `Total Revenue` | 3yr GM 均值 + 趋势 | >60% 且不下滑 = 高 |
| NM 水平 | income_ttm `Net Income` / `Total Revenue` | TTM NM% | >20% = 高 |
| FCF yield | cf_ttm `Free Cash Flow` / info.json `marketCap` | TTM FCF / MCap | >5% = 高 |
| FCF − SBC | cf_ttm `Free Cash Flow` − `Stock Based Compensation` | TTM 差值 | >0 = 合格 |
| 真缩股 vs 稀释 | income_annual `Diluted Average Shares` | 3yr 股数趋势 | 下降 = 真缩股 |
| ROIC | health/scoring.py `_compute_roic` | NOPAT / 投入资本 | >15% = 优秀 |
| ROE | info.json `returnOnEquity` | 直接 | >15% = 优秀 |

|------|------|------|

## D-1: 质量评分（0-7 分）

### 1a. 本地指标（Task B 可算，免费）

```
GM > 60% 且 3yr 不下滑            +1
NM > 20%                         +1
FCF yield > 5%                   +1
FCF − SBC > 0                    +1
真缩股（Diluted Shares 3yr 下降）  +1
ROIC > 15% 或 ROE > 15%          +1
```

### 1b. 外部指标（Task C，需 web search）

```
护城河宽（网络效应/品牌/切换成本/规模/牌照）  +1
```

### 1c. 评级

```
6-7 分 → 伟大
3-5 分 → 好公司
0-2 分 → 平庸
```

### 预判（B 完成后，C 完成前）

```
B 指标 6/6（满分不含护城河）→ 至少"好公司 ×0.67"，C 确认护城河后可升"伟大 ×0.75"
B 指标 ≤2 → "平庸 ×0.60"，C 无法升级
B 指标 3-5 → 待 C 确认护城河后定档
```

## D-2: 麻烦定性（Task C，需 web search）

### 四档定义

```
明确一次性:
  - 原因可识别（监管叫停/诉讼/一次性减值/周期底）
  - 外部驱动（非公司战略失误）
  - 已解决或正在解决（有催化/时间表）
  - GM/FCF 未结构性崩塌

一般:
  - 正常周期波动
  - 中等竞争压力
  - GM 缓慢下滑但未崩塌
  - 公司有应对措施

存疑:
  - 不确定是暂时还是结构性
  - 竞争侵蚀加速但未定论
  - 管理层战略调整效果未验证

重麻烦:
  - GM 崩塌（连续 2 季大幅下滑）
  - FCF 转负
  - **FCF − SBC < 0**（烧钱式增长，硬规则触发 → ×0.40）
  - 护城河永久受损
  - 核心产品/技术被替代
```

### 管理层更替分档

| 情形 | 麻烦定性 | 例子 |
|------|---------|------|
| 无更替 | 不影响 | — |
| 计划交接（有继任人选+时间表） | 一般 | 创始人→内部培养接班 |
| 突发离职（无继任计划） | 存疑 | CEO 突然卸任、空缺 |
| 频繁换帅（1 年 2+ C-suite） | 存疑 | TTD 一年两换 CFO |
| 创始人离开 + 无明确继任 | 重麻烦 | key person risk + 战略真空 |

### 麻烦检查项

```
2a. 麻烦原因是什么？（可识别 → 偏一次性）
2b. 是外部还是内部？（外部/监管 → 偏一次性；战略失误 → 存疑）
2c. 已解决/正在解决？（有催化 → 明确一次性；无进展 → 存疑）
2d. GM 趋势？（稳定/回升 → 偏一次性；持续下滑 → 结构性）
2e. FCF 状态？（正/恢复 → 偏一次性；转负 → 重麻烦）
2f. 竞争格局变化？（稳定 → 偏一次性；份额加速流失 → 结构性）
2g. 管理层更替？（无/计划交接→不影响或一般；突发离职/频繁换帅→存疑；创始人离开无继任→重麻烦）
```

## D-3: 交叉定档

### 折扣系数表

```
              明确一次性    一般      存疑      重麻烦
伟大           ×0.75       ×0.75    ×0.67    ×0.60
好公司         ×0.67       ×0.67    ×0.60    ×0.40~0.50
平庸           ×0.60       ×0.60    ×0.60    ×0.40
```

### 定档逻辑

```
满仓目标 = 合理价 × 折扣系数

现价 ≤ 满仓目标 → 分批建满仓
满仓目标 < 现价 < 合理价 → 不足，先小仓 / 观察
现价 > 合理价 → 买贵了，不出手
```

### 特殊情况

```
- 伟大 + 明确一次性 → ×0.75（巴菲特"合理价买伟大公司"）
  例: ADBE（GM 89%、FCF 强、护城河宽 + 明确一次性情绪伤口）

- 好公司 + 存疑 → ×0.60（最常见，需更多安全边际）
  例: PDD（GM 65% 但份额被侵蚀 + 营收放缓）

- FCF − SBC < 0 → 重麻烦 → ×0.40（不否决，总是估值；合理价 × 0.40 = 极低满仓目标）
  例: CPNG（FCF−SBC −$0.18B，烧钱式增长；合理价 $10.2 × 0.40 = 满仓 $4.1）

- 平庸 + 重麻烦 → ×0.40（赌反转，≤小仓不对称投机）
  例: INTC（GM 薄 + 代工未证实 + 18A 延迟）

- 伟大 + 无麻烦 → 无折扣适用（没好价格不出手）
  例: NVDA（质地之最但距高点仅 15%，非困境）
```

## 与其他两要素的配合

```
合理价   = min(GAAP,tool,v3.1) EPS × min(8.5+g, 30)
满仓目标 = 合理价 × 折扣系数

EPS 保守（min 三者）= 防止 NI 注水
g 保守（取低值）= 防止增长外推过高
折扣保守（×0.60~0.75）= 防止质量/麻烦判断过于乐观

三重保守 → 合理价偏低 → 需要更便宜才出手 → 哪怕错过，不要做错
```

> 仓位定档见 D-3 上文。

## 信心等级

| 判定 | 信心 | 理由 |
|------|------|------|
| 质量 1a 本地指标 | 高 | CSV 可自动计算 |
| 质量 1b 护城河 | 中 | 需 web search + 人工判断 |
| 麻烦 2a-2c 原因/解决 | 中 | web search 可查但需判断 |
| 麻烦 2d-2f 趋势/结构 | 中 | CSV + web 交叉验 |
| 交叉定档 | 高 | 查表即可 |

## 实装

```
质量 1a 可自动化（从 CSV 算 GM/NM/FCF/缩股/ROIC → 打分）
质量 1b + 麻烦 2a-2f 需 web search（Task C）
交叉定档 = 查表（自动，给定质量+麻烦 → 系数）
```
