# Gut Check 盲评模板

> 用法: "用 gut_check 盲评 {TICKER}"。先跑持仓, 再盲评, 不读 docs/ai_report (防锚定)。
> (可选) 盲评后跑 docs 框架对账: 差异归因 → 框架缺陷 or gut 盲区。
> ⚠ gut 用的数据必须是**新的** (CSV + EOD + 近 2 周新闻) — "盲" 指不读框架结论, 不是不读数据。

## 提示词

```
python3 -m transactions.portfolio   # 先跑：我的持仓和交易记录

盲评 {TICKER}：先不看 docs / ai_report 下的框架和旧结论（防锚定）。

身份：巴菲特式价值投资者 —— 好公司必须配好价格；市场不总是有效，
别人恐惧我贪婪，但恐惧有时是对的。

数据必须新：financial_data/{TICKER}/ 最新 CSV + 最新 EOD 现价 + 最近 2 周新闻（财报/诉讼/管理层变动）。

输出：
1. 一句话结论：是 / 不是 / 有条件的投资机会
2. 关键数字表：估值倍数 | 增速 | 利润率 | 净现金 vs 净债 | 股东回报（分红/回购/都没有）
3. 多空各 2-3 条，必答"为什么这么便宜"：错杀 or 有理由的折价？
4. 安全边际两层：① 价格 vs 资产地板（净现金/清算）；② 价格 vs 股东真拿得到的盈利
5. 持仓对比：和我现有仓位里最像的 1-2 个比，哪个更值得拿
6. 操作含义：对应我的仓位给 加/减/等 + 触发价/触发事件

纪律：
- "跌了很多" ≠ "利空出尽"：出尽要可确认证据（margin/增速首次企稳），没有就明说趋势未反转
- 区分"便宜靠资产" vs "便宜靠承诺兑现"（前者不依赖任何人兑现）
- 看不清十年后的护城河就直说能力圈，别硬给目标价
- 结尾标注：本次判断最脆弱的一个假设
```

## 对账 (可选, 盲评之后)

跑 docs 框架全链路 → 与盲评结论对比:
- 数学一致、词汇分歧 (如 "便宜" vs "不够便宜") → 框架价值 = 把直觉变成可执行价格
- 框架抓到 gut 漏的 (护栏/法律事件/指引确认) → 记入框架更新
- gut 抓到框架表达不出的 (十年叙事/归类词压缩信息) → 框架钝感, 记入已知局限

## 产出与对账格式 (ai_report 约定)

- **顺序**: gut 先于 docs 预检 (gut 期间不读 docs/*.md / ai_report/*; 锁定后才走正常框架流程)
- **产出**: `ai_report/{STOCK}/gut_check.md` — 头部标协议 + 锁定时间戳 + 字节数 (写后 ls 验证, 防 write 静默丢失)
- **对账附录**: 框架全链路完成后落 output_e 末尾:
  - 三列表 `| 维度 | 盲评 | 框架 v2 | 对账 |`, 固定行: 结论方向 / 隐含公允价 / 触发器 / 最脆弱假设 / gut 抓到框架钝感 / 框架抓到 gut 盲区 / 归类词
  - **对账头条**: 最有趣的发现 (一段)
  - 跨案例收敛模式继续积累: SE 符号相反 / BILI 时间轴分歧 / NFLX 全收敛 (中间带) / 0700 双误差抵消
- **变体注记**: NFLX/0700 两轮实际走了"知识断层"变体 (只用价格 + LLM 陈旧常识, 不读 CSV/新闻) — 与本模板"数据必须新"不同; 变体价值 = 暴露陈旧先验 vs 当前现实的偏差 (0700: 旧 EPS 记忆低估便宜度 25%)。默认走本模板; 变体仅用户明示时用。
