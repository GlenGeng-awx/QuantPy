# LLM vs SaaS 经济学 — 原料的便宜不等于成品的死亡

> 这条讲什么: LLM 推理 "越来越便宜" 是市场叙事, 但重度用户的账单在涨。这里用三个 assumption 的正反证据检验 "SaaS 要被 prompt 绕过" 这个叙事, 以 ADBE/NFLX/Sora 为 case 展开。
>
> 核心观点: **LLM 像电力, SaaS 像电器厂 — 原料便宜不会消灭电器厂, 只会重划谁造什么 (深电器活, 浅电器死); 而且电价分了档 (工业电 $0.15 vs 特高压 $50), 直接烧电阻丝的用户烧的是最贵的一档。**

## 三个 assumption 逐一过堂

### ① "LLM 现在的便宜是大公司补贴的"

正方: Sora 是极端例证 — **$2.1M 终身收入 vs $15M/天运营成本**, 补贴燃烧到死; OpenAI 推理成本 2025 $8.4B → 2026E $14.1B, $20 订阅的重度用户在亏钱卖; Google Gemini 零边际定价 (拿搜索利润养)。

反方: 消费级免费/订阅确实在补贴, 但 **API/企业级不是卖 below cost** — 单位经济为正。但 "效率的便宜" 的真实结构不是普跌, 是**档位分化** (2026/11 现场价目, input/output per 1M tokens):

| 档位 | 模型 | Input | Output |
|------|------|-------|--------|
| Frontier 旗舰 | Claude Opus 5.5 | $4.00 | $20.00 |
| | Claude Opus 5 | $5.00 | $25.00 |
| | GPT-6 Astra / Fable 5.1 (max reasoning) | ~$10 | ~$50 (历史新高方向) |
| 生产力主力 | Claude Sonnet 5.5 | $2.00 | $10.00 |
| 轻量/长上下文 | GPT-6 Luna / Haiku 5.5 | $0.10-0.50 | $0.50 |
| 够用级 (中国厂定义价格带) | DeepSeek V4-Flash | $0.14 | $0.28 |
| | GLM-5.3 | ~$0.15 | ~$0.50 |

两件事同时发生: **DeepSeek/GLM 把 "够用的智能" 压到 $0.15-0.50 (逼出 Luna/Haiku 应战), 而 frontier 反而越卖越贵** — "1200× 暴跌" 类叙事 ($60→$0.05) 的水分 = 拿轻量档+缓存价冒充前沿降价。同性能口径的诚实算法: Epoch AI ~13×/yr 固定性能推理成本下降。

便宜的来源拆三截 (回应 "NVDA 每代降 10×"): ① 芯片代际 (Hopper→Rubin tokens/$ 宣传口径 10×+, 整机口径打折) ② 架构/软件效率 (量化/蒸馏/投机解码/MoE — 2023-25 实际降幅主力) ③ 档位迁移 (同样的活换轻模型干 — 用户账单降幅的主力)。NVDA 供的是燃料便宜, 用户感知的便宜是三截合计。

修正后的结论: 消费层是 "补贴的便宜" (不可持续的战术定价), 企业层是 "效率+档位分化的便宜" (真实)。推论: 补贴退潮时 (Sora 已示范退场), 直接用 prompt 的个人用户先感受涨价 — **而且已经在发生的版本不是普涨, 是 frontier 越来越贵**。

### ② "SaaS 不会灭亡, 借助 LLM 提供更好更便宜的服务"

正方: 2026 实际战况是**划地而治** (无一方全胜) — 复杂工作流 (合规/权限/审计/协作) 归打包 SaaS, 简单高频任务被 agent 剥离; Gartner: 40% 企业应用将带任务型 agent (2025 <5%) — SaaS 在吸收 AI 而不是被替代; ADBE 的 Firefly/GenStudio = 防线打法 (利润从 "生成" 层迁走, 往 "工作流+资产+法务" 层挤)。档位分化越狠, "帮你路由到对的档位 + 打包稳定服务" 的批发商角色越值钱。

反方: AI unbundling 真在发生 (agent 从捆绑包抽走单功能); ADBE 自己的痛 — C&MP 净增 -36%、freemium 出水口, 新用户漏斗在被便宜替代品啃; "SaaS business model debt" 批评 — 旧捆绑里很多功能本来就是用户不要的。

结论: **部分成立** — 深度工作流 SaaS 不会亡 (转换成本+合规资产), 浅层功能 SaaS 会死一批。分界线 = "AI 能不能完整 owning outcome" — 能 → 被替代, 不能 → 被 AI 加持。

### ③ "用户绕过 SaaS 直接 prompt, 可能反而更贵"

正方 (三个里最扎实): DIY 原始 API 平台的 **TCO 常比企业 SaaS 席位贵** (Citadel/juanbeltran 口径 — 算上 token 试错、长 context、重试、嵌入、维护); shadow AI 支出失控是企业 2026 实况; 隐性成本三件: 员工时间 (prompt 工程化不是生产力)、无 SLA/合规审计、重试试错的 token 浪费。Vibe coding 同款隐账: 看似免费的 prompt, 算上调试时间和烂尾率, 比 IDE 订阅贵。

反方: 一次性/低频任务直接 prompt 确实便宜; token 价格还在跌, TCO 交叉点在右移。

结论: 成立 — **SaaS 的经济学本质是风险+复杂度的批发商** (把不稳定的 LLM 原料加工成有 SLA 的稳定服务), LLM 时代这个角色没有被消灭的理由。

## 为什么市场喊便宜, 重度用户账单却更贵

三层机制, 各管一段 (第一手实证: 本人 frontier 模型重度 agent 用户, 月账单 $1000+):

1. **档位价差**: "便宜" 说的是 $0.15-0.50 的够用级; 账单付的是 $20-50/M 输出的 frontier — 三个数量级的价差, 单价叙事和账单体验根本不在一个市场。
2. **Jevons 悖论**: 单价降 10×, 用量涨更多 (context 越来越长 / agent 循环越跑越多) — 效率便宜反而推高总消耗, "边际便宜" 和 "总账单贵" 同时为真。
3. **无打包上限**: 直接烧电阻丝的用户没有 SaaS 席位式的成本上限, token 计量上不封顶 — assumption ③ 的个人版。

## Case: Sora 关闭 → ADBE / NFLX

**ADBE (assumption ②③ 的主战场)**: Sora 关闭对它是利好但小 (生成层最大威胁者自杀, 但威胁主力本来已是 Google 免费 + Kling $500M ARR — 链内定调 "反向注脚")。②+③ 联合给 ADBE 的 "工作流防线" 论增加经济学支柱: 就算生成免费, 专业用户也不会全绕过 Adobe — prompt 原料的 TCO 高且不稳。对链内费雪票 #11 (护城河) 判定权重向好。

**NFLX (assumption ① 的镜像案例)**: Netflix 是 LLM 补贴的**受益人不是受害者** — AI 触达 ~300 部作品 (后期/VFX 降本, 省的钱再投入内容), Sarandos 拒做纯 AI 内容 ("faster and cheaper doesn't matter if AI isn't making films better") 但拥抱工具。Sora 死了反而强化 Netflix: 高端内容的 "人味稀缺性" 少了一个稀释者; 真威胁仍是 YouTube 免费洪水 (注意力稀释), 不是 AI 替代制片。① 在 NFLX 的含义: 补贴退潮 → 生成成本回升 → Netflix 的降本斜率放缓 (内容支出 $19.4B 的 AI 节省真实但有上限)。
