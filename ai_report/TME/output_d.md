## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列，非替代。详见 `docs/dcf.md`。base = FY25 annual FCF ¥9.04B（cf_ttm.csv 空，用年度作 TTM proxy；TTM OCM ¥10.04B 略低，影响 <2%）。

```
r = 10% (好公司 5/7)
g = 8% (from Task C)
P/FCF₀ = min((1+g)/(r−g), 30) = min(1.08/0.02, 30) = min(54, 30) = 30x（封顶）
net_cash/sh = (¥26.74B − ¥4.84B) / 6.76 / 1.557B = $2.08/sh
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $0.795 | 30x | $25.94 | +144% |
| DCF FCF | $0.859 | 30x | $27.85 | +162% |

回购 ¥390M ≤ SBC ¥669M → 净稀释 → **FCF−SBC 为主口径**

gap 分析:
- gap 1 (EPS→FCF−SBC): $15.30 → PE 公式差异（8.5+g=16.5x vs (1+g)/(r−g)=54→封顶 30x）+ min EPS 假阳性过度剥离。g=8% 接近 r=10%，Gordon 乘数爆炸封顶；框架 PE 16.5x 远保守于 DCF 30x
- gap 2 (FCF−SBC→FCF): $1.91 → SBC 差异（$0.064/sh × 30 = $1.91）
- 判断: **DCF 揭示低估**——EPS 模型 $10.64 对 g=8% 增长 + FCF≈NI（低 CapEx，D&A > CapEx）的公司过度保守。FCF/sh $0.859 > GAAP EPS $0.84 > min EPS $0.645（min 强制剥离假阳性 Unusual ¥2.51B，B.5 已标注）。DCF 用现金流口径，不受 Unusual 会计扰动 → 更接近内在价值

> 熊口径验证: g=5%（P/FCF=21x 不封顶）→ DCF FCF−SBC = $18.78，仍 >> EPS 模型 $8.71。全场景 DCF > EPS 模型 = 一致性低估信号
> 满仓目标仍用 EPS 模型（最保守口径 × 折扣系数 = $7.13）。DCF $25.9~$27.9 作合理价区间上限参考——内在价值大概率介于 EPS 模型 $10.6 与 DCF $26 之间
