## B.5 正常化 EPS Chain

| 口径 | EPS | 来源 |
|------|-----|------|
| GAAP | $4.56 | Diluted EPS（TTM，含递延税收益 + MTM 净亏） |

| **FINAL** | **$2.53** | **min(三者) = v3.1** |

### Detector 2a: OtherInc（股权投资 MTM）

- **vol_ratio = 2.6x**，range −$1.57B~$1.43B（Didi/Aurora/Grab 等持股 MTM 大幅摆动）→ 标记一次性 ✓
- **amount = TTM OtherInc = −$294M（净亏）** → per "只剔收益不加回亏损"，净值为负 → **不剥离**
- ⚠️ **净额陷阱**（已知问题 #11）：TTM 内含 gross 收益 $2.77B（Q3'25 +$1.43B + Q2'26 +$1.34B）被 gross 亏损 $3.06B（Q4'25 + Q1'26）净额为负。detector 剥净额 → gross 收益未剥离。**不自动改 detector**（gross 剥离过应，见 normalize_eps.md #11）。此处 GAAP $4.56 已被 gross 亏损拉低（net OtherInc 为负），MTM 不是 EPS 虚高的主因——递延税才是

### Detector 2c: TaxAnomaly（触发 — Step 1 绝对检查）

- TTM 税率 = −45.7%（Tax −$3.05B / Pretax $6.68B）
- **Step 1（abs，NEW）**：Pretax $6.68B > 0 且 TTM 税率 −45.7% < 0% → **触发** → normal_rate = 21%（法定）
  - v3.1 NI = Pretax × (1 − 21%) = $6.68B × 0.79 = $5.28B → EPS = $5.28B / 2.09B = **$2.53**
  - 剥离超额税收益 = TTM Tax − 21% × Pretax = −$3.05B − $1.40B = −$4.45B（即 $4.45B 一次性税收益被剥离）
- Step 2（rel，未到）：TTM −45.7% vs 3yr 均值 −50.9%，diff 5.3pp < 10pp → 不触发（历史本身被 DTA 扭曲，Step 2 漏判 → Step 1 兜底）
- Q3'25 递延税 −$4.05B 是 DTA 估值准备释放（离散事件），Step 1 用 21% 法定作绝对锚，不依赖被扭曲的历史均值 → catches 此 case

### Detector 2x: Unusual（工具）

- 工具 Total Unusual Items = −$20M（TTM），与 detector 2a 量级差异大 → 独立剥离（但量级小，无实质影响）

### 评估

- 框架 FINAL = **$2.53**（v3.1，21% 法定税率重算）
- $2.53 剥离了 Q3'25 一次性 DTA 释放（~$4.45B 超额税收益）。GAAP $4.56 含此水分 → 现在 v3.1 更保守
- FCF−SBC/sh = $3.91（owner earnings，不受递延税会计影响）→ 介于 v3.1 $2.53 与 GAAP $4.56 之间。DCF 交叉验用 FCF（见 D.2b）
