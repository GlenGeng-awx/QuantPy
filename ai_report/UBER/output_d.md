## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。

```
r = 10%（好公司，4/7）
g = 11%（from Task C）
P/FCF₀ = min((1+0.11)/(0.10−0.11), 30) = 30x  ← g > r，封顶
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $3.91 | 30x | $112.95 | +129% |
| DCF FCF | $4.84 | 30x | $140.79 | +186% |

参数:
- base FCF/sh = $10.12B / 2.09B = $4.84
- base FCF−SBC/sh = ($10.12B − $1.94B) / 2.09B = $3.91
- net_debt/sh = ($5.39B − $14.73B) / 2.09B = −$4.47（净债）
- 回购 $6.90B > SBC $1.94B → 净缩股 → FCF 主口径，但两者并列

gap 分析:
- gap 1 (EPS→DCF FCF−SBC): $112.95 − $49.34 = **+$63.61** → ① PE 公式差异（19.5x vs 30x cap）② **DTA 税盾差异**：EPS 用 21% 法定（剥 DTA），DCF 用 FCF（含低现金税 $458M = 7% 实际率）→ DCF 的 base ($3.91) > EPS ($2.53)，因 DTA 税盾使 FCF 高于 21%-normalized NI
- gap 2 (DCF FCF−SBC→DCF FCF): $140.79 − $112.95 = **+$27.84** → SBC 差异（$0.93/sh × 30 = $27.9）
- **判断: DCF >> EPS（gap $63.6 = 129%）**。核心分歧：**DTA 税盾是"结构性合法"（UBER 真实少缴现金税 → FCF 高 → DCF 对）还是"一次性会计水分"（DTA 终将释放完 → 税率正常化 → EPS 对）**。框架取保守（EPS $49.34），DCF 作上限参考。但 g=11%≈r=10% → 30x 封顶，DCF 不可靠（降 g=5% → P/FCF=21x → DCF FCF−SBC = $3.91×21 − $4.47 = $77.6）

> 满仓目标仍用 EPS 模型（最保守口径 × 折扣系数）。DCF 因封顶 + DTA 分歧参考价值有限。
