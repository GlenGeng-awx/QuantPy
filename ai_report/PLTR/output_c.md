## C.2 护城河

- **壁垒类型**: 
  - (1) **本体论（Ontology）+ AIP 治理层**——不是模型套壳，而是企业级 agent 操作系统（权限/审计/成本归因/治理），企业数据深度整合后切换成本极高
  - (2) **政府/国防深度嵌入**——机密级信任 + 多年合同 + 合规壁垒（JWCC/DOD 级别认证），新进入者无法复制
  - (3) **数据网络效应**——客户数据越多，本体论越强，AIP 价值越高
- **份额趋势**: **扩张**——美国商业 +149% YoY，$6.24B 剩余交易价值（YoY 翻倍），record $1M+ deals
- **威胁**: 
  - 大厂竞争（MSFT/AWS/GCP agent 框架 + 开源 LangChain 等）
  - 政府预算/政治周期依赖（DOD 预算不确定性）
  - 估值对增长极度敏感（任何减速 = 剧烈杀估值）
- **宽度: 宽** → 质量评分 +1
