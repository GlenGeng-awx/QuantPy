## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。

```

```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $0.98 | 30x | $33.0 | −0.9% |
| DCF FCF | $1.31 | 30x | $42.8 | +28.5% |

```
base_fcf    = $3.36B / 2.57B = $1.307/sh
base_sbc    = ($3.36B − $0.835B) / 2.57B = $0.982/sh
net_cash/sh = ($9.41B − $0.211B) / 2.57B = $3.58/sh
```

回购 $0 < SBC $835M → 净稀释 → **FCF−SBC 为主口径**

gap 分析:
- gap 1 (EPS→FCF−SBC): −$0.3 → PE 公式差异（8.5+g vs (1+g)/(r−g)，均封顶 30x → 差异来自 base 差异: EPS $1.11 vs FCF−SBC $0.98）
- gap 2 (FCF−SBC→FCF): $9.7 → SBC 差异（$0.325/sh × 30 = $9.7）
- gap 3 (EPS→FCF): $9.5 → PE + SBC 叠加
- 判断: **DCF FCF−SBC ≈ EPS 模型（一致）** — FCF−SBC $0.98 ≈ EPS $1.11（差异 12% 来自 OtherInc 剥离 + 税率差异）。两模型殊途同归，结论稳健。DCF FCF 高出 $9.7 纯为 SBC 未扣，但回购$0 → SBC 是真成本 → 不采纳 FCF 口径。
