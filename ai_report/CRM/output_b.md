## B.5 正常化 EPS Chain

- winner: v3.1 = tool（一致）
- adj: −10%（$1.008B 税前剥离，占 Pretax 10%）
- detectors: 2a OtherInc(MTM)+Unusual（合并取大值）+ 2b Restructuring（只标记，不剥离）

### GAAP NI → v3.1 桥接

```
GAAP 净利                    $8.02B
  − OtherInc/Unusual 合并剥离（税前）  $1.008B  ← detector 2a+2x（overlap 10.6% < 20% → 取大值）
  = 正常化税前               $9.262B
  × (1 − 税率 21.8%)
  = 正常化净利               $7.24B
  ÷ 稀释股数 931M
  = v3.1 EPS                 $7.77
```

### Detector 触发原因分析

**2a OtherInc (MTM) + Unusual 合并**: 非利息 Other = $1.15B（TTM，含 Gain on Sale of Security $2.21B）。季度波动率 vol=2.1x（range $64M~$611M）→ 触发。OtherInc $901M 与 Unusual $1.008B diff 10.6% < 20% → **合并取大值 $1.008B**，不重复剔。Salesforce Ventures 投资组合变现收益，非经营性 → 剥离合理。

**2b Restructuring**: $630M（TTM）。**只标记不剥离**（v3.1 已修）。重组是费用非收益，per"只剔收益不加回亏损"→ 不进 total_strip。连续 5 年存在（$828M→$988M→$461M→$586M→$630M）= 经常性，非一次性。
