**口径二：业主盈利中枢（v3.1 NI + 摊销 after-tax，软/估算）**

**口径三：FCF（更适合摊销重的 SaaS roll-up）**
```
FCF/股 = $14.66B / 871M = $16.83
78% GM + 10% 增长的 SaaS 合理 P/FCF ~12x → 合理价 ~$202
```

**取口径二（业主盈利中枢）→ 合理价 ~$200**（软/估算）


现价 $163.66 在 **满仓目标 $120 ~ 合理价 $200 之间** → 安全边际不足，先小仓 / 观察。
