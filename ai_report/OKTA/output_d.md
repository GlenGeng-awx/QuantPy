## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。

```
r = 11% (平庸 2/6)
g = 9.5% (from Task C)
P/FCF₀ = min((1+0.095)/(0.11−0.095), 30) = min(73.0, 30) = 30x (封顶! g ≈ r)
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $2.09 | 30x (封顶, g≈r) | $75.18 | +203% |
| DCF FCF | $5.15 | 30x (封顶, g≈r) | $167.18 | +573% |

```
FCF (TTM) = $896M
SBC (TTM) = $533M
FCF−SBC = $363M
Shares = 173.8M
FCF/sh = $5.15
(FCF-SBC)/sh = $2.09
net_cash = $2.59B − $0.35B = $2.24B → $12.53/sh
回购 $321M < SBC $533M → 净稀释 → FCF−SBC 为主口径
```

> ⚠ **g ≈ r 致 DCF 封顶不可靠**: g=9.5%, r=11%, r−g=1.5% → P/FCF=73 → 封顶 30x → 无意义。
> **DCF 揭示高 SBC**: FCF/sh $5.15 >> EPS $1.38（**3.7x!**）→ 因 SBC $533M 在 OCF 加回但不计 NI → FCF 与 NI 严重背离。SBC $533M = 17.8% Rev → 吃 59% FCF → FCF−SBC/sh $2.09 << FCF/sh $5.15。
> DCF FCF $167 ≈ 现价 $148（若 SBC 被回购对冲 → "公平"）; 但回购 $321M < SBC $533M → 净稀释 → SBC 是真成本 → DCF FCF−SBC $75 才是正确口径 → << 现价。
> **结论**: DCF g≈r 封顶不可靠; 但方向揭示: SBC 17.8% 巨大, FCF 表象（$896M）远强于真实现金创造（FCF−SBC $363M）; EPS 模型（$1.38, NI 被 SBC 压低）和 DCF FCF（$896M, SBC 加回）两个口径都失真 → 真值介于两者。

gap 分析:
- gap 1 (EPS→DCF FCF−SBC): $75.18 − $24.84 = **$50.34** → 巨大 gap: ① PE 18x vs 30x 封顶 ② FCF−SBC/sh $2.09 vs EPS $1.38（FCF−SBC > NI, 因 D&A + WC addback）③ 净现金 +$12.53/sh
- gap 2 (DCF FCF−SBC→DCF FCF): $167.18 − $75.18 = **$92.00** → SBC 差异（$533M/173.8M × 30 = $3.067 × 30 = $92.0 ✓）
- **判断: DCF 封顶不可靠**（g≈r）; 但揭示 SBC 是核心: DCF FCF $167 ≈ 现价（SBC 被忽略时"公平"）vs DCF FCF−SBC $75 << 现价（SBC 是真成本时"高估"）→ 取决于 SBC 是否被回购对冲（否, 净稀释 → 高估）。
