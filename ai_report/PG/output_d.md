## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。

```
r = 10% (好公司)
g = 2% (from Task C)
P/FCF₀ = min((1+0.02)/(0.10-0.02), 30) = min(12.75, 30) = 12.75x
```

**不封顶!** g=2% << r=10% → Gordon 公式有效 → DCF 有意义!

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $6.04 | 12.75x | $66.69 | -4.1% |
| DCF FCF | $6.26 | 12.75x | $69.45 | -0.1% |

```
base_fcf    = $15.15B / 2.42B = $6.26/sh
base_sbc    = $14.626B / 2.42B = $6.04/sh
net_debt/sh = ($35.03B - $9.94B) / 2.42B = $10.37/sh

DCF FCF     = $6.26 × 12.75 + (-$10.37) = $69.45
DCF FCF-SBC = $6.04 × 12.75 + (-$10.37) = $66.69
EPS model   = $6.62 × 10.5 = $69.51
```

回购 $5.03B > SBC $0.524B → 净缩股 → **FCF 为主口径**

gap 分析:
- gap 1 (EPS→FCF-SBC): $69.51 - $66.69 = $2.82 → PE 公式差异 (10.5x vs 12.75x), 部分被 FCF-SBC < NI 对冲
- gap 2 (FCF-SBC→FCF): $69.45 - $66.69 = $2.76 → SBC 差异 ($0.22/sh × 12.75 = $2.76) ✓
- gap 3 (EPS→FCF): $69.51 - $69.45 = $0.06 → 几乎完全对消 (gap1 + gap2 ≈ 0)
- **判断: DCF 与 EPS 一致!** gap 仅 ~4% → FCF ≈ NI (FCF/NI = 94%, SBC 极低 3.3% of FCF) → 两模型收敛 → 估值结论稳健

> 继 MRK (g=2%, r=10%, P/FCF=12.5x)、NVO (g=3%, r=9%)、PDD (g=5%, r=10%)、PFE (g=0%, r=11%) 后, PG 是第五个 DCF 不封顶且有意义的标的。
