## D.1 三要素

### 正常化 EPS（from Task B）

| 口径 | EPS |
|------|-----|
| GAAP | −$0.18 |

→ **EPS 模型 N/A**（负 EPS × min(8.5+g, 30) = 负合理价，公式失效）。改用 DCF FCF 作为合理价区间上限（per `dcf.md` DCF-6: EPS 模型 ≤ DCF FCF−SBC ≤ DCF FCF；前两者 N/A，仅 DCF FCF 可用）。

### 前瞻 g（from Task C）

**g = 9%**（3yr 营收 CAGR 8.83% 上调，反映 Q2 加速 + Ad tech 改善 + 订阅头空间；低于分析师共识 12.5% 与 Q3 指引 +14%）

## D.2 合理价 + 满仓目标（估值锚，低频）

```
合理价 = DCF FCF（base case g=9%, capped at 30x）
       = $0.418 × 30 + (−$0.93)
       = $12.54 − $0.93
       = $11.61

满仓目标 = 合理价 × 折扣系数
        = $11.61 × 0.40
        = $4.64

锚定: 恢复 EPS = −$0.18（N/A）、g = 9%、系数 = ×0.40、DCF base = FCF $0.418/sh、net_cash/sh = −$0.93、日期: 2026-08-08
```

> ⚠️ 边界情况: EPS 模型 N/A（负 EPS），DCF FCF−SBC N/A（base 负）→ 仅 DCF FCF 可用，作为合理价上限（乐观口径）。这是 `dcf.md` DCF-6 三口径体系的边界 case — 正常顺序 "EPS ≤ DCF FCF−SBC ≤ DCF FCF" 退化为 "DCF FCF 唯一可用"。满仓目标用 DCF FCF × ×0.40，比框架标准（满仓 = EPS model × 系数）更宽松，已在系数 ×0.40 中反映重麻烦惩罚。

> D 不含现价/安全边际/操作建议 — 汇总时 join A(price) + D(锚) 算。

## D.2b DCF 交叉验（base × (1+g)/(r−g) + net_cash/sh）

```
r = 11%（平庸）
g = 9%（from Task C）

P/FCF₀ = min((1 + 0.09) / (0.11 − 0.09), 30) = min(1.09 / 0.02, 30) = min(54.5, 30) = **30x**（封顶触发）
```

封顶触发点（per `dcf.md` DCF-4）: 平庸 r=11%，g ≥ 7.4% → 封顶。g=9% > 7.4% → 封顶 30x。

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价（N/A） |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | −$0.192 | 30x → 但 base 负 → N/A | N/A | — |
| DCF FCF | **$0.418** | **30x** | **$11.61** | N/A（EPS 模型失效） |

```
base_fcf    = cf_ttm['Free Cash Flow'] $705M / income_ttm['Diluted Average Shares'] 1.69B = $0.418/sh
base_sbc    = (FCF − cf_ttm['Stock Based Compensation'] $1.03B) / 1.69B = −$0.192/sh
net_cash/sh = (bs_quarterly Cash $2.66B − Total Debt $4.23B) / 1.69B = −$1.57B / 1.69B = −$0.93/sh

回购 $851M ≤ SBC $1.03B → 净稀释 → 严格说应取 FCF−SBC 口径，但其 base 为负 → DCF FCF−SBC N/A
→ 仅展示 DCF FCF，标注 FCF−SBC < 0
```

### gap 分析

- gap 1 (EPS→DCF FCF−SBC): N/A（EPS 模型失效 + FCF−SBC base 负，两口径都 N/A）
- gap 2 (FCF−SBC→FCF): **+$0.61/sh × 30x = +$18.3/sh** — SBC 差异。这是 SNAP 估值的核心争议：SBC 是真成本（→ 用 FCF−SBC，N/A）还是被回购对冲（→ 用 FCF，$11.61）？SNAP 回购 < SBC = 净稀释 → SBC 是真成本 → **DCF FCF $11.61 是乐观上限，真实内在价值应低于此**
- gap 3 (EPS→DCF FCF): N/A
- 判断: **DCF FCF $11.61 是合理价上限**，真实内在价值介于 [无效, $11.61]；乘 ×0.40 满仓目标 $4.64 = 已包含 SBC 真成本 + 重麻烦惩罚
