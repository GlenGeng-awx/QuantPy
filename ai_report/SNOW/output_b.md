## B.5 正常化 EPS Chain

| 口径 | EPS | 来源 |
|------|-----|------|

### GAAP → v3.1 桥接

```
GAAP 税前                    -$1,184M
  − OtherInc 剥离（税前）      $0       ← detector 2a: amount=-$40.5M (损失, 不剥离, per "只剔收益不加回亏损")
  − Unusual 剥离（税前）       $0       ← Total Unusual -$39.7M (损失, 不剥离)
  = 正常化税前               -$1,184M  ← 无变化（无一次性收益可剥）
  × (1 − 税率 -0.87%)          ← TTM 实际税率（亏损下仍缴少量税）
  = v3.1 净利               -$1,195M
  ÷ 稀释股数 340.7M
  = v3.1 EPS                 -$3.51
```

### Detector 2a: OtherInc（非利息其他收入）

- OtherInc = -$40.5M（损失，非收益）
- vol_ratio = 1.9x（<2x 阈值，未真正触发，但 detector 仍报告）
- 季度波动: range -$28M ~ -$1.9M，波动率 1.9x（接近但未超 2x 阈值）
- 评估: **未触发**（vol < 2x + 金额 < 1% NI），OtherInc 小额且稳定，无需剥离

### Unusual 重叠检查

```
|OtherInc -$40.5M − Unusual -$39.7M| / max = |$0.8M| / $40.5M = 2.0%
→ <20% → 重叠，取 max 不重复剔
→ 但两者均为负（损失），per "只剔收益不加回亏损"，不剥离
```

### 恢复 EPS（EPS 负值时使用，EPS-4b）

```
恢复 EPS = (TTM Pretax + 一次性费用加回 − 一次性收益剥离) × (1 − 正常税率) / 稀释股数

TTM Pretax = -$1,184M
一次性费用加回 = $0（无重组/罚款/减值，detector 2a 为损失不加回）
一次性收益剥离 = $0（无收益可剥）
正常税率 = 21%（美国法定税率；公司亏损下实际税率 ~0%，恢复时假设 21%）

恢复 NI = -$1,184M × (1 − 0.21) = -$1,184M × 0.79 = -$936M
恢复 EPS = -$936M / 340.7M = -$2.75
```

> 恢复 EPS = **-$2.75（仍为负）**
> 原因: SNOW 的亏损不是一次性的，而是结构性的（SBC $1.62B + R&D $2.03B + SGA $2.66B = OpEx $4.69B > GP $3.38B）。无一次性费用可加回、无一次性收益可剥离 → 恢复 EPS ≈ GAAP EPS（仍负）。
> EPS 模型（合理价 = EPS × PE）无法产出正值 → **N/A**。DCF FCF 成为主估值参考（详见 output_d D.2b）。
