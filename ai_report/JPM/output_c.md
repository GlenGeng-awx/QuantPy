## C.2 护城河

- **壁垒类型**: 规模 + 牌照 + 品牌
  - **SIFI 监管壁垒**: Too-Big-To-Fail = 监管护城河（进入壁垒极高）
  - **规模**: $4.9T 资产, 全球最大银行之一; 固定成本分摊极强
  - **全能银行**: 投行 + 商业银行 + 财富管理 + 支付 + 证券服务 → 多元化抗周期
  - **品牌信任**: Jamie Dimon 招牌 + 堡垒资产表 = 危机中逆势扩张（First Republic 收购）
  - **科技投入**: 年 tech spend $17B+, AI/支付领先
- **份额趋势**: 稳固扩张（First Republic 整合 + 支付业务 +13% YoY）
- **威胁**: 利率周期转向（NII 压缩）、信贷周期转向（拨备激增）、监管收紧（更严资本要求）、fintech 侵蚀支付
- **宽度: 宽**（银行里最宽, 但银行本质同质 + 高杠杆, 非软件式护城河）→ 质量评分 +1
