- **壁垒类型**：智能驾驶（XNGP VLA 2.0）领先 + 性价比智能车 + Mona 走量子品牌 + 出海渠道；AI/机器人（GX、Robotaxi）前瞻布局。属"技术/品牌"组合，非网络效应/切换成本/规模

  - 比亚迪/小米/华为价格战 + **智驾平权**（智驾从差异化变标配，XPEV 技术领先被稀释）

  - 新进入者（小米 SU7）+ 传统 OEM 智能化追赶
- **壁垒是否在侵蚀**：智驾护城河**未固化**——靠持续技术领先维持，一旦被平权即丧失差异化。Robotaxi/AI 是上行期权（Q3 试运营，Jul 9-10 员工内测已提前启动），未贡献收入
