### 净债务口径分歧（关键修正 vs 旧 base）

旧 base.md 取 FY25 Total Debt ¥19.55B → 净现金 +¥15.4B。**但 Q1'26 as-reported Total Debt = ¥41.50B（Current Debt 从 7.31B 跳至 25.37B）→ 净债务 −¥14.36B**。

## B.5 正常化 EPS Chain

| 口径 | EPS (¥) | EPS ($) | 来源 |
|------|---------|--------|------|
| GAAP | −2.36 | −0.347 | income_ttm `Diluted EPS` |
| 工具 | −3.08 | −0.453 | `Normalized Income` −2,648.8M / 953.4M shares |
| v3.1 | −2.78 | −0.409 | detector 计算（剥 Unusual gain） |
| **FINAL** | **−3.08** | **−0.453** | **min(三者)** — 全负 |

- winner: 工具（最保守）
- adj: GAAP → FINAL −0.30（−¥0.72，剥一次性收益后更负）
- detectors: **Unusual**（高信心，✅剔）+ **[Restructuring]**（低信心，只标记不剔）

### GAAP → 工具桥接

```
GAAP NI                  = −2,259.5M
  − Total Unusual Items  = +648.8M（pre-tax，gain on sale of security ¥596.7M + special income ¥52.0M）
  = 工具 Normalized NI   = −2,648.8M  ← 剥一次性收益后亏损扩大
  ÷ 稀释股数 953.4M
  = 工具 EPS             = −¥3.08
```

三口径全负 → **EPS 公式不适用（TTM 亏损）→ 用恢复 EPS**（详见 `normalize_eps.md` EPS-4b）。

### 恢复 EPS（EPS-4b，亏损股专用）

TTM 经营性亏损（OpInc −3.66B）非一次性项主导 → 无法用"加回一次性费用"恢复。**恢复 EPS 取前瞻首次盈利年共识**（FY27，stockanalysis.com Aug 3 共识）：

```
恢复 EPS（FY27 共识，首次盈利年）= +¥0.79 = +$0.116（÷6.8 FX）
  来源: stockanalysis.com Financial Forecast (Aug 3, 2026)
  FY26 共识 EPS = −¥1.06（仍亏），FY27 共识 EPS = +¥0.79（首转正）
  NI FY27 ≈ +¥0.79 × 953M = +¥753M（薄利，首盈利年 depressed）
  注: info.json forwardEps $0.38（=¥2.59）更乐观（不同共识窗口），框架取保守的 stockanalysis 共识
  注: GAAP ≈ non-GAAP（SBC 仅 0.76% of Rev，调整极小）
```

> 恢复 EPS 是**判断性估算**（依赖前瞻共识 + 转型假设），不如 min(GAAP,tool,v3.1) 精确。标注"恢复 EPS"与正常标的的"正常化 EPS"区分。合理价仍 = 恢复 EPS × min(8.5+g, 30)（见 Task D）。
