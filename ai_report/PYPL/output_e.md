## E.4 归类

**小仓/观察 — 深度低估但 take-rate 结构性侵蚀，安全边际 +2.9%（接近合理价）**

- **好价格（满足）**: 粗筛 4/7 入池（P/E 11.2x✓ + FCF yield 13.0%✓ + EV/EBITDA 8.3x✓ + P/S 1.5x✓）。双分位均贴 5yr 下限（GAAP ~7th✓、正常化 ~6.7th✓）。DCF 揭示低估（DCF FCF−SBC $87 >> EPS $61 → FCF/NI=1.35, 高 SBC addback + 低 CapEx）。但距 52W 低 +52.1%（已反弹离底）、1Y/2Y 回撤未达阈值。
- **好公司（满足）**: 质量 3/6 = 好公司（FCF−SBC $5.59B✓ + 真缩股 -9.7%/yr✓ + ROE 24.5%✓；GM 45.8%下滑✗ + NM 14.4%✗ + 护城河中等收窄✗）。回购 $6.05B >> SBC $1.00B → 净缩股。
- **麻烦（存疑）**: take-rate 侵蚀是结构性/永久性（Stripe/Adyen/Apple Pay 持续挤压）；但重组见效（FCF +18%、指引上调）+ GM 未崩塌（45.8% 仍正）→ 未到重麻烦。
- **质量×麻烦×系数**: 好公司 × 存疑 = ×0.60 → 满仓 $36.50
- **DCF 交叉验**: DCF 不封顶（g=3% << r=10%, P/FCF=14.7x）→ DCF FCF−SBC $86.7 vs EPS $60.84 → gap $25.9 → FCF >> NI（高 SBC addback + 低 CapEx → FCF/NI=1.35）。回购 >> SBC → SBC 被对冲 → FCF 口径更准确。
- **隐藏机会**: FCF yield 13.0%（全标的最强之一）。双分位均贴 5yr 下限。DCF FCF−SBC $87 >> 现价 $59 → 隐藏低估。真缩股 -9.7%/yr（回购 $6.05B/yr）。Net Debt 仅 $2.14B（≈MCap 4%，近 net cash）。
- **关键风险**: (1) take-rate 永久受压（Stripe/Adyen/Apple Pay 竞争）；(2) GM 下滑 -140bps（45.8%）；(3) NM 14.4% 薄（vs MA/V 50%+）；(4) 距 52W 低 +52%（已反弹离底）。
- **操作**: 现价 $59.07 ≈ 合理价 $60.84（安全边际 +2.9%）→ 小仓/观察。现价在满仓 $36.50 和合理价 $60.84 之间 → 小仓。等回调至满仓 $36.50 或 take-rate 止跌回升考虑加仓。
