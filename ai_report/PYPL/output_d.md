## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。


参数:
- FCF/sh = $6.59B / 924M = $7.14
- (FCF−SBC)/sh = $5.59B / 924M = $6.05
- net_cash/sh = ($11.26B − $13.40B) / 924M = −$2.32（Net Debt）

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $6.05 | 14.7x | $86.7 | +42% |
| DCF FCF | $7.14 | 14.7x | $102.6 | +69% |

回购 $6.05B > SBC $1.00B → 净缩股 → **FCF 为主口径**

gap 分析:
- gap 1 (EPS→FCF−SBC): $86.7 − $60.84 = $25.9 → PE 公式差异 (11.5x vs 14.7x Gordon) + (FCF−SBC $6.05 vs EPS $5.29 的 D&A−CapEx 差异)
- gap 2 (FCF−SBC→FCF): $102.6 − $86.7 = $15.9 → SBC 差异 ($1.08/sh × 14.7 = $15.9)
- **判断: DCF 揭示低估**——FCF $6.59B >> NI $4.90B（高 SBC addback + 低 CapEx → FCF/NI = 1.35）。回购 $6.05B >> SBC $1.00B = 净缩股，SBC 被回购对冲 → FCF 口径更准确。

> 满仓目标仍用 EPS 模型（最保守口径 × 折扣）。DCF 作为"合理价区间"参考：$61 (EPS) ~ $87 (DCF FCF−SBC) ~ $103 (DCF FCF)。
