## C.2 护城河

- **壁垒类型**: 规模/成本 + 品牌
  - **数字银行结构成本优势**: 效率比 17.6%（vs 传统银行 40%+）→ 边际成本低 = 新增客户几乎零成本
  - **135M 客户**: 拉美最大数字银行; 网络效应（更多客户 → 更多数据 → 更好风控 → 更低成本）
  - **Brazil 规模**: 80%+ 市占率; 扩张至墨西哥/哥伦比亚
  - **监管牌照**: 银行牌照 = 进入壁垒
- **份额趋势**: 扩张 — 从传统银行抢客户; 交叉销售（信贷 + 投资 + 保险）
- **威胁**: ① NPL 跳升（89bps → 5.0%, 周期 vs 结构待观察）② BRL 贬值压 USD 口径 ③ 传统银行数字化反扑 ④ Brazil 政治/宏观风险
- **宽度: 宽**（结构成本护城河 + 135M 客户 + 规模）→ 质量评分 +1
