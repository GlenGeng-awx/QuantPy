## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。

```
r = 10% (好公司)
g = 14% (from Task C)
P/FCF₀ = min((1+g)/(r−g), 30)
  (1+0.14)/(0.10−0.14) = 1.14/(-0.04) = 负值 → g > r，公式失效 → 封顶 30x
  P/FCF₀ = 30x
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 $347 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $16.97 | 30x | $560 | +61% |
| DCF FCF | $18.52 | 30x | $606 | +75% |

- base FCF/sh = €3.27B/209M × 1.184 = $18.52
- base (FCF−SBC)/sh = (€3.27B−€0.274B)/209M × 1.184 = $16.97
- net_cash/sh = (€9.39B−€0.466B)/209M × 1.184 = $50.6

回购 €977M (TTM) > SBC €274M → 净缩股（近期）→ **FCF 是主口径**（SBC 被回购对冲），但 FCF−SBC 并列展示（保守口径）

gap 分析:
- gap 1 (EPS→DCF FCF−SBC): $560 − $347 = **+$213** → PE 公式差异 (22.5x vs 30x 封顶，因 g=14%>r=10% 触发 DCF 封顶) + FCF−SBC > Normalized NI（D&A €104M + ΔWC 浮存 €243M − CapEx €70M ≈ +€277M）
- gap 2 (DCF FCF−SBC→DCF FCF): $606 − $560 = **+$46** → SBC 差异（SBC/sh $1.55 × 30 = $46.5）
- 判断: **DCF 揭示 EPS 模型对 SPOT 高增长 + 轻 CapEx 结构偏保守**——DCF FCF−SBC $560 与分析师目标均值 $607 吻合。但需注意: (a) 30x cap 因 g>r 触发，本身偏激进; (b) FCF 含 ~€240M 营运资本浮存（预收订阅 + 应付版税），随订阅增长顺向流入但非永久，作锚要打折。剔除浮存后 DCF FCF−SBC ≈ $16.97 − ($0.243B/209M×1.184×30=$0.41) → ~$519，仍 > EPS $347。

> 满仓目标仍用 EPS 模型（最保守口径 × 折扣系数 = $347 × 0.67 = $232）。DCF 作"合理价区间"上限参考: **[$347 EPS, $560 DCF FCF−SBC, $606 DCF FCF]**。区间跨度反映 g=14%>r=10% 触发 DCF 封顶 30x（vs EPS 22.5x）+ FCF>NI（D&A/浮存）的口径差异——现价 vs 区间的安全边际在 A.3 算。
