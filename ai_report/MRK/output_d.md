> **DCF 揭示高估**: DCF FCF $58 vs EPS 合理价 $76 → gap $18 → DCF 更悲观。
> gap 来源: ① FCF/sh $5.96 < EPS $7.28（FCF < NI 18%, CapEx + WC 变动）② 净债 −$17.58/sh 压低 DCF ③ P/FCF 12.75x > PE 10.5x（Gordon 比框架高 21%）, 部分对冲但不足以弥补。
> **DCF FCF-SBC $54 vs DCF FCF $58**: gap $4 → SBC/sh $0.32 × 12.75 = $4.08 ✓。回购>SBC → FCF 为主口径 → DCF FCF $58 更准确。
> **两模型一致说"买贵了"**: DCF $54-58 << EPS $76 << 现价 $129 → 三重确认高估。

gap 分析:
- gap 1 (EPS→DCF FCF−SBC): $54.32 − $76.44 = **−$22.12** → ① PE 公式差异 10.5x vs 12.75x（+$2.30×7.28=$16.7 抬高 DCF）② FCF < NI −$1.32/sh × 12.75 = −$16.9 压低 ③ 净债 −$17.58 压低 → 净效果: 抬高 $16.7 − 压低 $33.5 = −$16.8 ≈ gap $22 ✓
- gap 2 (DCF FCF−SBC→DCF FCF): $58.41 − $54.32 = **$4.09** → SBC 差异（$0.793B/2.47B × 12.75 = $0.321 × 12.75 = $4.09 ✓）
- **判断: DCF 揭示高估** — FCF < NI + 净债大 → DCF $54 < EPS $76。两模型一致: 买贵了。
