
> ✅ **DCF 不封顶 → 交叉验有意义!** g=3% << r=9%, P/FCF=17.17x < 30 → Gordon 公式正常工作。
> **DCF 揭示高 CapEx**: FCF/sh $1.64 << EPS $4.02 → **FCF 仅 NI 的 41%**（CapEx DKK 84B GLP-1 产能建设吞噬 64% OCF）。DCF FCF-SBC $24 << EPS 合理价 $46 → gap $23。
> 但: CapEx DKK 84B 是 GLP-1 工厂建设（增长投资, 非维护）→ 建成后 CapEx 将降至 ~DKK 30B → FCF 将释放至 ~DKK 102B → "normalized" DCF 更高。**DCF 用 TTM FCF 过度悲观**（同 AMZN/GOOG/MSFT/LLY 高 CapEx 模式）。
> gap 来源: ① FCF $1.64 vs EPS $4.02（FCF = NI 41%, CapEx 吞噬）② 净债 −$3.26/sh（举债建厂）③ P/FCF 17.17x > PE 11.5x（Gordon 高于框架, 部分对冲）→ 净效果: FCF 低 + 净债 压倒 PE 公式差异 → DCF << EPS。

gap 分析:
- gap 1 (EPS→DCF FCF−SBC): $23.52 − $46.23 = **−$22.71** → ① FCF $1.56 vs EPS $4.02（FCF = NI 39%, CapEx DKK 84B 吞噬）② 净债 −$3.26/sh ③ P/FCF 17.17x > PE 11.5x（部分对冲: $1.56 × (17.17−11.5) = $8.84 抬高 DCF, 但被 FCF 低 + 净债压倒）
- gap 2 (DCF FCF−SBC→DCF FCF): $24.87 − $23.52 = **$1.35** → SBC 差异（$0.35B/4.445B × 17.17 = $0.079 × 17.17 = $1.35 ✓）
- **判断: DCF 揭示高估** — 高 CapEx 致 FCF << NI → EPS 模型高估。但 CapEx 是临时性 GLP-1 建厂 → DCF 过度悲观; 真值介于 DCF $24（TTM FCF）和 EPS $46（NI）之间。
