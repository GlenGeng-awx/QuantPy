### ⚠️ 多币种 ADR 单位混淆（info.json 失真，必手算）

info.json 直出的 `EV/EBITDA=1.92x` 与 `P/S=0.635` **都是单位混淆假象**（MCap 用 USD $208.18B、EBITDA/Revenue 留 DKK 直接相除）。CLAUDE.md 交叉验证条款：EV/EBITDA<2x 但 P/E>10x = 单位混淆，本案正是典型 ADR 案例。

**手算（统一 USD，FX 6.56）**：
- MCap = $208.18B USD
- 净债 = (Total Debt DKK 130.96B − Cash DKK 26.96B) / 6.56 = 104.0B / 6.56 = **$15.85B**
- EV = $208.18 + $15.85 = **$224.03B**
- EBITDA TTM = DKK 179.89B / 6.56 = **$27.42B**
- **EV/EBITDA = 224.03 / 27.42 = 8.2x**（<10x ✓，但非"极便宜"）
- Revenue TTM = DKK 327.80B / 6.56 = $49.97B → **P/S = 208.18 / 49.97 = 4.2x**（NM 37%>25% 放宽至 4.0x，仍擦边 ✗）

> 真正便宜信号来自 **P/E 11.3x + 2Y 深度回撤 64%**，非 EV/EBITDA（8.2x 是合理偏便宜，非 1.9x 极便宜）。

### de-rating 判断

⚠️ **de-rating 陷阱（NVO 特别严重）**：历史 36–41x 是 2021-23 GLP-1 狂热期的**成长泡沫溢价**（当时增速 20-30%+、市场按"无限 TAM"定价）。如今增速切到 2026 **负增长**、2027 才恢复双位数 → 从 40x 掉到 11x **大部分是合理范式切换**（"高增长小竞争 → 双寡头分食 + 降价"），**不全是错杀**。这与 ADBE（89% GM 垄断、增速仍 12%）性质不同——NVO 的便宜里含"真实竞争恶化"成分，须打折看。安全边际不能只看"vs 历史 40x 便宜了 73%"。
