## C.2 护城河

- **壁垒类型**: 切换成本 + 规模
  - **Oracle 数据库垄断**: 全球最大企业数据库; 极高切换成本（mission-critical, 数据迁移风险大）
  - **OCI 云**: 差异化 = 高性能 + 成本优势（Exadata 一体机 + 自建数据中心）; RPO $638B
  - **全栈**: 数据库 + 中间件 + ERP + 云 → 企业级深度锁定
  - **AI**: OpenAI/Anthropic/Mistral 等 20+ AI 厂商选 OCI = AI 基建需求验证
- **份额趋势**: 数据库稳固; OCI 从零起步快速扩张（+93% YoY）
- **威胁**: ① AWS/Azure/GCP 三巨头碾压规模 ② GM 下滑（IaaS 低毛利）③ Cerner 整合风险 ④ 高杠杆 + FCF 转负 = 财务风险
- **宽度: 宽**（DB 垄断 + OCI 增长 + 切换成本）→ 质量评分 +1
