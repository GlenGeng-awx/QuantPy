## D.2 合理价 + 满仓目标

### 中周期锚

```
中周期 NI = $12-20B（含 HBM 结构性抬升；保守取下限 $12B）
中周期 PE = 12-13x（内存历史峰值 PE）
中周期 EPS = $10.5-17.5
中周期合理价 = $10.5 × 12 ~ $17.5 × 13 = $126 ~ $228
```

### P/B 回归

```
P/B 历史 = 1x（底部）~ 3x（常态峰值）
当前 P/B = 9.2x（极端高位）
 P/B 回归 3x → $89 × 3 = $267（对应权益 $100.7B，含峰值留存）
 P/B 回归 1x → $89 × 1 = $89（周期底部，对应正常化权益 ~$55B → ~$48-55）
```

### 净现金

```
净现金 = $19.64B / $930B MCap = 2.1% → 无托底
周期底部需净现金/市值 >30% → 对应价位 ~$200 以下
```

### 汇聚

```
中周期合理价 = $126-228（保守~慷慨）
P/B 峰值回归 = ~$267
P/B 底部回归 = ~$89-55
净现金托底 = 无（2.1%）
```

> 安全边际 join A(现价) + D(中周期合理价) 算, 见 output_a.md A.3。
