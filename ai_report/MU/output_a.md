## A.2 估值分位（周期股：P/E 反读 + P/B 分位 + 净现金）

### P/E 反读（周期顶部特征）

```
P/E TTM = 19.9x（info.json trailingPE；CSV GAAP $44.24 → 877.57/44.24 = 19.8x）
Forward P/E = ~5.7x（877.57 / $153.74 forwardEps，分析师预期 FY27 继续暴涨）
```

周期股底部：利润趋零/亏损 → P/E 高或负 → **买点**
周期股顶部：利润暴涨 → P/E 低 → **卖点**
**当前 18.6x 低 P/E = 峰值盈利把分母吹大 = 卖出信号，非便宜。** Forward 5.4x 更极端——假设超级周期永续。

### P/B 分位 — 极端高位

| 口径 | 值 | 说明 |
|------|-----|------|
| P/B (info.json) | 9.8x | `priceToBook`=9.84 |
| P/B (MCap/Equity) | 930B / 100.7B = 9.2x | ✓ |
| 历史区间 | 1-3x | 底部 ~1x、常态峰值 ~2-3x |
| **偏离** | **9.2x vs 历史 1-3x = 极端高位** | **周期顶部铁证** |

> 权益 $100.7B 含峰值留存收益（$94.7B vs FY25 $48.6B），账面已被尖峰利润撑大。若用正常化权益（剔除峰值留存），P/B 更高。
