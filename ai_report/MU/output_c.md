## C.1 周期定位（替代"增长前瞻 g"）

**周期股不用 g 套 min(8.5+g, 30) 公式**（forward_g.md G-4d）。无稳定 g，increments 是价格周期不是结构增长。

### 周期定位

- **当前位置: 超级周期顶部区**。AI/HBM 驱动内存荒，价格推到历史极值
- Q3'26（2026-05）营收 $41.46B，Q4'26 指引 ~$50B——**周期仍在加速**
- Forward EPS $153.74（FY27 预期，trailing $39.83 的 3.9x）——分析师预期继续暴涨

### 结构性变化（新信息，挑战"纯周期"论）

- **$100B 长期 take-or-pay 合同**（16 份，覆盖至 2030 年）——锁定最低营收，减弱传统 boom-bust 周期性
- HBM 全部产能售罄至 2027，HBM4 快速量产
- Seeking Alpha (7/28): "The Boom And Bust Memory Cycle Could Finally Be Dead"

### 但周期风险仍在

- **全行业扩产**: MU $25B CapEx + 三星/SK 海力士同步扩 HBM → 供给增加是必然
- **CXMT（中国内存竞争者）IPO** (7/15): 大规模上海 IPO，未来全球 DRAM/NAND 供给扩张风险——触发 MU 从 $1,255 回落
- **Michael Burry 空头披露**: 叠加获利了结情绪
- GM 84.6% 历史绝无仅有——即便 HBM 结构性抬升盈利底，84.6% 仍不可持续

**g = 不适用（周期股）**，仅参考：分析师预期 FY26 +247%、FY27 +81%（增速在放缓，但仍极高）

## C.5 熊市逻辑

1. **GM 84.6% 不可持续**: 历史内存 GM 30-50%，84.6% 是价格尖峰非结构改善。新增产能上线 → 供给增加 → 价格回落（FY23 曾亏损 -$5.83B）
2. **P/B 8.3x 极端高位**: 历史 1-3x。权益含 $46B 尖峰留存利润，正常化后 P/B 更高
3. **全行业扩产 $25B+**: MU + 三星 + SK 海力士 + CXMT → 2027-2028 供给过剩必然
4. **Forward PE 4.8x 是陷阱**: 假设 $153.74 EPS 可持续 = 赌"周期已死"。任何均值回归 = 腰斩再腰斩
5. **Burry 空头**: 逆向信号
6. **中周期合理价 $126-228**: 现价 $739 是其 3.3-5.9 倍

## C.6 牛市逻辑

1. **$100B take-or-pay 合同至 2030**: 16 份长期不可撤销合约，~$20B/年最低营收锁定 → 减弱 boom-bust
2. **HBM 售罄至 2027**: 全部产能已签约，HBM4 快速量产
3. **Forward PE 4.8x**: 若 FY27 EPS $154 兑现，当前 $739 看似便宜
4. **AI 需求结构性**: HBM 绑定 AI 加速器（认证壁垒），比通用 DRAM 粘性高
5. **去杠杆+净现金**: 债 $15.28→$6.38B，现金 $26B
6. **分析师目标 $1,569**: FactSet 共识 mean

**但**: 即便牛论全对，也需内存价永久维持历史极值才撑得起 $739。$100B 合同锁营收不锁 margin——HBM ASP 回落时，合同量不变但利润缩水。周期股赌"永续尖峰"是最经典顶部错误。
