## D.2 合理价 + 满仓目标（SOTP — 净现金 $7.66B 巨额须拆分）

```
操作价值 = 正常化 EPS $3.38 × 12.5 = $42.25/股
+ 净现金 = $7.66B / 304.2M（TTM diluted） = $25.18/股
= 合理价（SOTP） = $67.43/股

满仓目标 = 合理价 × 0.60 = $67.43 × 0.60 = $40.46/股

锚定: EPS=$3.38, g=4%, PE=12.5x, 系数=×0.60, 日期: 2026-08-09（锚不变自 8-01）
```

> SOTP 理由：净现金 $7.66B（25% MCap @ $104.5，见 A）= 留存收益 $6.13B（真赚的）+ 投资组合。EPS 模型（$42.25）排除现金 → 对现金充裕公司过保守；DCF（D.2b）含现金给上限。SOTP = 框架 PE（保守）× 操作 + 全额现金 = 保守-incl-现金 中间口径。
> D 不含现价/安全边际/归类 — 见 A.3。

## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列，非替代。详见 `docs/dcf.md`（Gordon 单阶段 + 质量调整 r + 封顶）。

```
r = 10%（好公司，6/7）
g = 4%（from Task C）
P/FCF₀ = min((1+0.04)/(0.10−0.04), 30) = min(17.33, 30) = 17.33x
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 模型 $42.25 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $4.02 | 17.33x | $94.85 | +125% |
| DCF FCF | $6.45 | 17.33x | $136.91 | +224% |

参数: FCF $1.96B / 304.2M = $6.446/sh；FCF−SBC ($1.96B−$0.738B)/304.2M = $4.019/sh；net_cash $7.66B / 304.2M = $25.18/sh。

回购 $1.56B > SBC $0.738B → 净缩股 → **FCF 为主口径**（回购对冲 SBC）

gap 分析:
- gap 1 (EPS→FCF−SBC): +$52.60 → **净现金 $25.18（主因，EPS 模型忽略 25% MCap 现金）** + PE 公式差异（12.5 vs 17.33，+$16.3）+ FCF−SBC $4.02 > 正常化 EPS $3.38（D&A 等，+$11.1）
- gap 2 (FCF−SBC→FCF): +$42.06 → SBC 差异（$2.43/sh × 17.33）
- 判断: DCF >> EPS 模型 — **主因是净现金**（非 SBC）。dcf.py 自动标"高 SBC / TTD-CRM pattern"**不适用 ZM**（ZM SBC/Rev 仅 15%，非高 SBC；gap 2 $42 < gap 1 $52.6，且 gap 1 主因是现金非 PE/FCF 差异）。SBC 被 $1.56B 回购对冲 → FCF 口径合理。

三口径合理价区间:
```
$42.25（EPS 模型, excl 现金, 框架 PE）
  < $67.43（SOTP, incl 现金, 框架 PE）← D.2 锚
  < $94.85（DCF FCF−SBC, incl 现金, Gordon PE）
  < $136.91（DCF FCF, 回购>SBC, FCF 口径）
```
> 满仓目标用 SOTP × 0.60 = $40.46（最保守-incl-现金 × 折扣）。DCF FCF−SBC $94.85 给"合理价区间"上限参考。
