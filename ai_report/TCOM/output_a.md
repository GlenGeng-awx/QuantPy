### de-rating 判断

低分位（~32nd）成因：

1. **范式切换**（部分永久）：增速从 2023 COVID 恢复期的 17% 降到 Q2'26 指引 3-8%（合规压力）→ "高恢复→常态" de-rating 合理
2. **SAMR 反垄断**（7/25 落地）：罚 $765M + 禁止独家交易/价格操纵 → take rate 永久受压，de-rating 有结构性成分
3. **VIE/中概折价**：地缘风险定价
4. **一次性收益扰乱**：GAAP P/E 6.6x 假便宜 → 正常化后 14.0x → 不是深度错杀

**结论**：便宜成因 = 范式切换 + SAMR 结构性 + VIE 折价叠加，非纯错杀。呼应 Task B（一次性收益垫高 EPS）和 Task C（SAMR 落地、take rate 受压）。
