## C.2 护城河

- 壁垒类型: **规模（x86 installed base + fab 规模）+ 品牌（但衰退）+ 技术（18A PowerVia 临时领先 6-12mo）**
  - x86 duopoly（与 AMD），installed base = 切换成本 → 但 ARM server + NVIDIA CPU 侵蚀
  - 18A PowerVia backside power → 临时技术领先 TSMC 6-12mo → 但 TSMC A16 2026 末追上
  - 14A High-NA EUV → 可能领先 TSMC ~1yr（2027-28）→ **speculative**
- 份额趋势: **稳定/微增**（DCG +59% AI 驱动 server CPU 回升；但 Gaudi AI 加速器非重要竞争者）
- 威胁: **AMD/TSMC（代工失验证）、NVIDIA（AI 训练垄断 + 推出 standalone CPU）、ARM server（替代 x86）**
- 代工: **未证实** → 无大型外部客户（Nvidia 停止测试 18A；仅 Fortinet 旧节点）；foundry $5.8B 主要内部
- **宽度: 中-窄**（eroding；foundry 如成功可升级 → 目前 speculative） → 不 +1
