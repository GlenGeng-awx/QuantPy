## B.5 正常化 EPS Chain

| 口径 | EPS | 来源 |
|------|-----|------|
| GAAP | $0.34 | Diluted EPS（TTM，SBC $1.02B 全费用化压低） |
| 工具 | $0.466 | Normalized Income $299M / Diluted Shares 642M |
| v3.1 | $0.387 | detector 2a + 2c（⚠ 边缘情况，见下） |
| **FINAL** | **$0.34** | **min(三者) = GAAP** |

- winner: GAAP
- adj: v3.1 +13.9% vs GAAP（**异常**，应 ≤ GAAP，见边缘情况说明）

### Detector 2a: OtherInc（非利息其他收入）

| 子项 | 金额 | 性质 |
|------|------|------|
| Other Income Expense（TTM） | -$63M | 负值 = 费用/损失，**不加回**（per "只剔收益不加回亏损"） |
| 季度波动 vol_ratio | 3.9x（> 2 触发） | 季度摆动 -$48M ~ +$10M |
| Unusual Items（TTM） | -$61M | 与 OtherInc 重叠 3.5%（< 20% → 判重叠取 max 不重复剔） |

**amount_pretax = -$63M（负值 → 不剥离，total_pretax_adj = 0）**

### Detector 2c: TaxAnomaly

| 项目 | 值 |
|------|-----|
| TTM 税率 | 17.6%（$53M / $302M） |
| 3yr 均值税率 | -167.3%（**失真**：2024 税 provision -$1.57B = 递延税备抵转回一次性） |
| 差异 | 185pp（> 10pp 触发） |
| one_time_tax after-tax | +$559M |

**⚠ 边缘情况**：2024 年 $1.57B 递延税备抵转回是**一次性收益**，使 2024 税率为 -547%（provision 为负）。3yr 均值被拉至 -167%。detector 2c 用此负税率计算 v3.1 NI = Pretax × (1 - (-1.673)) - $559M = $302M × 2.673 - $559M = $807M - $559M = $248M ≈ GAAP NI。结果 v3.1 EPS $0.387 > GAAP $0.34，违反"v3.1 ≤ GAAP"保证。

**原因**：v3.1 用 NI/shares（$248M/642M = $0.387），但 GAAP Diluted EPS $0.34 用 if-converted 法（含可转债稀释股数更高）。**口径不同致 v3.1 虚高。**

**处理**：GAAP $0.34 是最保守且口径正确 → FINAL = $0.34。v3.1 标"边缘情况，TaxAnomaly 被 2024 一次性税收益扭曲"。

### GAAP → v3.1 桥接

```
GAAP 税前 (TTM)                      $302M
  − OtherInc 剥离（税前）              $0     ← 2a: 负值不剥离
  − Unusual 剥离（税前）              $0     ← 与 OtherInc 重叠，取 max 不重复
  = 正常化税前                      $302M
  × (1 − 税率 -167.3%)              ← ⚠ 负税率（2024 一次性扭曲）
  = v3.1 税后                      $807M（虚高）
  − TaxAnomaly after-tax            $559M   ← 2c 剥离
  = v3.1 NI                        $248M
  ÷ 稀释股数 642M
  = v3.1 EPS                       $0.387
```

### 评估

v3.1 $0.387 > GAAP $0.34 是 TaxAnomaly detector 被 2024 $1.57B 递延税备抵转回扭曲所致（负历史税率 → v3.1 虚高）。**GAAP $0.34 是正确保守锚**：TTM 税率 17.6% 正常，无一次性税收益加回。工具 EPS $0.466 高于 GAAP 因 Normalized Income 未剔 SBC（工具只剔 Unusual Items）。
