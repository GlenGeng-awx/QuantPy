## D.2b DCF 交叉验

> 与 D.2 EPS 模型并列。详见 `docs/dcf.md`。

```
r = 10% (好公司, 4/6)
g = 15% (from Task C)
P/FCF₀ = min((1+0.15)/(0.10−0.15), 30) → g > r → 封顶 30x
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $0.405 | 30x | $12.27 | +54% |
| DCF FCF | $1.994 | 30x | $59.93 | +650% |

```
net_cash = $1.27B − $1.20B = $0.077B → $0.12/sh
FCF (TTM)   = $1.28B → base $1.994/sh
FCF−SBC     = $1.28B − $1.02B = $0.26B → base $0.405/sh
```

回购 $3.10B > SBC $1.02B → 框架判 FCF 为主口径
**但**: 回购 $3.10B >> FCF $1.28B（2.4x），差额靠 $980M 可转债 + 现金消耗 → **债务融资不可持续 → FCF−SBC 更现实**

gap 分析:
- gap 1 (EPS→FCF−SBC): $12.27 − $7.99 = $4.28 → PE 公式差异 (23.5x vs 30x) + FCF−SBC vs NI 微差
- gap 2 (FCF−SBC→FCF): $59.93 − $12.27 = $47.66 → SBC 差异 ($1.594/sh × 30 = $47.82)
- 判断: **DCF >> EPS → EPS 模型低估**（高 SBC 公司通病，同 TTD/CRM）。但 DCF FCF−SBC $12.27 仍 < 现价 $23.68 → 即使 realistic 口径也偏贵。DCF FCF $59.93 假设 SBC 全被回购对冲，但回购是债务融资不可持续 → 过于乐观。
