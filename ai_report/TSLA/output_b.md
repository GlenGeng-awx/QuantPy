## B.5 正常化 EPS Chain

| 口径 | EPS | 来源 |
|------|-----|------|
| GAAP | $1.08 | Diluted EPS (TTM) |
| 工具 | $1.16 | Normalized Income $4.10B / 3.54B shares |
| v3.1 | $1.09 | detector 计算 |
| **FINAL** | **$1.08** | **min(三者) = GAAP** |

- winner: GAAP（最低）
- adj: 0%（FINAL = GAAP，无上偏）
- detectors（`python3 docs/normalize_eps.py` 实跑）:
  - 2a OtherInc(MTM): −$965M 税前（**负=损失，不加回**，留在 GAAP）
  - 2b Restructuring: +$400M 税前（flag only，low confidence，不剥离）
  - 2c TaxAnomaly: +$1.28B after-tax（medium，剥离；TTM 税率 25.9% vs 历史均值 1.4%，diff 24.6pp）
  - 2d OpIncDrop: QoQ −58%（Q0 $398M vs Q1 $941M；low，flag only）
  - 2x Unusual(tool): −$400M 税前（**负=损失，不加回**）

### GAAP → v3.1 桥接

```
GAAP 税前                    $5.22B
  − OtherInc 剥离（税前）      $0          ← detector 2a 负值不加回
  − Unusual 剥离（税前）       $0          ← 2x 负值不加回
  = 正常化税前               $5.22B
  × (1 − 正常税率 1.4%)
  = 正常化净利               $5.15B
  − TaxAnomaly 剥离（after-tax） $1.28B   ← detector 2c
  = v3.1 NI                 $3.86B
  ÷ 稀释股数 3.54B
  = v3.1 EPS                $1.09
```

> ⚠ 2c TaxAnomaly：历史均值税率 1.4% 本身被 2023 年 −$5.0B 税收收益（递延税估值免扣释放）扭曲。TTM 25.9% 实为更"正常"的税率，1.4% 才是异常。但 min() 兜底：GAAP $1.08 < v3.1 $1.09，FINAL 仍取 GAAP，保守不受影响。
