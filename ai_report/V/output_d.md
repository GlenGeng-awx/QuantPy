## D.2b DCF 交叉验

> 详见 docs/dcf.md。与 D.2 EPS 模型并列，非替代。

```
r = 9% (伟大，7/7 质量评分)
g = 10% (from Task C)
(1+g)/(r−g) = 1.10 / (0.09 − 0.10) = 1.10 / (−0.01) = −110 → g > r → 封顶
P/FCF₀ = min(−110, 30) = 30x（封顶）
```

| 口径 | base ($/sh) | P/FCF₀ | DCF/sh | vs EPS 合理价 |
|------|-------------|--------|--------|---------------|
| DCF FCF−SBC | $9.35 | 30x | $275.82 | +42% |
| DCF FCF | $9.78 | 30x | $288.72 | +49% |

```
回购 $21.36B > SBC $0.92B（23x）→ 净缩股 → FCF 是主口径
net_cash/sh = ($13.79B − $23.86B) / 2148.65M = −$4.68/sh（净债）
```

gap 分析:
- gap 1 (EPS→DCF FCF−SBC): $275.82 − $194.44 = $81.38 → PE 公式差异（18.5x vs 30x 封顶）+ 股份口径差异（v3.1 NI/shares vs FCF/shares）
- gap 2 (DCF FCF−SBC→FCF): $288.72 − $275.82 = $12.90 → SBC 差异（$0.43/sh × 30）
- gap 3 (EPS→FCF): $288.72 − $194.44 = $94.28 → PE + 股份 + SBC 叠加

**判断**: DCF >> EPS，揭示 EPS 模型对高增长+低 CapEx+低 SBC 公司过度保守。但 g=10% > r=9% 导致 Gordon 失效封顶 30x，DCF 估值偏高（30x P/FCF 对 10% 增长+净债公司偏乐观）。真实价值在 $194-289 区间。现价 $362.5 仍 > DCF FCF $288.72 → 即使最乐观口径也贵 −25%。
