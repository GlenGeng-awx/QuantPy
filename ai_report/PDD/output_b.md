## B.5 正常化 EPS Chain（FX=6.8，CNY→USD）

| 口径 | EPS(CNY) | EPS(USD) | 来源 |
|------|----------|---------|------|
| GAAP | ¥64.52 | $9.49 | Diluted EPS（TTM） |
| 工具 | ¥65.59 | $9.65 | Normalized Income ¥97.18B / 1.482B 稀释股 |
| v3.1 | ¥64.46 | $9.48 | detector 计算（见下） |
| **FINAL** | **¥64.46** | **$9.48** | **min（三者）= v3.1** |

- winner: v3.1（与 GAAP 几乎相等，差 ¥0.06 = 重算口径微差）
- adj: ±0%（三口径近似相等，因 OtherInc/Unusual 均为**损失**不剥离）
- detectors（实跑 `python3 docs/normalize_eps.py PDD` 验证）:
  - **2a:OtherInc(MTM)** — 高信心，vol=3.5x（季度 range −2.18B~+3.02B），amount=**−¥4.435B（损失，非收益）** → 按"只剔收益不加回亏损"原则 **不剥离**（max(0,−4.435)=0）。vol=3.5x 来自 Q2'25 正 Other Income +3.02B vs 其他季负值，是 FX/投资损益真波动，**非半年报假阳性**（PDD 季报齐全）。
  - **2x:Unusual(tool)** — 高信心，amount=**−¥1.870B（Gain On Sale Of Security 损失）** → 损失不剥离。
  - 两者 diff 57.8% > 20% → 判独立，但**均为损失 → 均 max(0,·)=0 不剥离** → total_pretax_adj=0 → v3.1 ≈ GAAP。

### GAAP → v3.1 桥接

```
GAAP 税前                    ¥116.876B
  − OtherInc 剥离（税前）      ¥0       ← detector 2a: amount=−4.435B（损失，不剥离）
  − Unusual 剥离（税前）       ¥0       ← 2x: amount=−1.870B（损失，不剥离）
  = 正常化税前               ¥116.876B
  × (1 − 税率 18.28%)
  = 正常化净利               ¥95.510B
  ÷ 稀释股数 1.482B
  = v3.1 EPS                 ¥64.46（= $9.48 ÷ FX 6.8）
```

### Unusual 重叠检查

```
|OtherInc −4.435B − Unusual −1.870B| / max = 57.8%
→ > 20% 判独立；但两者均为负（损失）→ 均不剥离 → 无双重剥离风险
```

### 三口径对比

| 口径 | 剥离额 | Normalized NI | EPS(CNY) |
|------|--------|--------------|----------|
| GAAP | 0 | ¥95.65B | ¥64.52 |
| 工具 | ¥1.87B（Gain On Sale，加回损失） | ¥97.18B | ¥65.59 |

> 工具 vs v3.1 差距 = 工具加回了 ¥1.87B 损失（Gain On Sale Of Security 负值），v3.1 按"不加回亏损"保守保留 → v3.1 < 工具。min = v3.1 ¥64.46 = **$9.48**。

### 评估

v3.1 不过度保守（OtherInc/Unusual 均为损失，本就不剥离，三口径收敛于 ~¥64.5）。**FINAL = $9.48 稳健**，无需 SOTP 补偿路径（区别于 0700.HK 投资控股型）。
